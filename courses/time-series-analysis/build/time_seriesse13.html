13 The Frequency Domain

Everything so far has described a series by how each value relates to the ones before it. The frequency domain describes the same series by which cycles it is made of. Neither view adds information the other lacks — they are Fourier transforms of one another — but each makes different things obvious, and periodicity is far easier to see as a peak than as a pattern in the autocorrelations.
