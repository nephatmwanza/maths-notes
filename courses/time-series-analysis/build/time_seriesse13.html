13 State Space Models And The Kalman Filter

An ARMA model describes a series directly. A state space model instead supposes an unobserved process driving it, and the observations are a noisy view of that process. The framework is more general — every ARMA model can be written in state space form — and it handles missing data and time-varying parameters, which ARMA cannot.
