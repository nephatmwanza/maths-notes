1.1 Discrete Data

Discrete data can take only separate, particular values, with gaps between them. Between any two neighbouring values there is nothing a measurement could land on. Such data usually arise from counting.

Example

  1. Marks obtained in a test
  2. Number of passengers in a bus
  3. Ages of students in a class.

Presentation of discrete data are:

  1. Pie chart
  2. Bar chart
  3. Pictograph
