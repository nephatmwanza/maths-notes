1.12 Properties of \(E(X)\)

  1. If \(X\geq 0\), then \(E(X)> 0\) and \(E(X)=0\implies P(X=0)=1\).

  2. \(E(X+a)=E(X)+a\) if \(=\) constant

    Proof \begin {align*} E(X+a) &=\frac {1}{n}\sum (X+a)=\frac {1}{n}\Bigg [\sum X+\sum a\Bigg ]\\\\ &=\frac {1}{n}\sum X +\frac {1}{n}\sum a=\frac {1}{n}\sum X +\frac {n}{n}a\\\\ \implies \hspace {0.5cm}E(X+a) &=E(X) +a \end {align*}

    If \(C\) is a constant then \(E(CX)=CE(X)\) since \(E(C)=C\).

  3. For the random variable \(X\) and \(Y\) then \(E(X+Y)=E(X)+E(Y)\) property 3 and 4 shows the important property that the operation \(E(.)\) is a linear operator.
  4. \(E(g(X))=\sum \limits _1^ng(x)P(X=x)\)
  5. \(E(XY)=E(X)E(Y)\) if and only if \(X\) and \(Y\) are independent random variables.
