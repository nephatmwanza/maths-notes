14.6 Practice Problems

Problem 14.6.1. Show that \(c = \lambda + 1/\lambda \) has minimum \(2\) over \(\lambda > 0\), and find the minimal front speed of a population with diffusivity \(D = 10\) km\(^2\)/year and growth rate \(r = 0.5\) per year.

Show solution

Solution. \(c'(\lambda ) = 1 - \lambda ^{-2} = 0\) at \(\lambda = 1\), where \(c = 2\); \(c \to \infty \) at both ends. In physical units \(c^* = 2\sqrt {rD} = 2\sqrt {5} = 4.47\) km per year.

Problem 14.6.2. For the bistable equation with \(a = 0.25\), find the front speed and the width of the front, measured as the distance over which \(U\) falls from \(0.9\) to \(0.1\).

Show solution

Solution. \(c = \sqrt 2(0.5 - 0.25) = 0.354\), with the state \(1\) invading. \(U = 0.9\) at \(e^{z/\sqrt 2} = \frac 19\), \(z = -\sqrt 2\ln 9\), and \(U = 0.1\) at \(z = \sqrt 2\ln 9\), so the width is \(2\sqrt 2\ln 9 = 6.21\) in scaled units.

Problem 14.6.3. Find the critical diffusion ratio \(d\) for the Schnakenberg model with \(a = 0.1\), \(b = 0.9\), and the critical wavenumber.

Show solution

Solution. With \(f_u = 0.8\), \(g_v = -1\), \(\det J = 1\), the condition is \(0.8d - 1 > 2\sqrt d\). Put \(s = \sqrt d\): \(0.8s^2 - 2s - 1 > 0\) for \(s > (2 + \sqrt {4 + 3.2})/1.6 = 2.927\), so \(d_c = 8.57\). At threshold the minimum of \(h(q)\) is at \(q = (0.8d_c - 1)/2d_c = 0.342\), so \(k_c = 0.585\), consistent with the narrow band near \(k = 0.56\) found at \(d = 10\).

Problem 14.6.4. Show that no Turing instability is possible when the two diffusivities are equal.

Show solution

Solution. If \(d = 1\) then \(J_k = J - |k|^2I\), whose eigenvalues are those of \(J\) shifted by \(-|k|^2\). Since those of \(J\) have negative real parts, so do all those of \(J_k\). Equivalently, the condition of Theorem 14.3.1 would need \(f_u + g_v > 0\), contradicting \(\operatorname {tr}J < 0\).

Problem 14.6.5. Solve \(u_t = u_{xx} + e^{-t}\sin x\) on \((0, \pi )\) with \(u = 0\) at both ends and \(u(x, 0) = 0\).

Show solution

Solution. The source is a single eigenfunction, so try \(u = T(t)\sin x\): \(T' = -T + e^{-t}\), \(T(0) = 0\), giving \(T = te^{-t}\). The forcing decays at exactly the rate of the mode it drives, a resonance, which produces the factor \(t\). So \(u = te^{-t}\sin x\).

Problem 14.6.6. Decide which of these problems are well posed, giving a reason for each: (a) \(u_{xx} + u_{yy} = 0\) for \(y > 0\) with \(u\) and \(u_y\) given on \(y = 0\); (b) \(u_t = u_{xx}\) for \(t > 0\) on \((0, 1)\), with \(u\) given at \(t = 0\) and at both ends; (c) \(u_{tt} = u_{xx}\) on the square \(0 < x, t < 1\) with \(u\) given on all four sides.

Show solution

Solution. (a) Not well posed: Hadamard’s example (Section 3) has data tending to zero and solutions blowing up. (b) Well posed: existence by Fourier series, uniqueness and stability by the maximum principle. (c) Not well posed: \(u = \sin \pi x\sin \pi t\) vanishes on all four sides but is not zero, so solutions are not unique; boundary data on a closed curve are the wrong data for a hyperbolic equation.
