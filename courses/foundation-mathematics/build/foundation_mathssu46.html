12.5 Period, Amplitude, Phase Shift

12.5.1 Period

Definition 12.26.

A function \(f\) is called periodic if there exists a positive number \(\alpha \) such that \[f(x + \alpha ) = f(x)\] for all values \(x\) in the domain of \(f\).
The smallest such value \(\alpha \) is called the period of the function

Note 12.27.

\begin {align*} \sin (x + 2\pi ) & = \sin x \cos 2\pi + \cos x \sin 2\pi \\ & = \sin x \cdot (1) + \cos x \cdot (0)\\ & = \sin x \end {align*}

and

\begin {align*} \cos (x + 2\pi ) & = \cos x\cos 2\pi - \sin x \sin 2\pi \\ & = \cos x \cdot (1) - \sin x \cdot (0)\\ & = \cos x \end {align*}

\begin {align*} \sin (x + 2\pi ) & = \sin x\\ \cos (x + 2\pi ) & = \cos x \end {align*}

Thus the sine function and the cosine function are periodic and both have the period \(2\pi \).

Similarly

\(\sin (x - 2\pi ) = \sin x \)

\(\cos (x - 2\pi ) = \cos x\)

Note that the period of the tangent function is \(\pi \).

Consider the equation \(\, \sin x = \frac {1}{2}.\quad \) Here we see that \(\, x = \frac {\pi }{6}\,\) is a solution to the equation.
But since \(\, \sin ( x - 2\pi ) = \sin x = \frac {1}{2}\,\) we see that \(\, x - 2\pi = \frac {\pi }{6},\,\) which gives \(\, x = \frac {\pi }{6} + 2\pi \).

Also \(\, \sin (x - 4\pi ) = \sin x = \frac {1}{2}\)

\(\implies \quad x - 4\pi = \frac {\pi }{6}\)

\(\implies \quad x = \frac {\pi }{6} + 4\pi .\,\) in fact for any positive integer \(k\).

\(\sin ( x - 2k\pi ) = \sin x = \frac {1}{2}\)

\(\implies \quad x - 2k\pi = \frac {\pi }{6}\)

\(\implies \quad x = \frac {\pi }{6} + 2k\pi \)

Hence \(\, \frac {\pi }{6} + 2k\pi \,\) is also a solution to the equation \(\, \sin x = \frac {1}{2}\).

Similarly, \(\quad \sin ( x + 2\pi ) = \sin x = \frac {1}{2}\)

\(\implies \quad x + 2\pi = \frac {\pi }{6}\)

\(\implies \quad x = \frac {\pi }{6}- 2\pi \)

So that in the same way if it is a positive integer

\(\sin ( x + 2\pi k ) = \sin x = \frac {1}{2}\)

\(\implies \quad x + 2\pi k = \frac {\pi }{6}\)

\(\implies \quad x = \frac {\pi }{6} - 2\pi k\,\) is also a solution to the equation \(\, \sin x = \frac {1}{2}\)

Combining the two solutions i.e \[x = \frac {\pi }{6} + 2k\pi \qquad \text {and}\qquad x = \frac {\pi }{6} - 2k\pi \]

We conclude that for any integer \(n,\quad x = \frac {\pi }{6} + 2n\pi \,\) is a solution to the equation \(\, \sin x = \frac {1}{2}\).

Similarly, for the angle in the second quadrant \(\, x = \frac {5\pi }{6}\,\) is a solution to the equation. Hence by the periodicity of sine functions we see that for any integer \(n,\quad x = \frac {5\pi }{6} + 2n\pi \,\) is also a solution to the equation \(\, \sin x = \frac {1}{2}\).

Therefore the most general solution to the equation \(\sin x=\frac {1}{2}\) is given by

\[ x =\, \left .\begin {aligned} \frac {\pi }{6} + 2n\pi \\\\ \frac {5\pi }{6} + 2n\pi \\ \end {aligned} \right \}\, n \in \mathbb {Z} \]

Example 12.28.

Find the general solution for the equation \[\tan \theta = 2\sin \theta \]

Solution.

\(\tan \theta = 2\sin \theta \)

\begin {align*} \implies \quad \frac {\sin \theta }{\cos \theta } & = 2\sin \theta \\ \sin \theta & = 2\sin \theta \cos \theta \\ \implies \quad \sin \theta ( 1 - 2\cos \theta ) & = 0\ \end {align*}

\(\implies \quad \sin \theta = 0\quad \) or \(\quad \cos \theta = \frac {1}{2}\)

or

general solution

\begin {align*} \sin \theta = 0 \quad \implies \quad \theta & = 0\\ \theta & = \pi \\\\ \theta & = \left .\begin {aligned} 0 & + 2n\pi \\\\ \pi & + 2n\pi \\ \end {aligned} \right \} \, n\in \mathbb {Z} \end {align*}

Therefore, \(\quad \theta = \pi n \,, \quad n \in \mathbb {Z}\)

\(\cos \theta = \frac {1}{2}\)

\(\theta = \frac {\pi }{3}\quad 1^{\text {st}}\,\text {quadrant}\)

\(\theta = \frac {5\pi }{3}\quad 4^{\text {th}}\,\text {quadrant}\)

\[\cos \theta = \frac {1}{2} \quad \implies \quad \theta = \left .\begin {aligned} \frac {\pi }{3} & + 2n\pi \\\\ \frac {5\pi }{3} & + 2n\pi \\ \end {aligned} \right \}\, n \in \mathbb {Z}\]

Hence the general solution to the equation \(\quad \tan \theta = 2\sin \theta \,\) is \[\theta = \quad \left .\begin {aligned} & n\pi \\\\ \frac {\pi }{3} & + 2n\pi \\\\ \frac {5\pi }{3} & + 2n\pi \\ \end {aligned} \right \}\, n \in \mathbb {Z}\]

Example 12.29.

Given that \(\, 0 \leq \theta \leq 2\pi .\,\) Find all the values of \(\theta \) such that \[2\cos 4\theta = \sqrt {3}\]

Solution.

\(2\cos 4\theta = \sqrt {3}\quad \implies \quad \cos 4\theta = \frac {\sqrt {3}}{2}\)

\begin {align*} 4\theta & = \quad \left .\begin {aligned} \frac {\pi }{6} & + 2n\pi \\\\ \frac {11\pi }{6}& + 2n\pi \\ \end {aligned} \right \}\, n \in \mathbb {Z}\\\\\\ \implies \quad \theta & = \quad \left .\begin {aligned} & \frac {\frac {\pi }{6} + 2n\pi }{4}\\\\ & \frac {\frac {11\pi }{6} + 2n\pi }{4}\\ \end {aligned} \right \}\, n \in \mathbb {Z} \end {align*}

\[\implies \quad \theta = \quad \left .\begin {aligned} & \frac {\pi + 12n\pi }{24}\\\\ & \frac {11\pi + 12n\pi }{24}\\ \end {aligned} \right \}\, n \in \mathbb {Z} \]

\(n = 0\)

\(\theta = \frac {\pi }{24}\quad , \quad \frac {\pi }{24}\)

\(n = 1\)

\(\theta = \frac {13\pi }{24}\quad , \quad \frac {23\pi }{24}\)

\(n = 2\)

\(\theta = \frac {25\pi }{24}\quad , \quad \frac {35\pi }{24}\)

\(n = 3\)

\(\theta = \frac {37\pi }{24}\quad , \quad \frac {47\pi }{24}\)

\[\therefore \quad \theta = \frac {\pi }{24}, \quad \frac {11\pi }{24}, \quad \frac {13\pi }{24}, \quad \frac {23\pi }{24}, \quad \frac {25\pi }{24}, \quad \frac {35\pi }{24}, \quad \frac {37\pi }{24}, \quad \frac {47\pi }{24}, \quad \]

Consider the graph of \(\, f(x) = \sin bx\,\) for \(b> 0\).
One cycle of the graph is completed as \(bx\) increases from 0 to \(2\pi \).
When \(\, bx = 0, \quad x = 0\,\) and when \(\, bx = 2\pi , \, x = \frac {2\pi }{b}\)

Similarly, for \(g(x) = \cos bx\).
Therefore the period of \(\, f(x) = \sin bx\,\) and of \(\, g(x) = \cos bx\,\) when \(b> 0\) is given by \(\frac {2\pi }{b}\).

12.5.2 Amplitude

Definition 12.30. The amplitude of a periodic function is half the distance between its maximum and its minimum value: \[\text {amplitude}=\frac {\text {max}-\text {min}}{2} .\] It measures how far the curve swings either side of its centre line, not how high it reaches.

For \(f(x)=3\sin x\) the maximum is \(3\) and the minimum \(-3\), so the amplitude is \(3\); the maximum is attained when \(\sin x=1\), that is at \(x=\frac {\pi }{2}\).

For \(f(x)=-7\sin x\) the amplitude is \(\left |-7\right |=7\), the maximum \(7\) being attained when \(\sin x=-1\), at \(x=\frac {3\pi }{2}\).

Note 12.31. Amplitude is a distance, so it is never negative — which is why the absolute value appears. The negative sign in \(-7\sin x\) does not shrink the swing; it flips the curve upside down, so the graph is that of \(7\sin x\) reflected in the \(x\)-axis.

Note too that amplitude is not the same as the maximum value. For \(f(x)=2+3\sin x\) the maximum is \(5\) and the minimum \(-1\), so the amplitude is \(\frac {5-(-1)}{2}=3\), not \(5\): adding \(2\) raises the whole curve without widening its swing. Defining amplitude as “the maximum the function attains” is only correct when the curve is centred on the \(x\)-axis, which is the case in every example here but not in general.

In general the amplitude of the graph of the function \(\, f(x) = a\sin x\,\) or that of
\(\, g(x) = a \cos x\,\) is given by \(\,\left |a\right |\).

We have seen that the graph of \(\, f(x) = \sin \left (x - \frac {\pi }{2}\right )\,\) is the graph of \(\, f(x) = \sin x\,\) shifted \(\frac {\pi }{2}\) units to the right.

The number \(\frac {\pi }{2}\) in both cases is called the phase shift. In general the phase shift of the function \(\, f(x) = \sin (x - c)\,\) or \(g(x) = \cos (x - c)\,\) is \(\left |c\right |\). If \(c> 0\) the shift is to the right and if \(c<0\) the shift is to the left.

Theorem 12.32 (Period, amplitude and phase shift). For \[f(x)=a\sin \left (bx+c\right )+d \quad \text {or}\quad f(x)=a\cos \left (bx+c\right )+d,\quad b>0,\] \[\text {amplitude}=\left |a\right |,\quad \text {period}=\frac {2\pi }{b},\quad \text {phase shift}=-\frac {c}{b},\quad \text {vertical shift}=d .\] A negative phase shift moves the curve to the left, a positive one to the right.

Note 12.33. Each constant does one job, and it is worth seeing why.

\(a\) stretches the curve vertically, so it scales the swing: amplitude \(\left |a\right |\).

\(b\) compresses it horizontally. The parent function completes one cycle as its argument runs through \(2\pi \), so \(bx\) must run through \(2\pi \), which takes \(x\) only \(\frac {2\pi }{b}\) — a larger \(b\) means a shorter period and more cycles in the same space.

\(c\) shifts it sideways. Factorising, \(bx+c=b\left (x+\frac {c}{b}\right )\), and replacing \(x\) by \(x+\frac {c}{b}\) moves a graph left by \(\frac {c}{b}\). That is why the shift is \(-\frac {c}{b}\) rather than \(-c\), and why the sign feels backwards: adding inside the bracket moves the curve the opposite way to what the plus sign suggests.

\(d\) raises the whole curve, moving the centre line to \(y=d\) without touching the amplitude.

The practical rule for the shift is the one used below: set the whole bracket to zero and solve. That locates where the parent curve’s starting point has moved to, and it works without remembering any sign convention.

Example 12.34.

Find the period, the amplitude and the shift of the function \[f(x) = 2\sin \left (2x + \frac {\pi }{2}\right )\] and hence sketch the graph of \(f\).

Solution.

\(\quad \) Amplitude: \(\quad \left |2\right | = 2\)
\(\quad \) Period: \(\quad \frac {2\pi }{2}= \pi \quad \Bigg |\quad 2x = 2\pi \implies x = \frac {2\pi }{2} = \pi \)
\(\quad \) Shift: \(\quad 2x + \frac {\pi }{2} = 0\)

\(\quad \implies 2x = \frac {-\pi }{2} \quad \implies \quad x = -\frac {\pi }{4}\)

Therefore, shift is \(\left |-\frac {\pi }{4}\right | = \frac {\pi }{4}\,\) to the left.

Example 12.35.

Find the period and the shift of the function \[g(x) = 2 - 5\cos \pi \left (x - \frac {1}{2}\right )\]

Solution.

\(\quad \) Amplitude \( = \left |-5\right | = 5\)
\(\quad \) Period: \(\, \pi x = 2\pi \quad \implies \quad x = 2\)
\(\quad \) Shift: \(\quad \pi x - \frac {\pi }{2} = 0 \quad \implies \quad \pi x = \frac {\pi }{2}\)

\(\quad \implies \quad x = \frac {1}{2}\)

Therefore, the shift is \(\frac {1}{2}\) to the right.
