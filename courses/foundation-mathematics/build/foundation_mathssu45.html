12.4 Graphs

Consider the function \(\, f(x) = \sin x , \, 0 \leq x \leq 2\pi \).

Plotting the curve.

The sine function will repeat itself after \(2\pi \) radians. We can therefore expect the graph to repeat itself as \(x\) decreases to \(\, - \infty \,\) and also as \(x\) increases \(\,+\infty .\,\)
Using this factor, we now sketch the graph of \(\,f(x) = \sin x \,, \quad -4\pi \leq x \leq 4\pi \).

Similarly, the graph of the function \(\, f(x) = \cos x\,\) behaves in the same way as the graph \(\, f(x) = \sin x\).
We sketch the the graph \(\, f(x) = \cos x \,, \, -2\pi \leq x \leq 2\pi \).

\[-1\leq \sin x \leq 1\quad ,\quad - 1\leq \cos x \leq 1\]

Example 12.25.

Sketch the graph of \(\quad f(x ) = \sin \left (x - \frac {\pi }{2}\right )\,, \, -2\pi \leq x \leq 2\pi \).

Solution.

The graph of \(\, f(x) = \sin \left (x - \frac {\pi }{2}\right )\,\) is the graph of \(\, f(x) = \sin x \,\) but moved \(\frac {\pi }{2}\) units to the right.
