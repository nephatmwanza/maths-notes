18.3 Practice problems

Problem 18.1. Differentiate:

(a).
\(y=\arccos x^{2}\)
(b).
\(y=\arctan e^{3x}\)
(c).
\(y=(\arcsin x)^{2}\)
(d).
\(y=\arccos \left (\dfrac {1}{x+2}\right )\)

Show solution

Solution. Each is the chain rule applied to a standard derivative.

(a). With \(u=x^{2}\), \(\dfrac {du}{dx}=2x\), so \[\dfrac {dy}{dx}=\dfrac {-1}{\sqrt {1-u^{2}}}\cdot 2x =\dfrac {-2x}{\sqrt {1-x^{4}}} .\]

(b). With \(u=e^{3x}\), \(\dfrac {du}{dx}=3e^{3x}\), so \[\dfrac {dy}{dx}=\dfrac {3e^{3x}}{1+\left (e^{3x}\right )^{2}} =\dfrac {3e^{3x}}{1+e^{6x}} .\]

(c). With \(u=\arcsin x\), \(y=u^{2}\), so \[\dfrac {dy}{dx}=2u\cdot \dfrac {1}{\sqrt {1-x^{2}}} =\dfrac {2\arcsin x}{\sqrt {1-x^{2}}} .\]

(d). With \(u=(x+2)^{-1}\), \(\dfrac {du}{dx}=-(x+2)^{-2}\), so \[\dfrac {dy}{dx}=\dfrac {-1}{\sqrt {1-\dfrac {1}{(x+2)^{2}}}}\cdot \left (\dfrac {-1}{(x+2)^{2}}\right ) =\dfrac {1}{(x+2)^{2}}\cdot \dfrac {\left |x+2\right |}{\sqrt {(x+2)^{2}-1}} =\dfrac {1}{\left |x+2\right |\sqrt {(x+2)^{2}-1}} .\] The absolute value appears because \(\sqrt {(x+2)^{2}}=\left |x+2\right |\), not \(x+2\) — the expression is defined for \(x+2\leq -1\) as well as \(x+2\geq 1\).

Problem 18.2. Find \(\dfrac {dy}{dx}\):

(a).
\(y=\tan ^{-1}x^{3}\)
(b).
\(y=\left (\ln x\right )^{2}\)
(c).
\(y=\dfrac {4x+3}{\sqrt {2x-1}}\)

Show solution

Solution. (a). \(\dfrac {dy}{dx}=\dfrac {3x^{2}}{1+x^{6}}\).

(b). \(\dfrac {dy}{dx}=2\ln x\cdot \dfrac {1}{x}=\dfrac {2\ln x}{x}\).

(c). Write \(y=(4x+3)(2x-1)^{-1/2}\) and use the product rule: \begin {align*} \dfrac {dy}{dx} &=4(2x-1)^{-1/2}+(4x+3)\left (-\tfrac {1}{2}\right )(2x-1)^{-3/2}\cdot 2\\ &=(2x-1)^{-3/2}\left [4(2x-1)-(4x+3)\right ]\\ &=\dfrac {8x-4-4x-3}{(2x-1)^{3/2}} =\dfrac {4x-7}{(2x-1)^{3/2}} . \end {align*}

Taking the common factor \((2x-1)^{-3/2}\) out before simplifying is what keeps this short; expanding first produces an unnecessary mess.

Problem 18.3. Find \(\dfrac {dy}{dx}\):

(a).
\(y=\dfrac {x}{\sqrt {1+x^{4}}}\)
(b).
\(\tan (x+y)=x\)
(c).
\(y=x^{\cos x^{2}}\)
(d).
\(y=x\log _{10}(x+1)\)

Show solution

Solution. (a). With \(y=x\left (1+x^{4}\right )^{-1/2}\), \begin {align*} \dfrac {dy}{dx} &=\left (1+x^{4}\right )^{-1/2} +x\left (-\tfrac {1}{2}\right )\left (1+x^{4}\right )^{-3/2}\cdot 4x^{3}\\ &=\left (1+x^{4}\right )^{-3/2}\left [\left (1+x^{4}\right )-2x^{4}\right ] =\dfrac {1-x^{4}}{\left (1+x^{4}\right )^{3/2}} . \end {align*}

(b). Differentiate implicitly, remembering that \(y\) is a function of \(x\): \[\sec ^{2}(x+y)\left (1+\dfrac {dy}{dx}\right )=1 \hspace {0.5cm}\Longrightarrow \hspace {0.5cm} 1+\dfrac {dy}{dx}=\dfrac {1}{\sec ^{2}(x+y)}=\dfrac {1}{1+\tan ^{2}(x+y)} .\] Since \(\tan (x+y)=x\), this is \(\dfrac {1}{1+x^{2}}\), so \[\dfrac {dy}{dx}=\dfrac {1}{1+x^{2}}-1=\dfrac {-x^{2}}{1+x^{2}} .\]

(c). A variable raised to a variable power: take logarithms first. \[\ln y=\cos \left (x^{2}\right )\ln x .\] Differentiating both sides, \[\dfrac {1}{y}\dfrac {dy}{dx} =-2x\sin \left (x^{2}\right )\ln x+\dfrac {\cos \left (x^{2}\right )}{x},\] so \[\dfrac {dy}{dx}=x^{\cos x^{2}} \left [\dfrac {\cos \left (x^{2}\right )}{x}-2x\sin \left (x^{2}\right )\ln x\right ].\] Neither the power rule nor the exponential rule applies directly here, because the base and the exponent both vary. Logarithmic differentiation is the standard escape.

(d). Convert the base: \(\log _{10}(x+1)=\dfrac {\ln (x+1)}{\ln 10}\), so \[\dfrac {dy}{dx}=\dfrac {1}{\ln 10}\left [\ln (x+1)+\dfrac {x}{x+1}\right ].\]

Problem 18.4. Differentiate:

(a).
\(y=\dfrac {x^{2}-2}{\sqrt {x+2}}\)
(b).
\(y=\dfrac {e^{x\cos \left (x^{2}+2\right )}}{(x-2)^{2}}\)

Show solution

Solution. (a). With \(y=\left (x^{2}-2\right )(x+2)^{-1/2}\), \begin {align*} \dfrac {dy}{dx}&=2x(x+2)^{-1/2}-\tfrac {1}{2}\left (x^{2}-2\right )(x+2)^{-3/2}\\ &=\dfrac {(x+2)^{-3/2}}{2}\left [4x(x+2)-\left (x^{2}-2\right )\right ] =\dfrac {3x^{2}+8x+2}{2(x+2)^{3/2}} . \end {align*}

(b). Logarithmic differentiation again, since the function is a product and quotient of awkward pieces: \[\ln y=x\cos \left (x^{2}+2\right )-2\ln (x-2).\] Differentiating, and noting \(\dfrac {d}{dx}\left [x\cos \left (x^{2}+2\right )\right ] =\cos \left (x^{2}+2\right )-2x^{2}\sin \left (x^{2}+2\right )\), \[\dfrac {1}{y}\dfrac {dy}{dx} =\cos \left (x^{2}+2\right )-2x^{2}\sin \left (x^{2}+2\right )-\dfrac {2}{x-2},\] so \[\dfrac {dy}{dx}=\dfrac {e^{x\cos \left (x^{2}+2\right )}}{(x-2)^{2}} \left [\cos \left (x^{2}+2\right )-2x^{2}\sin \left (x^{2}+2\right )-\dfrac {2}{x-2}\right ].\]

Problem 18.5. Find \(\dfrac {dy}{dx}\):

(a).
\(y=xe^{3x}\)
(b).
\(y=2^{x^{3}}\)

Show solution

Solution. (a). By the product rule, \[\dfrac {dy}{dx}=e^{3x}+3xe^{3x}=e^{3x}(1+3x).\]

(b). The base is constant and the exponent varies, so \(\ln y=x^{3}\ln 2\) and \[\dfrac {1}{y}\dfrac {dy}{dx}=3x^{2}\ln 2 \hspace {0.5cm}\Longrightarrow \hspace {0.5cm} \dfrac {dy}{dx}=3x^{2}\ln 2\cdot 2^{x^{3}} .\] Compare with part (c) of the previous problem: there both base and exponent varied and two terms appeared. Here only one does. The \(\ln 2\) is easy to drop and is what makes \(\dfrac {d}{dx}2^{x}=2^{x}\ln 2\) rather than \(2^{x}\).
