22.1 Properties of Circles

1.
If \(r_1\) and \(r_2\) are the radii of two circles and it is the distance between the centers of two circles, the circles touch if and only if \(\, r_1 + r_2 = d\)
2.
Two circles do not touch each other if and only if \(\, r_1 + r_2 <d\)
3.
Two circles intersect one another if and only if \(\quad r_1 + r_2 > d\)
4.
One circle is inside the other circle if and only if \(\, r_1 - r_2 = d\).
