2.3 Real Numbers

The union of the set of rational numbers with the set of irrational numbers is the set of real numbers denoted by \(\mathbb {R}\).
To represents the subset of the set of real numbers we either use blackest.
e.g \((\cdot ,\cdot ),\hspace {0.5cm} (\cdot ,\cdot ],\hspace {0.5cm}[\cdot ,\cdot ),\hspace {0.5cm} [\cdot ,\cdot ]\)

\((\) or \()\) the number not included.
\([\) or \(]\) or \(\{\) or \(\}\) number included.

Example 2.7.

  • \([-2,0)\). This means \(-2\) is part of the set while 0 is not part of the set.
  • Set builder notation can also be used to describe the set \[[-2,0)=\{x\in \mathbb {R}:-2\leq x<0\}\]
  • When using interval notation the smaller number must be on the left while the bigger one must be on right side.
  • \(\infty \) infinity is not a real number.
    The blacket must always be open because it is not a real number.

Operation On \(\mathbb {R}\)

Example 2.8.

Let \(A=\{x\in \mathbb {R}:-7\leq x<3\}\) and \(B=\{x\in \mathbb {R}:x\geq -1\}\)

Find

1.
\(A\cap B\)
2.
\(A'\)

Solution.

1.
\(A=[-7,3),\hspace {0.7cm} B=[-1,8)\hspace {0.7cm} \implies \hspace {0.7cm} A\cap B=[-1,3)\)
2.
\(A'=(-\infty , -7)\cup [3,\infty )\)

Find

1.

2.
\(\cup -C\)
 

Solution.

\(A\cap B=(-2,5)\)

Properties Of \(\mathbb {R}\)
Real numbers have certain properties which allow us to compare any two real numbers or to perform some algebraic computation.

1.
Algebraic Properties
If \(x\), \(y\) and \(z\) are any three numbers, then
(a)
\(x+y=y+x\)   Commutative law
(b)
\( \begin {matrix} x+(y+z) & = & (x+y)+z\\ x(yz) & = & (xy)z\\ \end {matrix} \)  Associative Law
(c)
\(x+0=0+x=x,\hspace {0.4cm}\) 0 is addictive identity
(d)
\(x\cdot 1=1\cdot x=x,\hspace {0.4cm}\) 1 is multiplicative identity
(e)
\(x+(-x)=x-x=-x+x=0\)
(f)
\(x(y+z)=xy+xz\),  Distributive Law

2.
Order Relations:
If \(x\) and \(y\) are any two real numbers then
(a)
\(x\) is greater than \(y\) written \(x>y\) if \(x-y>0.\)
(b)
\(x\) is less than \(y\) written \(x<y\) if \(x-y<0\).
(c)
\(x\) is equal to \(y\) written \(x=y\) if \(x-y=0\).

3.
Absolute Value:

Definition 2.10. An absolute value denoted by \(|\cdot |\) \[|x|= \begin {cases} x, & \text {if}\hspace {0.3cm} x\geq \\ -x, & \text {if} \hspace {0.3cm} x<0\\ \end {cases} \]

The absolute of a real number is always positive.
e.g

(a).
\(|8|=8\)
(b).
\(|-23|=-(-23)\)

Example 2.11.

Find the value of \(|a-b|\) when

(i).
\(a=7,\hspace {0.4cm} b=4\)
(ii).
\(a=-6,\hspace {0.4cm} b=8\)
(iii).
\(a=2,\hspace {0.4cm} b=11\)

Example 2.12.

Given that \(a<b\). Express \(P\) in terms of \(a\) and \(b\), if \(\dfrac {|P-a|}{|b-a|}=\dfrac {3}{4}\).

Solution.

\(\dfrac {|P-a|}{|b-a|}=\dfrac {3}{4}\hspace {0.7cm} \implies \hspace {0.7cm} \dfrac {|P-a|}{b-a}=\dfrac {3}{4}\)

\(\implies \hspace {0.7cm} |P-a|=\dfrac {3}{4}(b-a)\)

\(\implies \hspace {0.7cm} |P-a|=\dfrac {3}{4}b-\dfrac {3}{4}a\)

case I: if \(P\geq a\) then \(P-a\geq 0\) \begin {align*} \implies \hspace {0.7cm} P-a & = \frac {3b}{4}-\frac {3a}{4}\hspace {0.7cm} \implies \hspace {0.7cm} P = \frac {3b}{4}-\frac {3a}{4}+a\\\\ & = \frac {3b}{4}+\frac {-3a+4a}{4}\\\\ \implies \hspace {0.7cm} P & = \frac {3b}{4}+\frac {a}{4}\\\\ \end {align*}

Case II: If \(P<a\) then \(P-a<0\).
Therefore, \(|P-a|=-(P-a)=-P+a\) in this case \begin {align*} -P+a & = \frac {3b}{4}-\frac {3a}{4}\hspace {0.7cm} \implies \hspace {0.7cm} -P=\frac {3b}{3}-\frac {3a}{4}-a\\\\ - P & = \frac {3b}{4}-\frac {7a}{4}\\\\ \implies \hspace {0.7cm} P & = \frac {7a}{4}-\frac {3b}{4}\\\\ \end {align*}

Example 2.13.

Solve the equation, \(|x-7|=11\).

case I: \(x>7\) so that \(x-7=0\)
in this case \(|x-7|=x-7=11\hspace {0.5cm}\) \(\implies \hspace {0.5cm} x=7+11=18\)

case II: \(x<7\), so that \(|x-7|=-(x-7)\)
In this case \(|x-7|=-(x-7)=11\)
\(x-7=-11\hspace {0.5cm} \implies \hspace {0.5cm} x=-11+7=-4\)

  • Let \(k\) be a positive real number consider the inequality \(|x|<k\).
    If \(x\geq 0\) then \(|x|=x\) so that \(|x|<k\hspace {0.4cm} \implies \hspace {0.4cm} x<k\hspace {0.2cm} \cdots \hspace {0.2cm}(1)\)

    If \(x<0\) then \(|x|=-x\) so that \(|x|<k\hspace {0.5cm} \implies \hspace {0.5cm} -x<k\hspace {0.4cm}\\ \implies \hspace {0.4cm} -k<x\hspace {0.2cm} \cdots \hspace {0.2cm} (2)\)
    Now, combining the two inequalities we conclude that \(|x|<k \iff -k<x<k\).
