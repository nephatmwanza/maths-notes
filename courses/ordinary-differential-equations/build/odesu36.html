5.7 Practice Problems

Problem 5.7.1. Compute \(e^{At}\) for \(A = \begin {bmatrix} 0 & 1\\ -1 & 0\end {bmatrix}\) directly from the series, and describe the solutions of \(x' = Ax\).

Show solution

Solution. \(A^2 = -I\), so \(A^{2k} = (-1)^kI\) and \(A^{2k+1} = (-1)^kA\). Splitting the series, \(e^{At} = \cos t\,I + \sin t\,A = \begin {bmatrix} \cos t & \sin t\\ -\sin t & \cos t\end {bmatrix}\), a rotation by angle \(-t\). The solutions move clockwise around circles centred at the origin with period \(2\pi \): a centre.

Problem 5.7.2. For the damped oscillator \(y'' + by' + ky = 0\) with \(b \geq 0\), \(k > 0\), classify the origin in terms of \(b\) and \(k\), and identify the underdamped, critically damped and overdamped cases.

Show solution

Solution. The system matrix \(\begin {bmatrix} 0 & 1\\ -k & -b\end {bmatrix}\) has \(\tau = -b\) and \(\Delta = k > 0\). If \(b = 0\) the origin is a centre (undamped oscillation). If \(0 < b^2 < 4k\) it is a stable spiral: the underdamped case, decaying oscillations. If \(b^2 = 4k\) it is a degenerate stable node, critical damping, the fastest return without oscillation. If \(b^2 > 4k\) it is a stable node: overdamped, a slow return without oscillation.

Problem 5.7.3. For \(A = \begin {bmatrix} 0 & 1\\ 0 & 0\end {bmatrix}\) and \(B = \begin {bmatrix} 0 & 0\\ 1 & 0\end {bmatrix}\), compute \(e^A\), \(e^B\), \(e^Ae^B\) and \(e^{A+B}\), and show that \(e^{A+B} \neq e^Ae^B\).

Show solution

Solution. \(A^2 = B^2 = 0\), so \(e^A = I + A = \begin {bmatrix} 1 & 1\\ 0 & 1\end {bmatrix}\) and \(e^B = \begin {bmatrix} 1 & 0\\ 1 & 1\end {bmatrix}\), with \(e^Ae^B = \begin {bmatrix} 2 & 1\\ 1 & 1\end {bmatrix}\). Next \(A + B = \begin {bmatrix} 0 & 1\\ 1 & 0\end {bmatrix}\) has \((A + B)^2 = I\), so \(e^{A+B} = \cosh 1\,I + \sinh 1\,(A + B) = \begin {bmatrix} 1.543 & 1.175\\ 1.175 & 1.543\end {bmatrix}\). The two differ; indeed \(AB - BA = \begin {bmatrix} 1 & 0\\ 0 & -1\end {bmatrix} \neq 0\).

Problem 5.7.4. Show that the zero solution of \(x' = Ax\) is stable for \(A = 0\) but not for \(A = \begin {bmatrix} 0 & 1\\ 0 & 0\end {bmatrix}\), although both have the double eigenvalue \(0\).

Show solution

Solution. For \(A = 0\) every solution is constant, hence bounded. For the Jordan block, \(e^{At} = I + tA\), and the solution from \((0, 1)\) is \((t, 1)\), unbounded. This is Theorem 5.3.2(iv): the eigenvalue \(0\) has a Jordan block of size two.

Problem 5.7.5. Solve \(x' = \begin {bmatrix} 3 & -2\\ 4 & -1\end {bmatrix}x\) with \(x(0) = (1, 0)\), and classify the origin.

Show solution

Solution. \(\tau = 2\), \(\Delta = -3 + 8 = 5\), \(\tau ^2 - 4\Delta = -16\): an unstable spiral with eigenvalues \(1 \pm 2i\). An eigenvector for \(1 + 2i\) solves \((2 - 2i)v_1 - 2v_2 = 0\), so \(v = (1, 1 - i)\), with real part \(u = (1, 1)\) and imaginary part \(w = (0, -1)\). The real solutions are \(e^t(u\cos 2t - w\sin 2t) = e^t(\cos 2t, \cos 2t + \sin 2t)\) and \(e^t(u\sin 2t + w\cos 2t) = e^t(\sin 2t, \sin 2t - \cos 2t)\). At \(t = 0\) these are \((1, 1)\) and \((0, -1)\), so \(x(0) = (1, 0)\) is their sum, and \(x(t) = e^t(\cos 2t + \sin 2t,\ 2\sin 2t)\). Check: \(x'(0) = (1 + 2, 4) = (3, 4) = A(1, 0)\).

Problem 5.7.6. An oscillator \(y'' + 4y = \cos \omega t\) starts at rest. Find the solution for \(\omega = 1.9\), the period of the beats, and the maximum amplitude. What happens at \(\omega = 2\)?

Show solution

Solution. With \(\omega _0 = 2\), \[ y = \frac {1}{4 - 3.61}(\cos 1.9t - \cos 2t) = 2.564(\cos 1.9t - \cos 2t) = 5.128\sin (0.05t)\sin (1.95t) . \] The envelope \(5.128|\sin 0.05t|\) has period \(\pi /0.05 = 62.8\), and the maximum amplitude is \(5.13\). At \(\omega = 2\), \(y = \frac t4\sin 2t\), which grows without bound.
