12.6 Practice problems

Problem 12.6.1. Show that for a linear model, \(\mathbf {f}(\boldsymbol \theta ) = \mathbf {X}\boldsymbol \theta \), Gauss–Newton reaches the least-squares estimate in one step from any starting value.

Show solution

Solution. Here \(\mathbf {F} = \mathbf {X}\) for every \(\boldsymbol \theta \), and \(\mathbf {e}^{(0)} = \mathbf {y} - \mathbf {X}\boldsymbol \theta ^{(0)}\). The step is \(\boldsymbol \delta = (\mathbf {X}^\top \mathbf {X})^{-1}\mathbf {X}^\top (\mathbf {y} - \mathbf {X}\boldsymbol \theta ^{(0)}) = \hat {\boldsymbol \beta } - \boldsymbol \theta ^{(0)}\), so \(\boldsymbol \theta ^{(1)} = \hat {\boldsymbol \beta }\). The linear approximation is exact, so the first step is the answer.

Problem 12.6.2. For the model \(y = \theta _1e^{-\theta _2x} + \varepsilon \) and the drug data of Example 12.3.2:

(a)
write down \(\hat \theta _1(\theta _2)\) and \(S_p(\theta _2)\);
(b)
evaluate them at \(\theta _2 = 0.3\), given \(\sum e^{-0.3x}y = 23.7162\), \(\sum e^{-0.6x} = 1.18313\) and \(\sum y^2 = 475.57\).

Show solution

Solution. (a) With \(g_i = e^{-\theta _2x_i}\), \[ \hat \theta _1(\theta _2) = \frac {\sum e^{-\theta _2x_i}y_i}{\sum e^{-2\theta _2x_i}} , \qquad S_p(\theta _2) = \sum y_i^2 - \frac {\bigl (\sum e^{-\theta _2x_i}y_i\bigr )^2}{\sum e^{-2\theta _2x_i}} . \]

(b) \(\hat \theta _1(0.3) = 23.7162/1.18313 = 20.045\) and \[ S_p(0.3) = 475.57 - \frac {23.7162^2}{1.18313} = 475.57 - 475.399 = 0.171 , \] a little above the minimum \(0.154\) at \(\theta _2 = 0.3047\). Since \(S_p\) is the difference of two nearly equal numbers, the sums must be carried to many figures.

Problem 12.6.3. The following data appear to rise steeply and then level off:

\(x\) 1 2 3 4 5 6 7 8
\(y\) 2.1 3.9 6.2 7.8 8.6 9.1 9.4 10.0

The linear spline \(y = \beta _0 + \beta _1x + \beta _2(x - t)_+ + \varepsilon \) was fitted for trial knots \(t = 3, 4, 5, 6\), with residual sums of squares \(0.984\), \(0.123\), \(0.807\) and \(2.288\); a straight line gives \(5.769\). Estimate the knot, and describe the fitted model if \(\hat \beta _0 = 0.096\), \(\hat \beta _1 = 1.973\) and \(\hat \beta _2 = -1.468\) at that knot.

Show solution

Solution. By Theorem 12.5.1, with \(t\) as the non-linear parameter, \(\hat t = 4\), where the residual sum of squares is smallest (a finer search between \(3\) and \(5\) could refine it). The fitted model rises at \(1.973\) per unit of \(x\) up to \(x = 4\) and at \(1.973 - 1.468 = 0.505\) per unit afterwards. Note that the usual \(t\)-tests treat \(t\) as known; since it was chosen from the data, they are somewhat optimistic.

Problem 12.6.4. For the asymptotic regression model \(f = \theta _1 - \theta _2e^{-\theta _3x}\):

(a)
find the columns of \(\mathbf {F}\);
(b)
identify which parameters are conditionally linear, and describe the profile approach;
(c)
suggest starting values from a plot of data that rise from about \(3\) at \(x = 0\) towards about \(10\).

Show solution

Solution. (a) \(\partial f/\partial \theta _1 = 1\), \(\partial f/\partial \theta _2 = -e^{-\theta _3x}\), \(\partial f/\partial \theta _3 = \theta _2xe^{-\theta _3x}\).

(b) For fixed \(\theta _3\) the model is linear in \((\theta _1, \theta _2)\), with columns \(\mathbf {1}\) and \(-e^{-\theta _3\mathbf {x}}\). So \(S_p(\theta _3)\) is the residual sum of squares from regressing \(y\) on \(e^{-\theta _3x}\) with an intercept, a function of one variable to be minimised.

(c) The ceiling is \(\theta _1 \approx 10\), and at \(x = 0\), \(f = \theta _1 - \theta _2 \approx 3\), so \(\theta _2 \approx 7\). For \(\theta _3\), find the \(x\) at which the curve has covered half the distance, \(y \approx 6.5\); there \(e^{-\theta _3x} = \frac 12\), so \(\theta _3 \approx \log 2/x\).

Problem 12.6.5. For the enzyme data of Example 12.5.2, find an approximate \(95\%\) confidence interval for the maximum rate \(\theta _1\), and say whether the Lineweaver–Burk estimate \(8.968\) is consistent with the data.

Show solution

Solution. With \(t_{0.025,4} = 2.776\): \(9.938 \pm 2.776(0.328) = 9.938 \pm 0.911\), from \(9.03\) to \(10.85\). The Lineweaver–Burk value \(8.968\) lies outside the interval: the linearised fit underestimates the maximum rate, for the reason given in the example.
