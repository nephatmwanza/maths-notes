2 SOME TESTS BASED ON BINOMIAL DISTRIBUTION

-
A random variable \(X\), a count of the occurrences of some outcome in a fixed number of observations \((n)\) is Binomial if
*
each observation falls into one of the just two categories i.e success/failure.
*
\(n\) observations are all independent.
*
probability of success is the same for each observations

\(X\thicksim B(n,P)\)

-
Sign and Binomial tests are examples of NP tests that are based on the Binomial distribution.
