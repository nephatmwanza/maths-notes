3.5 Percentile and Quartile

The \(K^{th}\) percentile of a set of values divides them so that \(K\%\) of the values lie below and \((100-K)\%\) of values above.

*
\(25^{th}\) percentile \(\implies \) lower quar tile.
*
\(50^{th}\) percentile \(\implies \) median.
*
\(75^{th}\) percentile \(\implies \) upper quar tile.

Consider a set of values \(3.7,\hspace {0.3cm} 2.7,\hspace {0.3cm} 3.3,\hspace {0.3cm} 1.3,\hspace {0.3cm} 2.2,\hspace {0.3cm} 3.1\)

- Order statistic of the sample is fractions.

Exercise: (Quartile function )

1.
What is the lower quartile of these values? [ans: 2.325]
2.
What is the median of these values? [ans: 2.9]
3.
What is the upper quartile of these values? [ans: 3.35]
-
In general to define the quartile which corresponds to the fraction \(P\) are linear interpolation between the two nearest \(P_i\).
-
If \(P_i\) lies a fraction \(f\) of the way from \(P_i\) to \(P_{i+1}\) define \(P^{th}\) quartile to be \[Q(P)=(1-f)Q(P_i)+fQ(P_{i+1})\]
-
Median \(Q(0.5)\)
-
L.Q \(Q(0.25)\)
-
U.P \(Q(0.75)\)

- General case: Given a random sample \(x_1,\dots ,x_n\) we can define the quar-tiles for any fraction \(P\) as follows \(x_{(1)}<x_{(2)}<\dots <x_{(n)}.\)

Take the order statistic to be the quar-tile which corresponds to the fractions \[P_i=\frac {i-1}{n-1},\hspace {0.4cm}i=1,2,\dots ,n\]
