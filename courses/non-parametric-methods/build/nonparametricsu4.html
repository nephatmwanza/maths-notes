1.4 Rationale of \(H_0\) and \(\alpha \)

-
True \(H_0\) \(\implies \) that values of \(t\) near \(0\) are more likely than large value of \(t\) either \(+ve\) or \(-ve\).
-
False \(H_0\) \(\implies \) that large values of \(|t|\) are more likely to occur.
-
\(\alpha =5\%\implies \) that if we perform a large number of such tests on different independent samples when \(H_0\) is true we shall in the long run incorrectly reject \(H_0\) in a proportion \(\alpha \) of these i.e we would reject \(H_0\) when it were true in a long in \(1\) in \(20\) tests on \(5\%\) of all tests.
-
Modern software gives the exact probability of obtaining the value \(|t|\) equal to or greater than the observed when \(H_0\) is true. The probability is called a \(P\)-value. It measures the strength of evidence against \(H_0\) provided by the data. The smaller the \(P\)-value is, the stronger is the evidence.
-
Type I error/ Error of the 1\(^{st}\) kind \(\implies \) rejecting \(H_0\) when it is true. If we decide to reject \(H_0\) whenever our \(P\)-value is less than some fixed \(P_0\) and then if in all cases \(H_0\) is true, we would in the long run reject it in a proportion \(P_0\) of these cases.
-
We reject \(H_0\) whenever \(P\)-value \(\leq P_0\) and do so when \(|t|\geq k\), where \(k\) is true
\(\hspace {0.2cm} P_r(|t|\geq k)=P_0\hspace {0.2cm}\) and these values of \(t\) define a critical/ rejection region of size \(P_0\).
-
Using critical of size \(P_0\implies H_0\) is plausible if \(|t|<k\).
-
Using CR sometimes we continue to regard \(H_0\) as plausible when in fact \(H_1\) is true. Continuing to accept \(H_0\) when \(H_1\) is true is type II error.
-
If we let \(P\) be probability of Type II error then \(1-\beta \) is the power of the test. Large values of \(1-\beta \) are preferred.
