3.16 Freedman Test

Sometimes it happens that the data collected are only in the rank form within each block normality can introduced.
In these situations a non-parametric approach called Freedman test can be used.
The Freedman test is primary used to test whether \(k\) sample groups (i.e the treatment level) have been selected from populations using equal medians i.e you test \(H_0\),
\(H_0:M_{.1}=M_{.2}=\dots =M_{.k}\) against \(H_1:\) Not all \(M_{.j}\) are equal ( where \(j=1,2,\dots ,k\)).

To develop the test. You first replace the data with their ranks on a block to block basis.
In each of the \(n\) independent blocks, the \(k\) observations are replaced by their corresponding ranks such that rank one is given to the smallest observation and rank \(k\) is given to the largest.
If any values in a block are tide assign the averaged rank that they would otherwise have been given. Thus \(R_{ij}\) is the rank from \(1,\dots ,k\) associated with \(j^{th}\) group (where \(j\) runs from \(1,\dots ,k\)) in the \(i^{th}\) block (where \(i=1,\dots ,n\)).
Under the null hypothesis of no difference in \(k\) groups each ranking within a block is equally likely. They are \(k!\) ways of ranking within each particular block and \((k!)^n\) possible arrangements of ranks over an \(n\) independent blocks. If the null hypothesis is true there will be no differences any way average ranks for each group are taken over all blocks.

From the above the following \(F\) test statistic \begin {align*} F_R &=\frac {12}{nk(k+1)}\sum ^k_{j=1}R^2_{.j}-3n(k+1)\\\\ &=\frac {12n}{k(k+1)}\Bigg [\sum ^k_jR^2_{.j}-\frac {k(k+1)^2}{4}\Bigg ]\\ \end {align*}

\(R^2_{.j}\) is the square rank total for group \(j\). \(n\) is the number of independent blocks \(k\) is the number of groups or treatment levels

Small sample sizes typically for \(k<6\) and \(n<14\) use critical values from the tables \(F(k,n,\alpha ).\)

As the number of blocks or treatment groups gets large (\(k>5\) or \(n>13\)), the test statistic \(F_R\) can be approximated by the chi-square \(\chi ^2_{\alpha }\) distribution thus for any level of significance \(\alpha \). The decision rule is reject \(H_0\) if computed \(F_R>\chi _{(k-1,\alpha )}\hspace {0.2cm}\) the upper tail critical value for the \(\chi ^2\) distribution having \(k-1\) degree freedom. i.e Reject \(H_0\) if \(F_R>\chi ^2_{(k-1,\alpha )}\) otherwise do not reject \(H_0\).
