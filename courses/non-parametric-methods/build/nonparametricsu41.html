5.3 The Friedman Test

Kruskal–Wallis compares \(k\) independent samples. When the samples are related — the same subjects measured under \(k\) conditions, or \(k\) treatments applied within each of \(b\) blocks — independence fails and Kruskal–Wallis is not available. Friedman’s test is the replacement, and it stands to the two-way analysis of variance as Kruskal–Wallis stands to the one-way.

The essential step is that ranking happens within each block, not across the whole data set. Each block of \(k\) observations is ranked \(1\) to \(k\) separately, which removes the block effect entirely: a consistently generous judge or a consistently fertile plot contributes the same set of ranks as any other and cannot influence the comparison between treatments.

Let \(R_j\) be the sum of ranks for treatment \(j\) across the \(b\) blocks. Then \[\chi ^{2}_{F} = \dfrac {12}{bk(k+1)}\sum ^{k}_{j=1} R_j^{2} - 3b(k+1),\] distributed approximately as \(\chi ^{2}\) on \(k - 1\) degrees of freedom when \(b\) is reasonably large. Under \(H_0\) each treatment is equally likely to receive any rank within a block, so every \(R_j\) should be near \(b(k+1)/2\).

With ties within a block, average ranks are used and the statistic is divided by \[1 - \dfrac {\sum \left (t_p^{3} - t_p\right )}{b\left (k^{3} - k\right )},\] the sum running over all groups of tied ranks in all blocks — the same shape of correction as for Kruskal–Wallis.

For \(k = 2\) the Friedman test reduces to the sign test of Chapter 2, which is a useful check on both.
