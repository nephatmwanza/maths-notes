4.4 The K Sample K-S Statistic

Let \(X_1,X_2,\dots ,X_k\), for some \(i=1,2,\dots ,k\) be \(k\) independent samples drawn respectively from distributions with cdf \[F_i(x):\hspace {0.3cm} i=1,2,\dots ,k\] Let \(\widehat {F}_i(X)\) denote the edf of the \(i^{th}\) sample.
To test \(H_0\) that \(F_i(X)\) are identical \[H_0:F_1(x)=F_2(x)=\dots =F_n(x)\hspace {0.4cm}\text {vs}\hspace {0.4cm} H_a:F_1(x)\geq F_2(x)\geq \dots \geq F_k(x)\] The test statistic is computed as follows \[D^+(k,n)=\sup _{x:i<k}\Big \{\widehat {F}_i(x)-F_{i+1}(x)\Big \}\] in the similar fashion to test for ........ \[D^-(k,n)=\sup _{x:i<k}\Big \{\widehat {F}_{i+1}(x)-\widehat {F}_i(x)\Big \}\]

Example
A random sample of \(n=8\) people yields the following counts of the number of times they swarm in the past month \(0\hspace {0.4cm}1\hspace {0.4cm}2\hspace {0.4cm}2\hspace {0.4cm}4\hspace {0.4cm}6\hspace {0.4cm}6\hspace {0.4cm}7\)

Calculate the empirical distribution function \(F_n(x)\).

Solution \begin {align*} P(x<0)=F_n(x) &=\frac {1}{8}\hspace {0.5cm} 0\leq x<1\hspace {0.3cm} F_n(0)\\\\ P(x=0)=F_n(x) &=\frac {2}{8}\hspace {0.5cm} 1\leq x<2\hspace {0.3cm} F_(1)\\\\ P(x\leq 1)=F_n(x) &=\frac {4}{8}\hspace {0.5cm} 2\leq x<4\hspace {0.3cm} F_n(2)\\\\ P(x\leq 2)=F_n(x) &=\frac {5}{8}\hspace {0.5cm} 4\leq x<6\hspace {0.3cm} F_n(4)\\\\ P(x\leq 4)=F_n(x) &=\frac {7}{8}\hspace {0.5cm}6\leq x<7\hspace {0.3cm} F_n(6)\\\\ P(x\leq 6)=F_n(x) &=\frac {8}{8}=1\hspace {0.4cm} x\geq 7\hspace {0.3cm} F(7).\\ \end {align*}

\[ F_n(x)= \begin {cases} 0,& x<0\\ 1/8, &x\leq 0\\ 2/8, &x\leq 1\\ 4/8, &x\leq 2\\ 5/8, &x\leq 4\\ 7/8, &x\leq 6\\ 8/8, &x\geq 7\\ \end {cases} \]

We observe the following \(n=8\) data points; \(1.41\hspace {0.4cm} 0.26\hspace {0.4cm}1.97\hspace {0.4cm}0.33\hspace {0.4cm}0.55\hspace {0.4cm}0.77\hspace {0.4cm}1.46\hspace {0.4cm} 1.18\)

Is there evidence that the data was not randomly sampled uniformly \((0,2)\) distribution \begin {align*} f(x) &=\frac {1}{b-a} =\frac {1}{2}\hspace {0.5cm}\text {for}\hspace {0.4cm} x\in (0,2)\\ \end {align*}

To find \(\displaystyle {F(x) =P(X\leq x) =\int \limits ^x_0\frac {1}{2}\,dx =\frac {x}{2}}\)

cdf: \(F(x)=\dfrac {x}{2}\), \(0<x<2\)

\[F_0(x_{(i)})=F(x_i)=\frac {x}{2}\] \[D^+_n=F_n-F_0\hspace {0.5cm}\text {and}\hspace {0.5cm} D^-_n=F_0-F_{n-1}\]

\[\max D^+_n=0.145\] \[\max D_n^-=0.130\] \begin {align*} D_n &=\max \{D^+_n,D^-_n\}\\ &=\max \{0.145,0.130\}\\ &=0.145\\ \end {align*}

Note that \(n=8\) \begin {align*} \text {at}\hspace {0.5cm} \alpha =0.05\hspace {1cm} D_n(\alpha ) &=D_8(0.05)\\ &=0.45427\\ &\approx 0.454\\ \end {align*}

\(\rightarrow \)
Reject \(H_0\) if \(D_8>D_8(0.05)\).
\(\rightarrow \)
