2.20 Practice Problems

Problem 2.20.1. Evaluate \(\hspace {0.2cm}\displaystyle {\lim _{x\rightarrow 0}\frac {\tan x - x}{x^3}}\).

Show solution

Solution. Both numerator and denominator tend to \(0\), so the limit is of the form \(\dfrac {0}{0}\) and l’Hôpital’s rule applies. Differentiating, \[\lim _{x\rightarrow 0}\frac {\sec ^2x - 1}{3x^2} = \lim _{x\rightarrow 0}\frac {\tan ^2 x}{3x^2} = \frac {1}{3}\lim _{x\rightarrow 0}\Big (\frac {\tan x}{x}\Big )^2 = \frac {1}{3}(1)^2 = \frac {1}{3},\] using \(\sec ^2x - 1 = \tan ^2 x\) and the standard limit \(\dfrac {\tan x}{x}\rightarrow 1\). Recognising the identity avoids two further applications of the rule.

Problem 2.20.2. Evaluate \(\hspace {0.2cm}\displaystyle {\lim _{x\rightarrow \infty } x^{1/x}}\).

Show solution

Solution. This is of the indeterminate form \(\infty ^0\), which must first be converted to a quotient. Let \(y = x^{1/x}\) and take logarithms: \[\ln y = \frac {\ln x}{x}.\] As \(x\rightarrow \infty \) this is of the form \(\dfrac {\infty }{\infty }\), so by l’Hôpital’s rule \[\lim _{x\rightarrow \infty }\frac {\ln x}{x} = \lim _{x\rightarrow \infty }\frac {1/x}{1} = 0 .\] Since \(\ln y \rightarrow 0\) and the exponential is continuous, \(y\rightarrow e^0 = 1\). Hence the limit is \(1\).

Problem 2.20.3. Use the mean value theorem to show that \(\left |\sin a - \sin b\right | \leq \left |a - b\right |\) for all real \(a, b\).

Show solution

Solution. If \(a = b\) the statement is trivial, so suppose \(a \neq b\). The function \(f(x) = \sin x\) is continuous on the closed interval with endpoints \(a\) and \(b\) and differentiable on its interior, so the mean value theorem gives a point \(c\) strictly between them with \[\frac {\sin a - \sin b}{a - b} = f'(c) = \cos c .\] Taking absolute values and using \(\left |\cos c\right | \leq 1\), \[\frac {\left |\sin a - \sin b\right |}{\left |a - b\right |} = \left |\cos c\right | \leq 1 ,\] and multiplying through by \(\left |a-b\right |\) gives the result.

This is the standard way the mean value theorem is used: it converts a bound on the derivative, which is local information, into a bound on how much the function itself can change, which is global.

Problem 2.20.4. Determine whether \(\displaystyle {\sum _{n=1}^{\infty }\frac {n}{2^n}}\) converges, and if so find its sum.

Show solution

Solution.

Convergence

Apply the ratio test with \(a_n = \dfrac {n}{2^n}\): \[\frac {a_{n+1}}{a_n} = \frac {n+1}{2^{n+1}}\cdot \frac {2^n}{n} = \frac {1}{2}\cdot \frac {n+1}{n} \longrightarrow \frac {1}{2} < 1 ,\] so the series converges.

The sum

Start from the geometric series \(\displaystyle {\sum _{n=0}^{\infty }x^n = \frac {1}{1-x}}\) for \(\left |x\right |<1\). Differentiating both sides term by term, \[\sum _{n=1}^{\infty }nx^{n-1} = \frac {1}{(1-x)^2} \hspace {0.5cm}\implies \hspace {0.5cm} \sum _{n=1}^{\infty }nx^{n} = \frac {x}{(1-x)^2}.\] Putting \(x = \dfrac {1}{2}\), \[\sum _{n=1}^{\infty }\frac {n}{2^n} = \frac {1/2}{(1/2)^2} = \frac {1/2}{1/4} = 2 .\]

Problem 2.20.5. Find the interval of convergence of \(\displaystyle {\sum _{n=1}^{\infty }\frac {(x-2)^n}{n\,3^n}}\).

Show solution

Solution. By the ratio test, \[\left |\frac {a_{n+1}}{a_n}\right | = \frac {\left |x-2\right |^{n+1}}{(n+1)3^{n+1}}\cdot \frac {n\,3^n}{\left |x-2\right |^n} = \frac {\left |x-2\right |}{3}\cdot \frac {n}{n+1} \longrightarrow \frac {\left |x-2\right |}{3}.\] The series converges when this is less than \(1\), that is \(\left |x - 2\right | < 3\), so the radius of convergence is \(3\) and the open interval is \(-1 < x < 5\). The endpoints must be tested separately.

At \(x = 5\) the series is \(\displaystyle {\sum \frac {1}{n}}\), the harmonic series, which diverges. At \(x = -1\) it is \(\displaystyle {\sum \frac {(-1)^n}{n}}\), which converges by the alternating series test since \(\dfrac {1}{n}\) decreases to \(0\).

The interval of convergence is therefore \(\hspace {0.2cm}[-1, 5)\).

Problem 2.20.6. Find the curvature of \(y = x^2\) at the origin, and the radius of the circle of curvature there.

Show solution

Solution. For a curve \(y = f(x)\), \[K = \frac {\left |y''\right |}{\Big (1 + (y')^2\Big )^{3/2}}.\] Here \(y' = 2x\) and \(y'' = 2\), so \[K = \frac {2}{\big (1 + 4x^2\big )^{3/2}} .\] At \(x = 0\) this gives \(K = 2\), and the radius of curvature is \(\rho = \dfrac {1}{K} = \dfrac {1}{2}\).

The circle of curvature at the origin therefore has radius \(\frac 12\) and centre on the axis of symmetry at \(\Big (0, \dfrac {1}{2}\Big )\). Note that \(K\) is largest at the origin and decreases as \(\left |x\right |\) grows, which matches the parabola flattening out away from its vertex.
