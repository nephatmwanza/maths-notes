Practice Problems

Problem 3.12.1. Evaluate \(\hspace {0.2cm}\displaystyle {\int x^2e^{2x}\,dx}\).

Show solution

Solution. Integrate by parts twice, each time differentiating the polynomial. Take \(u = x^2\), \(dv = e^{2x}dx\), so \(du = 2x\,dx\) and \(v = \dfrac {e^{2x}}{2}\): \[\int x^2e^{2x}dx = \frac {x^2e^{2x}}{2} - \int xe^{2x}dx .\] For the remaining integral take \(u = x\), \(dv = e^{2x}dx\): \[\int xe^{2x}dx = \frac {xe^{2x}}{2} - \int \frac {e^{2x}}{2}dx = \frac {xe^{2x}}{2} - \frac {e^{2x}}{4}.\] Therefore \[\int x^2e^{2x}dx = \frac {x^2e^{2x}}{2} - \frac {xe^{2x}}{2} + \frac {e^{2x}}{4} + c = \frac {e^{2x}}{4}\Big (2x^2 - 2x + 1\Big ) + c .\]

Problem 3.12.2. Evaluate \(\hspace {0.2cm}\displaystyle {\int \sin ^3x\cos ^2x\,dx}\).

Show solution

Solution. The power of \(\sin \) is odd, so substitute \(u = \cos x\), \(du = -\sin x\,dx\), and split off one factor of \(\sin x\): \[\int \sin ^3x\cos ^2x\,dx = \int \sin ^2x\cos ^2x\cdot \sin x\,dx = \int \big (1 - \cos ^2x\big )\cos ^2x\cdot \sin x\,dx .\] Substituting, \[= -\int \big (1 - u^2\big )u^2\,du = \int \big (u^4 - u^2\big )du = \frac {u^5}{5} - \frac {u^3}{3} + c .\] Hence \[\int \sin ^3x\cos ^2x\,dx = \frac {\cos ^5x}{5} - \frac {\cos ^3x}{3} + c .\]

Problem 3.12.3. Evaluate \(\hspace {0.2cm}\displaystyle {\int \frac {dx}{x^2\sqrt {x^2 + 4}}}\) for \(x>0\).

Show solution

Solution. The integrand contains \(\sqrt {x^2 + a^2}\) with \(a = 2\), so substitute \(x = 2\tan \theta \), giving \(dx = 2\sec ^2\theta \,d\theta \) and \(\sqrt {x^2+4} = 2\sec \theta \). Then \[\int \frac {2\sec ^2\theta \,d\theta }{4\tan ^2\theta \cdot 2\sec \theta } = \frac {1}{4}\int \frac {\sec \theta }{\tan ^2\theta }d\theta = \frac {1}{4}\int \frac {\cos \theta }{\sin ^2\theta }d\theta .\] With \(w = \sin \theta \) this is \[\frac {1}{4}\int \frac {dw}{w^2} = -\frac {1}{4w} + c = -\frac {1}{4\sin \theta } + c .\] From the substitution triangle, \(\sin \theta = \dfrac {x}{\sqrt {x^2+4}}\), so \[\int \frac {dx}{x^2\sqrt {x^2+4}} = -\frac {\sqrt {x^2+4}}{4x} + c .\]

Problem 3.12.4. Evaluate \(\hspace {0.2cm}\displaystyle {\int \frac {3x + 5}{(x-1)\big (x^2+1\big )}dx}\).

Show solution

Solution. The denominator has a linear factor and an irreducible quadratic, so write \[\frac {3x+5}{(x-1)(x^2+1)} = \frac {A}{x-1} + \frac {Bx + C}{x^2+1}.\] Multiplying up, \(3x + 5 = A(x^2+1) + (Bx+C)(x-1)\). Putting \(x = 1\) gives \(8 = 2A\), so \(A = 4\). Comparing coefficients of \(x^2\) gives \(0 = A + B\), so \(B = -4\); comparing constants gives \(5 = A - C\), so \(C = -1\). Hence \[\int \left [\frac {4}{x-1} - \frac {4x + 1}{x^2+1}\right ]dx = 4\ln \left |x-1\right | - 2\ln \big (x^2+1\big ) - \tan ^{-1}x + c ,\] splitting the middle term as \(\dfrac {4x}{x^2+1} + \dfrac {1}{x^2+1}\) and integrating each separately.

Problem 3.12.5. Find the length of the curve \(y = x^{3/2}\) from \(x = 0\) to \(x = 4\).

Show solution

Solution. \[\frac {dy}{dx} = \frac {3}{2}x^{1/2} \hspace {0.5cm}\implies \hspace {0.5cm} 1 + \Big (\frac {dy}{dx}\Big )^2 = 1 + \frac {9x}{4}.\] Hence \[S = \int _0^4\sqrt {1 + \frac {9x}{4}}\,dx = \left [\frac {8}{27}\Big (1 + \frac {9x}{4}\Big )^{3/2}\right ]_0^4 = \frac {8}{27}\Big (10^{3/2} - 1\Big ) .\] Numerically this is \(\dfrac {80\sqrt {10} - 8}{27} \approx 9.07\), which is plausible: the straight-line distance from \((0,0)\) to \((4,8)\) is \(\sqrt {80}\approx 8.94\), and the curve must be slightly longer.

Problem 3.12.6. Find the area of the surface generated by revolving \(y = x^3\), for \(0\leq x\leq 1\), about the \(x-\)axis.

Show solution

Solution. \[S = \int _0^1 2\pi y\sqrt {1 + \Big (\frac {dy}{dx}\Big )^2}\,dx = 2\pi \int _0^1 x^3\sqrt {1 + 9x^4}\,dx .\] Substitute \(u = 1 + 9x^4\), so \(du = 36x^3dx\) and \(x^3dx = \dfrac {du}{36}\). When \(x = 0\), \(u = 1\); when \(x = 1\), \(u = 10\). Then \[S = 2\pi \int _1^{10}\frac {\sqrt {u}}{36}du = \frac {\pi }{18}\left [\frac {2}{3}u^{3/2}\right ]_1^{10} = \frac {\pi }{27}\Big (10\sqrt {10} - 1\Big ) \approx 3.56 .\]
