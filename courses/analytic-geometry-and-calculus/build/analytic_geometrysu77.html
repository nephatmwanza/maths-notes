6.4 Practice Problems

Problem 6.4.1. Solve \(\hspace {0.2cm}\dfrac {dy}{dx} = x\big (1 + y^2\big )\).

Show solution

Solution. The variables separate: \[\frac {dy}{1 + y^2} = x\,dx .\] Integrating both sides, \[\tan ^{-1}y = \frac {x^2}{2} + c \hspace {0.5cm}\implies \hspace {0.5cm} y = \tan \Big (\frac {x^2}{2} + c\Big ).\]

Problem 6.4.2. Solve \(\hspace {0.2cm}\dfrac {dy}{dx} + \dfrac {2y}{x} = \dfrac {\cos x}{x^2}\).

Show solution

Solution. This is linear with \(P(x) = \dfrac {2}{x}\), so the integrating factor is \[\mu = e^{\int \frac {2}{x}dx} = e^{2\ln x} = x^2 .\] Multiplying through by \(x^2\) makes the left side an exact derivative: \[x^2\frac {dy}{dx} + 2xy = \cos x \hspace {0.5cm}\implies \hspace {0.5cm} \frac {d}{dx}\big (x^2y\big ) = \cos x .\] Integrating, \[x^2y = \sin x + c \hspace {0.5cm}\implies \hspace {0.5cm} y = \frac {\sin x + c}{x^2}.\]

Problem 6.4.3. Solve \(\hspace {0.2cm}\big (y\cos x + 2xe^y\big )dx + \big (\sin x + x^2e^y + 2\big )dy = 0\).

Show solution

Solution. With \(M = y\cos x + 2xe^y\) and \(N = \sin x + x^2e^y + 2\), \[\frac {\partial M}{\partial y} = \cos x + 2xe^y = \frac {\partial N}{\partial x},\] so the equation is exact. Integrating \(M\) with respect to \(x\), \[f(x,y) = y\sin x + x^2e^y + g(y).\] Differentiating with respect to \(y\) and comparing with \(N\), \[\sin x + x^2e^y + g'(y) = \sin x + x^2e^y + 2 \implies g'(y) = 2 \implies g(y) = 2y .\] Hence the solution is \[y\sin x + x^2e^y + 2y = C .\]

Problem 6.4.4. Solve the Bernoulli equation \(\hspace {0.2cm}\dfrac {dy}{dx} + y = xy^3\).

Show solution

Solution. Here \(n = 3\), so put \(v = y^{1-n} = y^{-2}\), giving \(\dfrac {dv}{dx} = -2y^{-3}\dfrac {dy}{dx}\). Dividing the equation by \(y^3\), \[y^{-3}\frac {dy}{dx} + y^{-2} = x ,\] and substituting, \[-\frac {1}{2}\frac {dv}{dx} + v = x \hspace {0.5cm}\implies \hspace {0.5cm} \frac {dv}{dx} - 2v = -2x ,\] which is linear with integrating factor \(e^{-2x}\): \[\frac {d}{dx}\Big (ve^{-2x}\Big ) = -2xe^{-2x} .\] Integrating the right side by parts, \[\int -2xe^{-2x}dx = xe^{-2x} + \frac {1}{2}e^{-2x} ,\] so \(ve^{-2x} = xe^{-2x} + \dfrac {1}{2}e^{-2x} + C\) and \[v = x + \frac {1}{2} + Ce^{2x} .\] Since \(v = y^{-2}\), \[y^{-2} = x + \frac {1}{2} + Ce^{2x} \hspace {0.5cm}\text {or}\hspace {0.5cm} y = \frac {1}{\sqrt {x + \frac {1}{2} + Ce^{2x}}} .\]

Problem 6.4.5. Solve \(\hspace {0.2cm}\dfrac {d^2y}{dx^2} + 4y = \sin 2x\).

Show solution

Solution.

Complementary function

The auxiliary equation is \(m^2 + 4 = 0\), with roots \(m = \pm 2i\), so \[y_c = A\cos 2x + B\sin 2x .\]

Particular integral

The forcing term \(\sin 2x\) already appears in \(y_c\), so the trial solution must be multiplied by \(x\). Try \[y_p = x\big (C\cos 2x + D\sin 2x\big ).\] Differentiating twice, \[y_p'' = -4x\big (C\cos 2x + D\sin 2x\big ) + 4\big (-C\sin 2x + D\cos 2x\big ),\] so \[y_p'' + 4y_p = 4\big (-C\sin 2x + D\cos 2x\big ) = \sin 2x .\] Comparing coefficients, \(4D = 0\) and \(-4C = 1\), giving \(D = 0\) and \(C = -\dfrac {1}{4}\). Hence \(y_p = -\dfrac {x}{4}\cos 2x\) and \[y = A\cos 2x + B\sin 2x - \frac {x}{4}\cos 2x .\] The \(x\) terms cancelled identically in \(y_p'' + 4y_p\), which is the signature of the resonant case and confirms the trial form was correct.

Problem 6.4.6. Use a power series to solve \(\hspace {0.2cm}\dfrac {dy}{dx} = 2xy\), and identify the solution.

Show solution

Solution. Put \(\displaystyle {y = \sum _{n=0}^{\infty }a_nx^n}\), so that \(\displaystyle {\frac {dy}{dx} = \sum _{n=0}^{\infty }(n+1)a_{n+1}x^{n}}\) and \(\displaystyle {2xy = \sum _{n=1}^{\infty }2a_{n-1}x^{n}}\).

Comparing coefficients of \(x^0\) gives \(a_1 = 0\), and for \(n\geq 1\), \[(n+1)a_{n+1} = 2a_{n-1} \hspace {0.5cm}\implies \hspace {0.5cm} a_{n+1} = \frac {2a_{n-1}}{n+1} .\] Since \(a_1 = 0\), every odd coefficient vanishes. For the even ones, \[a_2 = a_0,\qquad a_4 = \frac {2a_2}{4} = \frac {a_0}{2},\qquad a_6 = \frac {2a_4}{6} = \frac {a_0}{6},\qquad a_8 = \frac {2a_6}{8} = \frac {a_0}{24}.\] Therefore \[y = a_0\left (1 + x^2 + \frac {x^4}{2} + \frac {x^6}{6} + \frac {x^8}{24} + \cdots \right ) = a_0\sum _{k=0}^{\infty }\frac {\big (x^2\big )^k}{k!} = a_0e^{x^2}.\] This agrees with separating the variables directly: \(\dfrac {dy}{y} = 2x\,dx\) gives \(\ln y = x^2 + c\), that is \(y = a_0e^{x^2}\).
