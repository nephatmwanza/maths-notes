Practice Problems

Problem 5.12.1. Show that \(\displaystyle {\lim _{(x,y)\rightarrow (0,0)}\frac {xy}{x^2+y^2}}\) does not exist.

Show solution

Solution. Approach the origin along the line \(y = mx\), which passes through it for every value of \(m\). Along this line, for \(x \neq 0\), \[\frac {xy}{x^2+y^2} = \frac {x(mx)}{x^2 + m^2x^2} = \frac {mx^2}{x^2\big (1 + m^2\big )} = \frac {m}{1 + m^2}.\] The value is constant along each line but depends on \(m\): along \(y = 0\) it is \(0\), while along \(y = x\) it is \(\dfrac {1}{2}\).

Since different paths of approach give different values, no single limit exists.

This is the essential difference from one variable, where only two directions of approach are available. Here a function can be perfectly well behaved along every straight line and still fail to have a limit.

Problem 5.12.2. If \(z = x^2y\) with \(x = \cos t\) and \(y = \sin t\), find \(\dfrac {dz}{dt}\) by the chain rule.

Show solution

Solution. The chain rule for a function of two variables each depending on \(t\) is \[\frac {dz}{dt} = \frac {\partial z}{\partial x}\frac {dx}{dt} + \frac {\partial z}{\partial y}\frac {dy}{dt}.\] Here \(\dfrac {\partial z}{\partial x} = 2xy\) and \(\dfrac {\partial z}{\partial y} = x^2\), while \(\dfrac {dx}{dt} = -\sin t\) and \(\dfrac {dy}{dt} = \cos t\). Hence \[\frac {dz}{dt} = 2xy(-\sin t) + x^2\cos t = -2\cos t\sin ^2 t + \cos ^3 t = \cos t\big (1 - 3\sin ^2t\big ),\] using \(\cos ^2t = 1 - \sin ^2t\) in the last step. Direct substitution \(z = \cos ^2t\sin t\) followed by differentiation gives the same result.

Problem 5.12.3. The radius of a cylinder is measured as \(5\) cm with a possible error of \(0.1\) cm, and its height as \(12\) cm with a possible error of \(0.2\) cm. Use the total differential to estimate the greatest possible error in the calculated volume.

Show solution

Solution. The volume is \(V = \pi r^2h\), so \[dV = \frac {\partial V}{\partial r}dr + \frac {\partial V}{\partial h}dh = 2\pi rh\,dr + \pi r^2dh .\] Substituting \(r = 5\), \(h = 12\), \(dr = 0.1\) and \(dh = 0.2\), \[dV = 2\pi (5)(12)(0.1) + \pi (25)(0.2) = 12\pi + 5\pi = 17\pi \approx 53.4\ \text {cm}^3 .\] For comparison \(V = \pi (25)(12) = 300\pi \), so the relative error is \(\dfrac {17}{300} \approx 5.7\%\) — appreciably larger than either input error, because the radius enters squared and so its error counts twice over.

Problem 5.12.4. Find and classify the critical points of \(f(x,y) = x^3 + y^3 - 3xy\).

Show solution

Solution.

Locating them

\[f_x = 3x^2 - 3y = 0 \implies y = x^2,\qquad f_y = 3y^2 - 3x = 0 \implies x = y^2 .\] Substituting the first into the second, \(x = x^4\), so \(x(x^3 - 1) = 0\) and \(x = 0\) or \(x = 1\). The critical points are \((0,0)\) and \((1,1)\).

Classifying them

The second partials are \(f_{xx} = 6x\), \(f_{yy} = 6y\) and \(f_{xy} = -3\), so the discriminant is \[D = f_{xx}f_{yy} - \big (f_{xy}\big )^2 = 36xy - 9 .\] At \((0,0)\): \(D = -9 < 0\), so the point is a saddle.

At \((1,1)\): \(D = 36 - 9 = 27 > 0\) and \(f_{xx} = 6 > 0\), so the point is a local minimum, with value \(f(1,1) = 1 + 1 - 3 = -1\).

Problem 5.12.5. Find the equation of the tangent plane to \(z = x^2 + y^2\) at the point \((1,2,5)\).

Show solution

Solution. The tangent plane to \(z = f(x,y)\) at \((x_0,y_0)\) is \[z = f(x_0,y_0) + f_x(x_0,y_0)(x - x_0) + f_y(x_0,y_0)(y - y_0).\] Here \(f_x = 2x\) and \(f_y = 2y\), so at \((1,2)\) we have \(f_x = 2\), \(f_y = 4\) and \(f(1,2) = 5\). Hence \[z = 5 + 2(x-1) + 4(y-2) = 2x + 4y - 5 .\]

Problem 5.12.6. Verify Euler’s theorem for the function \(f(x,y) = x^3 + x^2y + y^3\).

Show solution

Solution. First check homogeneity. Replacing \(x\) by \(tx\) and \(y\) by \(ty\), \[f(tx,ty) = t^3x^3 + t^3x^2y + t^3y^3 = t^3f(x,y),\] so \(f\) is homogeneous of degree \(n = 3\). Euler’s theorem asserts that \[x\frac {\partial f}{\partial x} + y\frac {\partial f}{\partial y} = nf .\] Computing the partials, \[f_x = 3x^2 + 2xy,\qquad f_y = x^2 + 3y^2 ,\] so \[xf_x + yf_y = 3x^3 + 2x^2y + x^2y + 3y^3 = 3x^3 + 3x^2y + 3y^3 = 3\big (x^3 + x^2y + y^3\big ) = 3f ,\] which is the assertion with \(n = 3\).
