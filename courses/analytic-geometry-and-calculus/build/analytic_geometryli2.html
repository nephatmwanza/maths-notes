Practice Problems

Problem 1.9.1. Discuss the curve \(\hspace {0.2cm} 9x^2 + 25y^2 - 90x - 150y + 225 = 0\).

Show solution

Solution. Group and complete the square in each variable: \[9\big (x^2 - 10x\big ) + 25\big (y^2 - 6y\big ) = -225\] \[9\big [(x-5)^2 - 25\big ] + 25\big [(y-3)^2 - 9\big ] = -225\] \[9(x-5)^2 + 25(y-3)^2 = -225 + 225 + 225 = 225 .\] Dividing by \(225\), \[\frac {(x-5)^2}{25} + \frac {(y-3)^2}{9} = 1 .\] Both terms are positive, so this is an ellipse with centre \((5,3)\). Here \(a = 5\) and \(b = 3\), so \(c^2 = a^2 - b^2 = 16\) and \(c = 4\). The major axis is horizontal, so the vertices are \((5\pm 5, 3)\), that is \((0,3)\) and \((10,3)\); the foci are \((5\pm 4, 3)\), that is \((1,3)\) and \((9,3)\); and the eccentricity is \(e = \dfrac {c}{a} = \dfrac {4}{5}\).

Problem 1.9.2. Discuss the curve \(\hspace {0.2cm} 16y^2 - 9x^2 - 64y - 54x = 161\).

Show solution

Solution. \[16\big (y^2 - 4y\big ) - 9\big (x^2 + 6x\big ) = 161\] \[16\big [(y-2)^2 - 4\big ] - 9\big [(x+3)^2 - 9\big ] = 161\] \[16(y-2)^2 - 9(x+3)^2 = 161 + 64 - 81 = 144 .\] Dividing by \(144\), \[\frac {(y-2)^2}{9} - \frac {(x+3)^2}{16} = 1 .\] The signs differ, so this is a hyperbola with centre \((-3,2)\). The positive term is in \(y\), so it opens along the vertical direction — note that this is decided by the sign, not by the sizes of \(9\) and \(16\). With \(a = 3\) and \(b = 4\), \[c^2 = a^2 + b^2 = 9 + 16 = 25 \implies c = 5 .\] The vertices are \((-3, 2\pm 3)\), the foci are \((-3, 2\pm 5)\), the asymptotes are \(y - 2 = \pm \dfrac {3}{4}(x+3)\), and \(e = \dfrac {5}{3}\).

Problem 1.9.3. Derive the equation of the parabola with focus \((4,5)\) and directrix \(y = -1\).

Show solution

Solution. A point \(P(x,y)\) lies on the parabola when its distance to the focus equals its distance to the directrix: \[\sqrt {(x-4)^2 + (y-5)^2} = \left |y + 1\right | .\] Squaring both sides, \[(x-4)^2 + (y-5)^2 = (y+1)^2\] \[x^2 - 8x + 16 + y^2 - 10y + 25 = y^2 + 2y + 1\] \[x^2 - 8x + 40 = 12y .\] Hence \[y = \frac {x^2 - 8x + 40}{12},\] or in standard form, completing the square, \((x-4)^2 = 12(y - 2)\). The vertex is \((4,2)\), midway between the focus and the directrix, as it must be.

Problem 1.9.4. Use a rotation of axes to identify the curve \(\hspace {0.2cm} 7x^2 - 18xy + 7y^2 = 24\).

Show solution

Solution. Here \(A = 7\), \(B = -18\), \(C = 7\). First, \[B^2 - 4AC = 324 - 196 = 128 > 0 ,\] so the curve is a hyperbola. The rotation angle satisfies \[\cot 2\theta = \frac {A - C}{B} = \frac {0}{-18} = 0 \implies 2\theta = \frac {\pi }{2} \implies \theta = \frac {\pi }{4} .\] With \(x = \dfrac {X - Y}{\sqrt 2}\) and \(y = \dfrac {X + Y}{\sqrt 2}\), \[7\cdot \frac {(X-Y)^2}{2} - 18\cdot \frac {(X-Y)(X+Y)}{2} + 7\cdot \frac {(X+Y)^2}{2} = \frac {-4X^2 + 32Y^2}{2} = -2X^2 + 16Y^2 .\] So the equation becomes \(-2X^2 + 16Y^2 = 24\), that is \[\frac {Y^2}{\frac {3}{2}} - \frac {X^2}{12} = 1 ,\] a hyperbola opening along the \(Y-\)axis, which is the line \(y = x\) in the original coordinates.

Problem 1.9.5. Identify the conic \(\hspace {0.2cm} r = \dfrac {7}{1 - \sin \theta }\) and give its directrix.

Show solution

Solution. Compare with the standard polar form \(r = \dfrac {ep}{1 - e\sin \theta }\), which has a focus at the pole and directrix \(p\) units below it. Matching denominators gives \(e = 1\), and then the numerator gives \(ep = 7\), so \(p = 7\).

Since \(e = 1\) the conic is a parabola, with focus at the pole and directrix the horizontal line \(7\) units below the pole. In Cartesian terms the directrix is \(y = -7\), and the vertex lies midway between focus and directrix at \(\Big (0, -\dfrac {7}{2}\Big )\).

Problem 1.9.6. Find the equation of the hyperbola with foci \((\pm 2, 0)\) passing through the point \((2,3)\).

Show solution

Solution. The foci are on the \(x-\)axis, so the equation is \(\dfrac {x^2}{a^2} - \dfrac {y^2}{b^2} = 1\) with \(c = 2\), hence \(a^2 + b^2 = 4\), that is \(b^2 = 4 - a^2\). Substituting the point \((2,3)\), \[\frac {4}{a^2} - \frac {9}{4 - a^2} = 1 .\] Multiplying by \(a^2(4-a^2)\), \[4\big (4 - a^2\big ) - 9a^2 = a^2\big (4 - a^2\big )\] \[16 - 13a^2 = 4a^2 - a^4 \implies a^4 - 17a^2 + 16 = 0 \implies \big (a^2 - 1\big )\big (a^2 - 16\big ) = 0 .\] So \(a^2 = 1\) or \(a^2 = 16\). The second is impossible, since \(a^2 < c^2 = 4\) for a hyperbola. Hence \(a^2 = 1\), \(b^2 = 3\), and \[x^2 - \frac {y^2}{3} = 1 .\] Checking: \(4 - \dfrac {9}{3} = 4 - 3 = 1\), as required.
