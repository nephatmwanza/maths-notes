2.7 Uniform Convergence

When two limiting operations are performed on functions, the order in which they are carried out can make a difference. For example, let \[ f_n(x) = \begin {cases} 0, & x < 0,\\ nx, & 0\leq x \leq \frac {1}{n},\\ 1, & x> \frac {1}{n}. \end {cases} \] For each fixed \(x\), \(f_n(x)\longrightarrow f(x)\) as \(n\longrightarrow \infty \), where \[f(x) = \begin {cases} 0, & x\leq 0,\\ 1, & x>0. \end {cases}\]

Now \begin {gather*} \lim _{n\rightarrow \infty }\, \lim _{x\rightarrow 0^+} f_n(x) = \lim _{n \rightarrow \infty } 0 = 0,\\ \text {but}\qquad \lim _{x\rightarrow 0^+}\,\lim _{n\rightarrow \infty } f_n(x) = \lim _{x \rightarrow 0^+} f(x) = 1 . \end {gather*} Note also that every \(f_n\) is continuous everywhere and \(f_n(x) \longrightarrow f(x)\) for each \(x\), but the limit function \(f\) is discontinuous at \(x= 0\).

Example 2.7.1. Let \[ f_n(x) = \begin {cases} n e^{-nx}, & x>0,\\ 0, & x\leq 0. \end {cases} \] Then \(f_n(x) \longrightarrow 0\) for every \(x\), so \(f_n\) converges pointwise to \(f(x) = 0\). Now \[\int ^{\infty }_0f_n(x)\,dx = \int ^{\infty }_0 n e^{-nx}\,dx = 1 \quad \text {for every } n, \qquad \text {but}\qquad \int ^{\infty }_0 f(x)\, dx = 0 .\] Thus, although \(f_n \longrightarrow f\) pointwise, \(\int ^{\infty }_0f_n(x)\, dx\) does not converge to \(\int ^{\infty }_0f(x)\, dx\). In other words, the limit of the integrals of \(f_n\) is not the integral of the limit of \(f_n\).
