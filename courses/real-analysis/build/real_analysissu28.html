5.2 Properties of the Riemann Integral

We now consider Riemann integrable functions on a closed bounded interval \([a,b]\) and establish some of their properties.

We shall denote the set of all Riemann integrable functions on \([a,b]\) by \(R[a,b]\).

That is , we shall write \(f\in R[a,b]\) to mean that \(f\) is Riemann integrable on \([a,b]\) or \(f\) belongs to the class of Riemann integrable functions on \([a,b]\).

Theorem 5.2.1. If \(f\in R[a,b]\) and \(C\) is any real number, then \(C\, f\in R[a,b]\) and \[\int ^b_aCf \, = \, C\, \int ^b_af.\]

Proof. Since \(f\in R[a,b]\) then \(\displaystyle {\overline {\int ^b_a}f\, = \,\underline {\int ^b_a}f}\,\) and \(f\) is bounded on \([a,b]\). Now \(\left |Cf\right | = \left |C\right |\,\left |f\right |\,\) which implies that \(Cf\) is bounded on \([a,b]\). Now, for \(C = 0\), the result is obvious.
If \(C>0\), let \(P\) be a partition of \([a,b]\). Then \begin {align*} U\left (P,Cf\right ) & = \sum ^n_{k = 1}C\, M_k(f)\, \Delta x_k\\\\ & = C\, \sum ^n_{k = 1} M_k(f)\, \Delta x_k\\\\ & = C\, U\left (P,f\right ) \end {align*}

Thus \(\inf U(P,Cf) = C \inf U(P, f)\), and also \(\sup L(P, Cf) = C \sup L(P,f)\). Therefore \[\overline {\int ^b_a}Cf = \inf \left (U\left (P,Cf\right )\right ) = C\, \inf U\left (P,f\right ) = C\, \overline {\int ^b_a}f\] Since \(f\) in Riemann integrable, we have that \begin {align*} C\,\overline {\int ^b_a}f = C\,\underline {\int ^b_a}f & = C\, \sup L\left (P,f\right ) = \sup L \left (P, Cf\right ) = \underline {\int ^b_a}Cf \end {align*}

Thus \(\, \displaystyle {\overline {\int ^b_a}Cf = \underline {\int ^b_a}Cf}\,\) and \(Cf\in R[a,b]\).

Since \(\, \displaystyle {\overline {\int ^b_a}Cf = C\,\underline {\int ^b_a}f}\,\) we have \(\, \displaystyle {\int ^b_aCf \, = \, C\, \int ^b_af}\).

If \(C< 0\), then \(\, C\, M_k(f) = \inf \left \{C\,f(x):\, x\in [x_{k-1},x_k]\right \}\,\) and

\(\, C\, m_k(f) = \sup \left \{C\,f(x):\, x\in [x_{k-1},x_k]\right \}\,\) and so

\(\, \sup \left \{U\left (P,Cf\right ):\, P\in P[a,b]\right \} = C\, \inf \left \{U\left (P,f\right ):\, P\in P[a,b]\right \}\,\) and

\(\inf \left \{L\left (P,Cf\right ):\, P\in P[a,b]\right \} = C\, \sup \left \{L\left (P,f\right ):\, P\in P[a,b]\right \}.\,\) Therefore \begin {align*} \overline {\int ^b_a} Cf & = \inf \left \{L\left (P,Cf\right ):\, P\in P[a,b]\right \} = C\, \sup \left \{L\left (P,f\right ):\, P\in P[a,b]\right \}\\\\ & = C\, \underline {\int ^b_a}f = C\, \int ^b_af = C\, \overline {\int ^b_a}f\\\\ & = C\, \inf \left \{U\left (P,f\right ):\, P\in P[a,b]\right \} = \sup \left \{U\left (P,Cf\right ):\, P\in P[a,b]\right \}\\\\ & = \underline {\int ^b_a}Cf \end {align*}

Hence again \(\, Cf\in R[a,b]\,\) and \(\, \displaystyle {\int ^b_a Cf\, = \, C\, \int ^b_af}\). □

Theorem 5.2.2. If \(f\in R[a,b]\) and \(c\in [a,b]\) then \(f\in R[a,c]\) and \(f\in R[c,b]\) and conversely. In this case \[\int ^b_af \, = \,\int ^c_af \, + \, \int ^b_cf.\]

Proof. For \(c\in [a,b]\) we have that \(f\) is bounded on \([a,c]\) and on \([c,b]\) if and only if it is bounded on \([a,b]\). Since \(f\in R[a,b]\) given \(\varepsilon >0\) there exists a partition \(P\) such that \[U\left (P,f\right ) - L\left (P,f\right ) < \varepsilon \] Let \(P^* = P\cup \left \{c\right \}\,\) be a refinement of \(P\) by adding a point, then \(P^*\in [a,b]\) and \[U\left (P^*,f\right ) - L\left (P^*,f\right )\leq U\left (P,f\right ) - L\left (P,f\right ) < \varepsilon \] We break the partition \(P^*\) on \([a,b]\) to \(P_1\) on \([a,c]\) and \(P_2\) on \([c,b]\). Then we have \begin {align*} U\left (P^*,f\right ) - L\left (P^*,f\right ) & = U\left (P_1,f\right ) + U\left (P_2,f\right ) - L\left (P_1,f\right ) - L\left (P_2,f\right )\\ & = \left (U\left (P_1,f\right ) - L\left (P_1,f\right )\right ) + \left (U\left (P_2,f\right ) - L\left (P_2,f\right )\right )\\ & < \varepsilon \end {align*}

It follows that \(\, U\left (P_1,f\right ) - L\left (P_1,f\right ) < \varepsilon \,\) and \(\, U\left (P_2,f\right ) - L\left (P_2,f\right ) < \varepsilon .\,\) Thus \(f\in R[a,c]\) and \(f\in R[c,b]\).
Now it can be shown that \(\, U\left (P_1,f\right ) + U\left (P_2,f\right ) = U\left (P^*,f\right )\,\) implies that \[\inf \, U\left (P_1,f\right ) \, + \, \inf \, U\left (P_2,f\right )\, = \, \inf \, U\left (P^*,f\right )\] This then implies that \(\, \displaystyle {\int ^c_af\, + \, \int ^b_cf \, = \, \int ^b_af}.\,\)

Conversely, in \(c\in (a,b)\) and \(f\in R[a,c]\) and \(f\in R[c,d]\), then there exists partitions \(P_2\in P[a,c]\) and \(P_2\in P[c,b]\) such that \(\, U\left (P_1,f\right ) - L\left (P_1,f\right ) < \frac {\varepsilon }{2}\,\) and \(\, U\left (P_2,f\right ) - L\left (P_1,f\right )<\frac {\varepsilon }{2}\). Then for \(P= P_1\cup P_2\,\) we have \begin {align*} U\left (P,f\right ) - L\left (P,f\right ) & = U\left (P_1,f\right ) + U\left (P_2,f\right ) - L\left (P_1,f\right ) - L\left (P_2,f\right )\\ & = U\left (P_1,f\right ) - L\left (P_1,f\right ) + U\left (P_2,f\right ) - L\left (P_2,f\right )\\ & < \varepsilon \end {align*}

Hence \(f\in R[a,b]\) and the required relation of integrals follow as before. □

Corollary 5.2.3. If \(f\in [a,b]\) and \([c,c]\subset [a,b]\) then \(f\in R[c,d]\). That is if \(f\) is Riemann integrable on a closed bounded interval, then it is Riemann integrable on every closed subinterval.

Proof. Let \(\varepsilon >0\). Since \(f\in R[a,b]\), Riemann’s criterion gives a partition \(P\) of \([a,b]\) with \(U(f,P)-L(f,P)<\varepsilon \). Refine \(P\) by adjoining the points \(c\) and \(d\); refinement never increases the difference, so the refined partition \(P'\) also satisfies \(U(f,P')-L(f,P')<\varepsilon \).

Let \(Q\) be the part of \(P'\) lying in \([c,d]\), a partition of \([c,d]\). Every term of \(U(f,Q)-L(f,Q)\) appears among the terms of \(U(f,P')-L(f,P')\), and all terms are non-negative, so \[U(f,Q)-L(f,Q) \leq U(f,P')-L(f,P') < \varepsilon .\] By Riemann’s criterion again, \(f\in R[c,d]\). □

Theorem 5.2.4. Suppose that \(f,\, g\in R[a,b]\), then \(f + g\in R[a,b]\) and \[\int ^b_a\left (f + g\right ) \, = \, \int ^b_af \, + \, \int ^b_ag\]

Proof. Since \(f,\, g\in R[a,b]\), then there functions are bounded on \([a,b]\). Therefore there exists on \(M>0\) such that \(\left |f(x)\right | \leq M\) and \(\left |g(x)\right | \leq M\,\) for all \(x\in [a,b]\). Thus \[\left |f(x) + g(x)\right | \leq \left |f(x)\right | + \left |g(x)\right |\leq 2M\] for all \(x\in [a,b]\). This shows that \(\, f + g\,\) is bounded on \([a,b]\). Therefore \(\, \displaystyle {\overline {\int ^b_a}\left (f + g\right )}\,\) and \(\, \displaystyle {\underline {\int ^b_a}\left (f + g\right )}\,\) exists.

But if \(\, A\subseteq [a,b]\,\) then we have \(\, \left \{f(x) + g(x):\, x\in A\right \} \subset \left \{f(x_1) + g(x_2):\, x_1,\, x_2\in A\right \}\). Thus for any partition \(P\) of \([a,b]\), we have \(\, U\left (P,f+g\right )\leq U\left (P,f\right ) + U\left (P,g\right )\,\) and \(\, L\left (P,f+g\right )\geq L\left (P,f\right ) + L\left (P,g\right )\). Consequently, \begin {align*} \sup L\left (P,f\right ) + \sup L \left (P,g\right ) & \leq \sup L\left (P, f+g\right ) \\ & \leq \inf U\left (P,f+g\right ) \\ & \leq \inf U\left (P,f\right ) + \inf U\left (P,g\right ) \end {align*}

Thus \[\underline {\int ^b_a}f\, + \, \underline {\int ^b_a}g \, \leq \, \underline {\int ^b_a}\left (f + g\right )\, \leq \overline {\int ^b_a}\left (f+ g\right )\, \leq \,\overline {\int ^b_a}f\, + \, \overline {\int ^b_a}g\] and since \(f\) and \(g\) are Riemann integrable on \([a,b]\), we have \[\underline {\int ^b_a}f = \int ^b_af = \overline {\int ^b_a}f \qquad \text {and}\qquad \underline {\int ^b_a}g = \int ^b_a g = \overline {\int ^b_a}g,\] so that \[\int ^b_a f\, + \, \int ^b_a g\, \leq \, \int ^b_a\left (f + g\right )\, \leq \,\overline {\int ^b_a}\left (f + g\right )\, \leq \, \int ^b_af \, + \, \int ^b_a g\] This shows that all the inequalities are in fact equalities. Hence \(f + g \in R[a,b]\) and \[\int ^b_a \left (f + g\right ) \, = \, \overline {\int ^b_a}\left (f + g\right ) \, = \, \int ^b_a f \, + \, \int ^b_a g.\] □

Theorem 5.2.5. Let \(f,g\in R[a,b]\) and \(f\leq g\) on \([a,b]\), then \[\int ^b_a \leq \int ^b_ag.\]

Proof. For any partition \(P\) of \([a,b]\) we have \(\, L\left (P,f\right )\leq U\left (P,f\right ) \leq U\left (P,g\right ).\hspace {0.2cm}\) This implies that \begin {align*} &\sup _P\left \{L\left (P,f\right ) - U\left (P,g\right )\right \} \leq 0\\ \implies \hspace {0.3cm} & \sup _P\, L\left (P,f\right ) - \inf \, U\left (P,g\right ) \leq 0\\ \implies \hspace {0.3cm} &\int ^b_a f\, - \, \int ^b_a g \leq 0\\\\ \implies \hspace {0.3cm} & \int ^b_af \leq \int ^b_a g \end {align*} □

Theorem 5.2.6. Suppose that \(f,\, g\in R[a,b]\) then \(\, fg\in R[a,b]\).

Proof. Since \(f, \, g\in R[a,b]\), they are bounded on \([a,b]\). Therefore, there exists \(K> 0\, \ni \\ \, \left |fg\right | = \left |f\right |\, \left |g\right |\, = \, K^2\,\) on \([a,b]\).
This implies that \(fg\) is also bounded on \([a,b]\). Thus for any partition \(P\) of \([a,b]\) both \(U\left (P,fg\right )\) and \(L\left (P,fg\right )\) exists and are bounded We also have that for any \(\varepsilon >0\, \exists \, \) a partition \(P\) of \([a,b]\) such that \(\, U\left (P,f\right ) - L\left (P,f\right ) <\varepsilon \,\) and \(\, U\left (P,g\right ) - L\left (P,g\right )<\varepsilon \).

Let \(\, M_r(f)\, ,\, m_r(f)\, \) be bounds of \(f\) on \([x_{r-1},x_r]\)

\(\, M_r(g)\, ,\, m_r(g)\, \) be bounds of \(g\) on \([x_{r-1},x_r]\)

\(\, M_r(fg)\, ,\, m_r(fg)\, \) be bounds of \(fg\) on \([x_{r-1},x_r]\)

Then, for all \(x',\, x''\in [x_{r - 1}, x_r]\,\) we have \begin {align*} \left |fg(x'') - fg(x')\right | & = \left |g(x'')\, f(x'') - f(x') + f(x')\,g(x'') - g(x')\right |\\ & \leq \left |g(x'')\right |\, \left |f(x'') - f(x')\right | + \left |f(x')\right |\, \left |g(x'') - g(x')\right |\\ &\leq K\, \left |M_r(f) - m_r(f)\right | + K\, \left |M_r(g) - m_r(g)\right | \end {align*}

Thus \(\, \left (M_r(fg) - m_r(fg)\right )\leq K\left (M_r(f) - m_r(f)\right ) + K\left (M_r(g) - m_r(g)\right ).\,\) Hence \begin {align*} \sum ^n_{r=1}\left (M_r(fg) - m_r(fg)\right )\, \Delta x_r &\leq K\sum ^n_{r=1}\left (M_r(f) - m_r(f)\right )\, \Delta x_r \\ &\qquad + K\sum ^n_{r=1}\left (M_r(g) - m_r(g)\right )\, \Delta x_r \end {align*}

Thus \(\, U\left (P,fg\right ) - L\left (P,fg\right ) < K\, \varepsilon + K\, \varepsilon = 2K\varepsilon \,.\,\) This implies that \(fg\in R[a,b]\). □

Theorem 5.2.7. Let \(f,\, g\in R[a,b]\) and suppose that there exists \(t>0\) such that \(\left |g\right | > t\) on \([a,b]\), then \(\frac {f}{g}\in R[a,b]\).

Proof. The proof is similar to that of Theorem 5.2.6, but in this case \(\,\left |\frac {f}{g}\right |\leq \frac {K}{t}\,\) on \([a,b]\) and if \(\, M_r\left (\frac {f}{g}\right )\, ,\, m_r\left (\frac {f}{g}\right )\,\) denotes the bounds of \(\frac {f}{g}\) on \([x_{r-1}, x_r]\) then \[M_r\left (\frac {f}{g}\right ) - m_r\left (\frac {f}{g}\right ) \leq \dfrac {K}{t^2}\, \left (M_r(f) - m_r(f)\right ) \, + \, \dfrac {K}{t^2}\, \left (M_r(g) - m_r(g)\right ).\] □

Theorem 5.2.8. If \(f\in R[a,b]\) then \(\left |f\right | \in R[a,b]\) and \(\, \displaystyle {\left |\displaystyle {\int ^b_a f}\right |\, \leq \, \int ^b_a\left |f\right |}\).

Proof. Since \(f\in R[a,b],], \exists \, K\, \ni \, \left |f\right | < K\,\) on \([a,b]\) and so \(\left |f\right |\) is also bounded on \([a,b]\). Also given \(\varepsilon > 0\) there exist a partition \(P\) of \([a,b]\) such that \(\, U\left (P,f\right ) - L\left (P,f\right ) < \varepsilon \).
Let \(\, M_r(f)\, , \, m_r(f)\, ,\, M_r\left (\left |f\right |\right )\, \) and \(\, m_r\left (\left |f\right |\right )\,\) so the bounds of \(f\) and \(\left |f\right |\) respectively on \([x_{r-1},x_r]\), then for all \(x'\, , \, x''_r\in [x_{r-1},x_r]\,\) we have \(\, \left |\left |f(x'')\right | - \left |f(x')\right |\right | \leq \left |f(x'') - f(x')\right |\,\) and by taking supremum we have \(\, M_r\left (\left |f\right |\right ) - m_r\left (\left |f\right |\right ) \leq M_r(f) - m_r(f)\,.\,\) Thus \begin {align*} U\left (P,\left |f\right |\right ) - L\left (P,\left |f\right |\right ) & = \sum ^n_{r=1}\left (M_r\left (\left |f\right |\right ) - m_r\left (\left |f\right |\right )\right )\, \Delta x_r\\\\ & \leq \sum ^n_{r=1}\left (M_r(f) - m_r(f)\right )\, \Delta x_r\\\\ & = U\left (P,f\right ) - L\left (L,f\right )\\ & < \varepsilon \end {align*}

Hence \(\, \left |f\right |\in R[a,b]\,\) since \(\left |f\right |> f\,\) on \([a,b]\) we have \[\left |\displaystyle {\sum ^n_{r=1}M_r(f)\, \Delta x_r}\right |\leq \sum ^n_{r=1}M_r \, \left |f\right |\, \Delta x_r\] That is \(\, \left |U\left (P,f\right )\right |\leq U\left (P,f\right )\,\) for all the partition \(\, P\in P[a,b]\). Let \(\, \|P\| \longrightarrow 0\, \) to get \[\left |\displaystyle {\int ^b_a f}\right |\, \leq \, \int ^b_a \left |f\right |\]

□

Remark. If \(f\in R[a,b]\) and \(M\) and \(m\) are bounds of \(f\) on \([a,b]\), then \[m\,(b - a)\leq \int ^b_af \leq M\, (b-a)\]

Proof. Since \(m\leq f \leq M\) on \([a,b]\) , then for \(f\in R[a,b]\) we have \[\int ^b_a m \leq \int ^b_a f \leq \int ^b_a M\]

\[\implies \hspace {0.2cm} m\,(b - a) \leq \int ^b_a f\leq M\,(b-a)\] These inequalities also follow from the fact that \[m\, (b - a) \leq L(P , f) \leq \int ^b_a f \leq U(P , f) \leq M\, (b - a)\] for any partition \(P\).


□

Theorem 5.2.9 (Mean Value Theorem of Integrals). Suppose that \(f\) is continuous and bounded in the closed and bounded interval \([a,b]\), then there exists a number \(c\) with \(a < c < b\) such that \[\int ^b_a f(x)\,dx = (b-a)\, f(c)\]

Proof. From the above Remark; if \(M\) and \(m\) are bounds for \(f\), then \[m\, (b -a )\leq \int ^b_af(x)\, dx \leq M\, (b - a)\]

\[\implies \hspace {0.3cm} m\leq \dfrac {1}{(b - a)}\, \int ^b_af(x)\, dx \leq M\] This shows that \(\hspace {0.2cm}\displaystyle {\dfrac {1}{b - a}\,\int ^b_a f(x)\, dx}\hspace {0.2cm}\) is a value between \(m\) and \(M\) of a continuous function on \([a,b]\). Therefore, by the intermediate value theorem for continuous functions on \([a,b]\, f\) takes this value at some point \(c\in c[a,b]\). Thus \(\hspace {0.2cm}\displaystyle {\dfrac {1}{b - a}\, \int ^b_a f(x) \,dx = f(c)}\hspace {0.1cm}\) for some \(c\) in \([a,b]\). Hence \[\int ^b_af(x)\, dx = (b - a)\, f(c)\]

□

Theorem 5.2.10 (Generalized Mean Value Theorem for Integrals). Suppose that \(f,\, g\) are continuous on \([a,b]\) and \(g(x)\geq 0\) for all \(x\in [a,b]\), then there exist a point \(c\in (a,b)\ni \) \[\int ^b_af(x)\, g(x) \, dx = f(c)\, \int ^b_ag(x)\, dx\]

Proof. Let \(m\) and \(M\) be bounds of \(f\) in \([a,b]\), then \(m\leq f(x) \leq M\) for all \(x\in [a,b]\). Since \(g(x)\geq 0\) for all \(x\in [a,b]\), we have \(\, m\, g(x) \leq f(x)\, g(x) \leq M\, g(x)\,\) for all \(x\in [a,b]\). This implies that \[m\, \int ^b_ag(x)\, dx \leq \int ^b_af(x)\, g(x)\, dx \leq M\, \int ^b_ag(x)\,dx\] Thus, there is a number \(\mu \) with \(\, m\leq \mu \leq M\,\) such that \[\int ^b_af(x)\, g(x)\, dx = \mu \, \int ^b_ag(x)\, dx\] But since \(f\) is continuous on \([a,b]\), by the Intermediate Value Theorem there exists \(c\in [a,b]\) such that \(f(c) = \mu \). This implies that \[\int ^b_af(x)\, g(x)\, dx = f(c)\, \int ^b_ag(x)\,dx\hspace {0.5cm}\text {as required}\]

□

Example 5.2.11. Find a point \(c\) in \([0,1]\) such that \(\hspace {0.2cm}\displaystyle {\int ^1_0 \dfrac {x}{1 + x^2}\,dx = 1}\)

Solution. Let \(f(x) = x\) and \(g(x) = \dfrac {1}{1 + x^2}\). Then \(f\) and \(g\) satisfy the condition of the Generalized Mean Value Theorem. Therefore, there exists a point \(c\in [0,1]\) such that \begin {align*} \int ^1_0x\,\left (\dfrac {1}{1 + x^2}\right )\, dx & = f(c)\, \int ^1_0\dfrac {1}{1 + x^2}\, dx\\\\ & = c\, \int ^1_0\dfrac {1}{1 + x^2}\, dx \end {align*}

But \(\hspace {0.2cm} \displaystyle {\int ^1_0\dfrac {1}{1 + x^2}\, dx = \left .\tan ^{-1}(x)\right |^1_0 = \tan ^{-1}(1) - \tan ^{-1}(0) = \dfrac {\pi }{4} - 0 = \dfrac {\pi }{4}}\hspace {0.2cm}\) and also

\(\displaystyle {\int ^1_0\dfrac {x}{1 + x^2}\, dx = \left .\dfrac {1}{2}\, \ln (1 + x^2)\right |^1_0 = \dfrac {1}{2}\, \ln (2)}\)

Thus \(\hspace {0.3cm}\dfrac {1}{2}\, \ln (2) = \dfrac {\pi }{4}\, c\implies c = \dfrac {2}{\pi }\, \ln (2)\)
