1.3 Open Sets

Definition 1.3.1. Let \(A\) be a subset of \(\mathbb {R}\). A point \(x\in \mathbb {R}\) is said to be an interior point of \(A\) if there exists \(\varepsilon > 0\) such that \(( x - \varepsilon , x + \varepsilon ) \subseteq A\), that is, if \(A\) is a neighbourhood of \(x\).

The set of interior points of \(A\), denoted by \(A^0\), is called the interior of \(A\).

Note.

1.
\(A^0\) is the set of all points of which \(A\) is a neighbourhood, and \(A^0 \subseteq A\).
2.
By Theorem 1.2.15(iv), \(x \in \overline {A}\) if and only if \((x - \varepsilon , x + \varepsilon ) \cap A \neq \emptyset \) for every \(\varepsilon > 0\). Hence \(x\notin \overline {A}\) if and only if there exists \(\varepsilon > 0\) with \((x - \varepsilon , x + \varepsilon ) \cap A = \emptyset \), that is, with \((x - \varepsilon , x + \varepsilon ) \subseteq A^C = \mathbb {R} \setminus A\). This gives the following theorem.

Theorem 1.3.2. If \(A\) is any subset of \(\mathbb {R}\), then \(x\notin \overline {A}\) if and only if \(x\in (A^C)^0\). Thus, for any subset \(A\) of \(\mathbb {R}\), \[(\overline {A})^C = (A^C)^0 \qquad \text {and}\qquad \overline {A} = \bigl ((A^C)^0\bigr )^C.\]

Proof. By the second note above, \(x\notin \overline {A}\) exactly when some \(\varepsilon >0\) gives \((x-\varepsilon ,x+\varepsilon )\subseteq A^{C}\). That is precisely the statement that \(x\) is an interior point of \(A^{C}\), i.e. \(x\in (A^{C})^{0}\). Taking complements in \((\overline {A})^C = (A^C)^0\) gives the second identity. □

Remark. Closure and interior are dual under complementation, which is why every theorem about one has a mirror image about the other, and why it is enough to prove half of them.

Definition 1.3.3. A point \(x\in \mathbb {R}\) is called an exterior point of a set \(A\) if there exists a neighbourhood \(N\) of \(x\) such that \(N \cap A = \emptyset \). The set of all exterior points of \(A\) is called the exterior of \(A\) and is denoted by \(\operatorname {ext}(A)\).

Definition 1.3.4. A point \(x\in \mathbb {R}\) is called a boundary point of a set \(A\) if it is neither an interior point nor an exterior point of \(A\). The set of all boundary points of \(A\) is called the boundary of \(A\) and is denoted by \(b(A)\).

Note.

(i)
\(\mathbb {R} = A^0 \cup b(A) \cup \operatorname {ext}(A)\), and the three sets are disjoint.
(ii)
\(\operatorname {ext}(A) = (A^C)^0\).
(iii)
\(b(A) = \bigl ( A^0 \cup \operatorname {ext}(A) \bigr )^C\).

Definition 1.3.5. Let \(A\) be a subset of \(\mathbb {R}\). Then \(A\) is said to be an open set if every point of \(A\) is an interior point of \(A\), that is, if for each \(x \in A\) there exists \(\varepsilon > 0\) such that \((x - \varepsilon , x + \varepsilon ) \subseteq A\).

Note. A subset \(A\) of \(\mathbb {R}\) is open if and only if it is a neighbourhood of each of its points, that is, if and only if \(A = A^0\).

Theorem 1.3.6. For a subset \(A\) of \(\mathbb {R}\),

(i)
\(A\) is open if and only if \(A^C\) is closed;
(ii)
\(A\) is closed if and only if \(A^C\) is open.

Proof.

(i)
Suppose \(A\) is open, and let \(x_n\in A^C\) with \(x_n\longrightarrow x\). If \(x\) were in \(A\), there would be an \(\varepsilon >0\) with \((x-\varepsilon ,x+\varepsilon )\subseteq A\); since \(x_n\longrightarrow x\), some \(x_n\) would lie in this interval and hence in \(A\), which is impossible. So \(x\in A^C\), and \(A^C\) is closed.

Conversely, suppose \(A^C\) is closed, and let \(x\in A\). If no interval \((x-\varepsilon ,x+\varepsilon )\) were contained in \(A\), then for each \(n\) we could choose \(x_n\in A^C\) with \(|x_n - x|<\frac {1}{n}\). Then \(x_n\longrightarrow x\), and since \(A^C\) is closed, \(x\in A^C\), a contradiction. Hence \(x\) is an interior point of \(A\), and \(A\) is open.

(ii)
Apply (i) to the set \(A^C\), using \((A^C)^C = A\).
□

Note. “Open” and “closed” are not opposites. A set need not be either (for example \([0,1)\)), and \(\emptyset \) and \(\mathbb {R}\) are both.

Corollary 1.3.7. For every subset \(A\) of \(\mathbb {R}\), \(A^0\) is the largest open subset of \(A\).

Proof. First, \(A^0\) is open. If \(x\in A^0\), there is \(\varepsilon >0\) with \((x-\varepsilon ,x+\varepsilon )\subseteq A\). Each point \(y\) of this interval has a smaller interval around it inside \((x-\varepsilon ,x+\varepsilon )\), hence inside \(A\), so \(y\in A^0\). Thus \((x-\varepsilon ,x+\varepsilon )\subseteq A^0\).

Next, let \(G\) be any open set with \(G\subseteq A\), and let \(x\in G\). Since \(G\) is open it is a neighbourhood of \(x\), and so is the larger set \(A\). Thus \(x\in A^0\), and \(G\subseteq A^0\). □

Theorem 1.3.8. The union of an arbitrary family of open sets is open.

Proof. Let \(\{G_i: i\in I\}\) be a family of open sets, let \(G = \bigcup _{i\in I}G_i\), and let \(x \in G\). Then \(x \in G_i\) for some \(i\in I\). Since \(G_i\) is open, there exists \(\varepsilon > 0\) such that \((x - \varepsilon , x + \varepsilon ) \subseteq G_i \subseteq G\). Therefore \(G\) is open. □

Theorem 1.3.9. The intersection of finitely many open sets is open.

Proof. Let \(G = \bigcap ^{n}_{i = 1} G_i\), where each \(G_i\) is open. If \(G= \emptyset \), it is open. Otherwise let \(x \in G\). Then \(x \in G_i\) for every \(i = 1,2,\dots ,n\), and since each \(G_i\) is open there exist \(\varepsilon _i > 0\) such that \(( x - \varepsilon _i, x + \varepsilon _i) \subseteq G_i\). Let \(\varepsilon = \min \{ \varepsilon _1, \varepsilon _2,\dots , \varepsilon _n\}>0\). Then \((x - \varepsilon , x + \varepsilon ) \subseteq G_i\) for every \(i\), so \((x - \varepsilon , x + \varepsilon ) \subseteq G\). Therefore \(G\) is open.

The theorem fails for infinite families. For example, if \(x\in \mathbb {R}\) and \(G_n = \left (x - \frac {1}{n}, x + \frac {1}{n}\right )\) for \(n\in \mathbb {N}\), then each \(G_n\) is open but \(\bigcap _{n\in \mathbb {N}} G_n = \{x\}\), which is not open. □

Definition 1.3.10. A set \(A\) is said to be dense (or everywhere dense) in \(\mathbb {R}\) if \(\overline {A} = \mathbb {R}\). If \(A\subseteq A'\), that is, if every point of \(A\) is a limit point of \(A\), then \(A\) is said to be dense in itself.

Definition 1.3.11. A set \(A\) is said to be nowhere dense in \(\mathbb {R}\) if \((\overline {A})^0 = \emptyset \).

More generally, let \(I\) be an interval. If every subinterval of \(I\) contains a further subinterval free of points of \(A\), then \(A\) is said to be nowhere dense in \(I\). If no subinterval of \(I\) is free of points of \(A\), then \(A\) is said to be everywhere dense in \(I\).

Example 1.3.12. Show directly from the definition that every bounded open interval \((a,b)\) is an open set, and find \(\varepsilon \) explicitly.

Solution. Let \(x\in (a,b)\) and put \(\varepsilon = \min \{x-a,\ b-x\}>0\). If \(|y-x|<\varepsilon \), then \(y>x-\varepsilon \geq x-(x-a) = a\) and \(y<x+\varepsilon \leq x+(b-x) = b\), so \(y\in (a,b)\). Thus \((x-\varepsilon ,x+\varepsilon )\subseteq (a,b)\). For example, at \(x = 0.9\) in \((0,1)\) we may take \(\varepsilon = 0.1\).

Example 1.3.13. Let \(A = [0,1)\cup \{2\}\). Find \(A^0\), \(\overline {A}\), \(\operatorname {ext}(A)\) and \(b(A)\).

Solution. Interior. Each \(x\in (0,1)\) is interior, by the previous example. The point \(0\) is not interior, since every neighbourhood of \(0\) contains negative numbers, and \(2\) is not interior, since every neighbourhood of \(2\) contains points not in \(A\). So \(A^0 = (0,1)\).

Closure. The limit points of \(A\) are the points of \([0,1]\); the isolated point \(2\) is not a limit point but belongs to \(A\). So \(\overline {A} = [0,1]\cup \{2\}\).

Exterior. \(\operatorname {ext}(A) = (A^C)^0 = \bigl (\overline {A}\bigr )^C = (-\infty ,0)\cup (1,2)\cup (2,\infty )\).

Boundary. \(b(A)\) is what remains: \(b(A) = \{0,1,2\}\). Note that \(1\in b(A)\setminus A\) and \(2\in b(A)\cap A\).

Example 1.3.14. Show that \(\mathbb {Q}^0 = \emptyset \), \(\operatorname {ext}(\mathbb {Q}) = \emptyset \) and \(b(\mathbb {Q}) = \mathbb {R}\).

Solution. Every interval contains both rational and irrational numbers. So no interval lies inside \(\mathbb {Q}\), giving \(\mathbb {Q}^0 = \emptyset \), and no interval lies inside \(\mathbb {Q}^C\), giving \(\operatorname {ext}(\mathbb {Q}) = (\mathbb {Q}^C)^0 = \emptyset \). Every real number is therefore a boundary point, and \(b(\mathbb {Q}) = \mathbb {R}\). The same argument gives \(b(\mathbb {Q}^C) = \mathbb {R}\).

Example 1.3.15. Show that \(G = \{x\in \mathbb {R}: x^2>2\}\) is open and \(F = \{x\in \mathbb {R}: x^2\leq 2\}\) is closed.

Solution. We have \(G = (-\infty ,-\sqrt {2})\cup (\sqrt {2},\infty )\), a union of open intervals, which is open. (For instance, at \(x>\sqrt {2}\) the choice \(\varepsilon = x-\sqrt {2}\) works.) Since \(F = G^C\), Theorem 1.3.6 shows that \(F = [-\sqrt {2},\sqrt {2}]\) is closed.
