4.6 L’H\(\hat {\text {o}}\)pital’s Rule

We know from the algebra of limits that if \(\lim _{x\rightarrow a}\, f(x) = L\) and \(\lim _{x\rightarrow a}\, g(x) = M\) then \(\lim _{x\rightarrow a}\, \frac {f(x)}{g(x)} = \frac {L}{M}\) as long as \(M\neq 0\) and \(g(x) \neq 0\) for all values of \(x\) sufficiently close to \(a\). However, if \(L = 0\) and \(M = 0\), then the algebra of limits is not applicable. In this case we would have to apply the L’H\(\hat {\text {o}}\)pital’s rule.

Theorem 4.6.1 (L’H\(\hat {\text {o}}\)pital’s Rule). Suppose that \(f,\, g\) are functions which are continuous on the interval \([a,b]\). Suppose further that the first \(n\) derivatives are also continuous on \((a,b)\) for \(n\geq 1\). Let \(\alpha \in (a,b)\)

(i).
\(f(\alpha ) = 0,\quad f^k(\alpha ) = 0,\quad k\leq n - 1\)
(ii).
\(g(\alpha ) = 0,\quad g^k(\alpha ) = 0,\quad k \leq n -1\)
(iii).
\(g^{(n)}(\alpha ) \neq 0\).

then \(\lim _{x\rightarrow \alpha }\, \frac {f(x)}{g(x)} = \frac {f^{(n)}(\alpha )}{g^{(n)}(\alpha )}\).

Proof. Since \(g^{(n)}\) is continuous on \((a,b)\) and \(g^{(n)} \neq 0\) there is some \(r> 0\) with \((\alpha - r, \alpha + r)\subseteq (a,b)\) and such that \(g^{(n)}(t)\neq 0\) for all \(t\) such that \(\alpha - r < t < \alpha + r\). Let \(x\) be any real number such that \(0 < |x - \alpha | < r\), then \(f, \, g\) and their first \(n\) derivatives are continuous on the closed interval \([\alpha , x]\). By Taylor’s Theorem \begin {align*} f(x) = f(\alpha ) &+ f'(\alpha )\, (x - \alpha ) + \cdots \\ &+ \frac {f^{(n - 1)}(\alpha ) \, (x - \alpha )^{n - 1}}{(n - 1)!} + \frac {f^{(n)}(c)\, (x-\alpha )^n}{n!} \end {align*}

\(\implies \quad f(x) = \frac {f^{(n)}(c)\, (x - \alpha )^n}{n!}\) where \(\alpha < c < x\).

Similarly \begin {align*} g(x) = g(\alpha ) &+ g'(\alpha )\, (x - \alpha ) + \cdots \\ &+ \frac {g^{(n - 1)}(\alpha ) \, (x - \alpha )^{n - 1}}{(n - 1)!} + \frac {g^{(n)}(d)\, (x-\alpha )^n}{n!} \end {align*}

\(\implies \quad g(x) = \frac {g^{(n)}(d)\, (x - \alpha )^n}{n!}\) where \(\alpha < d < x\).

Thus \(0 < |\alpha - d| < r\) since \(0 < |\alpha - x| < r\). Since \(g^{(n)}(t) \neq 0\) for all \(t\) such that \(\alpha - r < t < \alpha + r\), we see that \(g^{(n)}(d)\neq 0\) and so \(g(x) \neq 0\) for \(0<|x - \alpha | < r\) \((x\neq \alpha \) but \(x\) is in a small neighbourhood of \(\alpha )\). Therefore, if \(0< |x - \alpha | < r\), then \begin {equation} \label {eq:lhratio} \frac {f(x)}{g(x)} = \frac {f^{(n)}(c)}{g^{(n)}(d)} . \end {equation} Now as \(x\longrightarrow \alpha \) we have \(c\longrightarrow \alpha \) and \(d\longrightarrow \alpha \) because \(c\) and \(d\) are between \(\alpha \) and \(x\). Further \(f^{(n)}(c)\longrightarrow f^{(n)}(\alpha )\) as \(c\longrightarrow \alpha \) and \(g^{(n)}(d)\longrightarrow g^{(n)}(\alpha )\) as \(d\longrightarrow \alpha \), because \(f^{(n)}\) and \(g^{(n)}\) are continuous. Thus \[\lim _{c\,, d\rightarrow \alpha } \, \dfrac {f^{(n)}(c)}{g^{(n)}(d)} = \dfrac {f^{(n)}(\alpha )}{g^{(n)}(\alpha )}\] Hence, from (4.10), \(\lim _{x\rightarrow \alpha }\, \frac {f(x)}{g(x)} = \frac {f^{(n)}(\alpha )}{g^{(n)}(\alpha )}\).

Note that Taylor’s Theorem states that a number \(c\) exists with given properties when \(f\) satisfies certain conditions. The number \(c\) is determined by the function \(f\) and the interval \([a,b]\) and it is not just any arbitrary number between \(a\) and \(b\). Hence the use of \(c\) and \(d\) in the above proof. □

Example 4.6.2. Evaluate

1.
\(\lim _{x\rightarrow 0} \, \frac {\cos x - 1}{x^2}\)
2.
\(\lim _{x \rightarrow 0} \, \frac {e^{x^2} - 1}{\sin x^2}\)

Solution. Let \(f(x) = \cos x - 1,\quad g(x) = x^2\) for all real values of \(x\). Then \(f(0) = 0\) and \(g(0) = 0\). We must now check that all conditions for the application of L’H\(\hat {\text {o}}\)pital’s Rule are satisfied before applying it. In particular we have to determine what \(n\) we must use differentiating \(g\) at \(x = 0\). \begin {align*} g'(x) & = 2x \quad \implies \quad g'(0) = 0\\ g''(x) & = 2 \quad \implies \quad g''(0) = 2 \end {align*}

Therefore \(n = 2\), we have that \begin {align*} f'(x) & = -\sin x\quad \implies \quad f'(0) = 0\\ f''(x) & = -\cos x\quad \implies \quad f''(0) = 1 \end {align*}

We see that \(f,\, g\) and all their derivatives are continuous on \(\mathbb {R}\). Hence using L’H\(\hat {\text {o}}\)pital’s Rule \[\lim _{x\longrightarrow 0}\, \dfrac {\cos x - 1}{x^2} = \dfrac {f''(0)}{g''(0)} = \dfrac {-1}{2}\]
