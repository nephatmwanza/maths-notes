5.3 Fundamental Theorem of Calculus

We now want to establish the fact that if \(f\) is a continuous function on \([a,b]\), then there exists a function \(F\) on \([a,b]\) and that \(F'(x) = f(x)\) for all \(x\in [a,b]\). That is,every continuous function is the derivative of its integral.

Suppose that \(f\in [a,b]\), define a function \(F\) on \([a,b]\) by \(f\) \[F(x) = \int ^x_af(t)\, dt,\quad x\in [a,b]\] Then \(F\) is well defined since for each \(x\in [a,b]\quad f\in R[a,x]\) and as such \(F(x)\) is uniquely defined on \([a,b]\).

Theorem 5.3.1. Let \(f\in R[a,b]\), then the function \(F\) defined on \([a,b]\) by \[F(x) = \int ^x_af(t)\, dt\quad \forall \, x\in [a,b]\] is continuous on \([a,b]\). If \(f\) is continuous at a point \(c\in [a,b]\) then \(F\) is differentiable at \(c\) and \(F'(c) = f(c)\).

Proof.

continuity If \(f\in R[a,b]\), then \(f\) is bounded on \([a,b]\) and so is \(|f|\). Let \(M\) be the upper bound of \(|f|\) on \([a,b]\).Then given \(\varepsilon > 0\, , \, \exists \, \delta > 0\) such that \(0 < M\,\delta < \varepsilon \) and if \(x\in [a,b],\quad x + h\in [a,b]\) and \(|h| < \delta \), then \begin {align*} |F(x + h) - F(x)| & = \left |\int ^{x+h}_af(t)\, dt - \int ^x_af(t)\,dt\right | \\ & = \left |\int ^{x+h}_af(t)\,dt + \int ^a_xf(t)\,dt\right |\\ & = \left |\displaystyle {\int ^{x + h}_xf(t)\, dt}\right |\\\\ & \leq \int ^{x + h}_x|f(t)| \, dt \\\\ & \leq M \, |h| < M\, \delta < \varepsilon \end {align*}

Hence \(F\) is continuous on \([a,b]\).

Differentiability at \(c\in [a,b]\) Since \(f\) is continuous at \(c\in [a,b]\) given \(\varepsilon > 0\) there exists \(\delta > 0\) such that \(|x - c| < \delta \, \implies \, |f(x) - f(c)| < \varepsilon \). Then for \(s,\, t \in [a,b]\) with \(s\neq t\) , \(c-\delta < s\leq c \leq t < c + \delta \) \begin {align*} \left |\dfrac {F(t) - F(s)}{t - s} - F(c)\right | & = \left |\dfrac {1}{t - s}\, \displaystyle {\int ^t_s[f(x) - f(c)]\, dx}\right |\\\\ & \leq \frac {1}{t - s}\, \int ^t_s|f(x) - f(c)|\,dx < \varepsilon \end {align*}

Since \(\varepsilon > 0\) is arbitrary, then \(F'(c) = f(c)\)

□

Theorem 5.3.2.

First Fundamental Theorem of Calculus Let \(f\) be a continuous function on the closed and bounded interval \([a,b]\), then if \[F(x) = \int ^x_af(t)\, dt\] then \(F'(x) = f(x)\) for \(x\in [a,b]\)

Proof. For any fixed \(x\in [a,b]\) chose \(h\neq 0\) and \(x + h \in [a,b]\). Then we have \begin {align*} F(x + h) - F(x) & = \int ^{x+h}_af(t)\,dt - \int ^x_af(t)\, dt\\\\ & = \int ^{x + h}_af(t)\, dt + \int ^a_xf(t)\, dt\\\\ & = \int ^{x + h}_xf(t)\, dt \end {align*}

Since \(f\) is continuous on the closed and bounded interval \([a,b]\, [x, x+h]\). Let \(M\) be the maximum value of \(f\) and \(m\) its minimum value on \([x,x+h]\), then the intermediate value theorem implies that there exist points \(t_1,\,t_2\in [x,x+h]\) such that \(f(t_1) = m,\, f(t_2)= M\) and \(m \leq f(t) \leq M\). Thus \[\int ^{x + h}_xm\, dt \leq \int ^{x + h}_xf(t)\, dt \leq \int ^{x + h}_xM\,dt .\] so that \(m\, h \leq \int ^{x + h}_x f(t)\, dt \leq M\, h\). Thus the number \[ \theta = \frac {1}{h} \int ^{x + h}_x f(t)\, dt \] satisfies \(m \leq \theta \leq M\). Again by the intermediate value theorem, there is a point \(C(h)\) in \([x,x+h]\) such that \(f(C(h)) = \theta \), so that \begin {equation} \label {eq:ftcquot} \dfrac {F(x + h) - F(x)}{h} = f(C(h)) . \end {equation} Since \(x\leq C(h)\leq x + h\), we have \(\lim \limits _{h\rightarrow 0}\, C(h) = x\). Since \(f\) is continuous at \(x\), the right side of (5.5) has the limit \(f(x)\) and the left side approaches \(F'(x)\) as \(h\rightarrow 0\). So we get \[F'(x) = \lim _{h\rightarrow 0} \, \dfrac {F(x + h) - F(x)}{h} = f(x)\] if \(h<0\), we take \([x + h, x]\) instead of \([x, x+h]\) and make necessary modification in the argument. □

Theorem 5.3.3.

Second Fundamental Theorem of Calculus If \(f\) is a continuous function on the closed bounded interval \([a,b]\) and if \(\Phi ' (x) = f(x) \quad \forall \, x\in [a,b]\), then \[\int ^b_af(x)\, dx = \Phi (b) - \Phi (a)\]

Proof. Let \(\displaystyle {F(x) = \int ^{x}_a f(t)\, dt}\). Since \(f\) is continuous the first fundamental theorem implies that \(F'(x) = f(x)\) for \(a\leq x\leq b\). By the hypothesis \(\Phi '(x) = f(x)\). Hence, we have \(F(x) = \Phi (x) + c\) for \(a\leq x \leq b\) and for a constant \(c\). Therefore \begin {align*} F(b) - F(a) & = [\Phi (b) + c] - [\Phi (a) + c]\\ & = \Phi (b) - \Phi (a) \end {align*}

But \(\displaystyle {F(a) = \int ^a_af(t)\,dt = 0}\) by definition. Thus \(F(b) = \Phi (b) - \Phi (a)\). Since \(\displaystyle {F(b) = \int ^b_af(t)\, dt}\) we have \(\displaystyle {\int ^b_af(t)\, dt = \Phi (b) - \Phi (a)}\) as required. □

Remark. If \(\Phi ' \neq 0\) on \([\alpha , \beta ]\), then \(\phi \) is strictly monotonic on \([\alpha ,\beta ]\) so that the condition of strictly monotonic of \(\Phi \) can be replaced by \(\Phi '\neq 0\) on \([\alpha ,\beta ]\).

Remark. The theorem still holds even if \(\Phi ' = 0\) for a finite number of times on \([\alpha , \beta ]\). In that case \([\alpha , \beta ]\) can be divided into a finite number of subintervals in each of which \(\Phi \) is strictly monotonic.
