2.8 Sequence of functions

Let \(A\) and \(B\) denote subsets of \(\mathbb {R}\) and for each natural number \(n\) let \(f_n: A\longrightarrow B\) denote a function with domain \(A\) and Co domain \(B\). If \(f\) is a function from \(A_0\subseteq A\) into \(B\), the sequence \(\{f_n\}\) is said to converge in \(A_0\) to \(f\) if the sequence of values \(\{f_n(x)\}\) converges to the number \(f(x)\) for every \(x\in A_0\). More precisely, we say that \(f_n\) converges to \(f\) point wise on \(A_0\) if for each \(x\in A_0\quad f_n(x) \longrightarrow f(x)\) as \(n\longrightarrow \infty \).

Definition 2.8.1. A sequence of function \(\{f_n\}\) on a set \(A\) converges to a function \(f\) on \(A_0\subseteq A\) if and only if for every \(\varepsilon > 0\), and each \(x\in A_0\), there is a number \(N = N(x,\varepsilon )\) such that \(|f_n(x) - f(x)| < \varepsilon \) whenever \(n>N\).

We write \(\displaystyle {\lim _{n\rightarrow \infty } f_n(x) = f(x)},\quad x\in A_0\) and say that \(\{f_n\}\) is convergent on \(A_0\).

Example 2.8.2. Let \(f_n : \mathbb {R}\longrightarrow \mathbb {R}\) be defined by \(f_n(x) = \dfrac {x}{n}\). Then the limit function \(f\) is such that \(f(x) = 0\) for all \(x\in \mathbb {R}\). Thus this sequence converges on \(\mathbb {R}\) to \(f\).

Uniform Convergence In the preceding definition of convergence, the value of \(N\) usually depends on both the choice of \(\varepsilon \) and \(x\). When \(N\) can be chosen independently of \(x\) then the convergence is said to be uniform.

Definition 2.8.3. A sequence \(f_n: A\longrightarrow B\) of functions converges uniformly to a function \(f\) on \(A_0\subseteq A\) if , for every \(\varepsilon > 0\) there is an \(N>0\) depending only on \(\varepsilon \) but not on \(x\), such that \(|f_n(x) - f(x)| < \varepsilon \) for all \(n> N\). Clearly any sequence that is uniformly convergent is also convergent. However, the converse is not true.

Example 2.8.4. Consider again the sequence of functions \(f_n: \, \mathbb {R} \longrightarrow \mathbb {R}\), defined by \(f_n(x) = \dfrac {x}{n}\). This sequence is convergent for every \(x\in \mathbb {R}\), but it is not uniformly convergent. To see this pick \(\varepsilon = \dfrac {1}{10}\), then \(|f_n(x) - f(x)| < \dfrac {1}{10},\quad n>10\) at \(x =1\) and \(n>20\) at \(x = 2\) e.t.c. In short the integer \(N\) depends on the choice of \(x\) and the convergence is not uniform.

Definition 2.8.5. A function \(f: \, A\subseteq \mathbb {R}\longrightarrow \mathbb {R}\) is said to be bounded if and only if there exist a positive number \(M\), \(0 < M < \infty \) such that \(\displaystyle {\sup _{x\in A}|f(x)|< M}\).

Theorem 2.8.6. A sequence of bounded function \(\{f_n\}\) \(f:\, A\longrightarrow \mathbb {R},\) converges uniformly on \(A\) to a function \(f\) if and only if \(\displaystyle {\lim _{n\rightarrow \infty } \, \sup _{x\in A}[|f_n(x) - f(x)|] = 0}\).

Proof. Let \(\{f_n\}\) converge uniformly to \(f\) on \(A\). Then for every \(\varepsilon > 0\) there is an \(N = N(\varepsilon )\) such that \(|f_n(x) - f(x)| < \varepsilon \) for \(n> N\), for every \(x\in A\). Thus \(\{|f_n(x) - f(x)|,\, x\in A\} < \varepsilon \) for \(n> N\) which means that \(\displaystyle {\sup _{x\in A}|f_n(x) - f(x)| }\) converges to zero.

Conversely, suppose that \(\displaystyle {\sup _{x\in A}|f_n(x) - f(x)| }\) converges to zero. Then for any \(\varepsilon > 0\) and \(x\in A\), we have \(\displaystyle {|f_n(x) - f(x)| \leq \sup _{x\in A}|f_n(x) - f(x)| < \varepsilon }\) for \(n> N\) where \(N\) does not depend on \(x\). Hence \(\{f_n\}\) converges uniformly on \(A\) to \(f\). □

Example 2.8.7. Let \(f_n(x) = n^2\, x\, (1 - x)^n\, , \, 0\leq x\leq 1\). Determine whether the sequence of function is converges uniformly on \(0\leq x\leq 1\).

We first note that \(f_n\) converges point wise to the zero function \(f\). To check for uniform convergence, we will compute \(\displaystyle {\sup _{0\leq x\leq 1}|f_n(x) - f(x)|}\) and note that the supremum is actually the maximum by continuity of \(|f_n - f|\). Taking the derivative of \(n^2\, x \, (1 - x)^n\) at maximum, we get, \(x = \dfrac {1}{n + 1}\). Hence \begin {align*} \sup _{0\leq x\leq 1}|f_n(x) - f(x)| & = \dfrac {n^2}{n + 1}\,\left (1 - \dfrac {1}{n + 1}\right )^n\\\\ & = \dfrac {n^2}{n + 1}\left [\left (1 - \dfrac {1}{n + 1}\right )^{n + 1}\right ]^{\dfrac {n}{n + 1}} \end {align*}

Since \(\dfrac {n^2}{n + 1}\longrightarrow \infty \) and \(\left (1 + \dfrac {1}{m}\right )^m\longrightarrow e^r\) as \(m \longrightarrow \infty \) for any \(r\) then \[\sup _{0\leq x\leq 1}|f_n(x) - f(x)| = \dfrac {n^2}{n + 1}\, \left ( 1 - \dfrac {1}{n}\right )^n\longrightarrow \infty \] as \(n\longrightarrow \infty \). Thus \(f_n\) does not converge uniformly.

Example 2.8.8. Let \(f_n(x) = \dfrac {x^n}{2 + 3\, x^n}\, ,\, 0\leq x\leq 1\). Show that \(f_n\) converges point wise and determine whether the sequence converges uniformly on \([0,1]\).

Solution. \(f_n \longrightarrow f\) pointwise, where \[ f(x) = \begin {cases} 0, & 0\leq x < 1,\\ \dfrac {1}{5}, & x = 1. \end {cases} \]

To check for uniform convergence \[|f_n(x) - f(x)| = \begin {cases} \dfrac {x^n}{2 + 3\,x^n} & 0\leq x < 1\\\\ 0 & x = 1\\ \end {cases}\] Since \(|f_n(x) - f(x)|\longrightarrow \dfrac {1}{5}\) as \(x\longrightarrow 1\) and \(|f_n(x) - f(x)|\) increases with \(x< 1\) then \[ \sup _{x\in [0,1)}|f_n(x) - f(x)| = \frac {1}{5} \quad \text {for every } n . \] This does not tend to \(0\), so \(f_n\) does not converge uniformly on \([0,1]\).

Theorem 2.8.9. Let \(E\subset \mathbb {R}\) and let \(f_1, \, f_2, \dots \) be a sequence of continuous functions on \(E\). If \(f_n \longrightarrow f\) uniformly on \(E\), then \(f\) is continuous on \(E\). In particular, if \(x_0\in E\), then \[\lim _{n \rightarrow \infty }\, \lim _{x\rightarrow x_0} \, f_n(x) = \lim _{x\rightarrow x_0} \,\lim _{n\rightarrow \infty } \, f_n(x) = f(x_0)\]

Proof. If \(x_0\in E\), then \(|f(x) - f(x_0)|\leq |f(x) - f_n(x)| + |f_n(x) - f(x_0)| + |f_n(x_0) - f(x_0)|\). Given \(\varepsilon > 0\), the uniform convergence of \(f_n\) to \(f\) allows us to find a positive integer \(N\) such that \(|f(x) - f_n(x)| < \dfrac {\varepsilon }{3}\) for all \(n> N\) and all \(x\in E\). Set \(x = x_0\) to obtain \(|f_n(x_0) - f(x_0)| < \dfrac {\varepsilon }{3}\).

Fix \(n>N\), since \(f_n\) is continuous at \(x_0\) there is a \(\delta > 0\) such that \(|f_n(x) - f_n(x_0)|< \dfrac {\varepsilon }{3}\) whenever \(|x - x_0| < \delta \). Thus \(|x - x_0| < \delta \) implies that \(|f(x) - f(x_0)| < \varepsilon \). □

Definition 2.8.10. A sequence of functions \(f_1, \, f_2, \dots \) is said to have a uniform Cauchy property on \(E\) if given \(\varepsilon > 0\) there is a positive integer \(N\) (depending only on \(\varepsilon \)) such that for \(n,\, m > N\), we have \(|f_n (x) - f_m(x)| < \varepsilon \) for all \(x\in E\).

Theorem 2.8.11. Suppose that the real valued functions \(f_1, \, f_2, \, \dots , \, f_n ,\dots \) have a uniform Cauchy property on \(E\). Then the sequence \(\{f_n\}\) converges uniformly on \(E\).

Proof. For each \(x\in E,\, \{f_n(x)\}\) is Cauchy sequence of real numbers hence \(f_n(x)\) converges to a limit \(f(x)\) (since a Cauchy sequence of real numbers converges). If \(|f_n(x) - f_m(x)| < \varepsilon \) for all \(n,\, m> N\) and all \(x\in E,\) fix \(n\) and let \(m\longrightarrow \infty \) to conclude that \(|f_n(x) - f(x)| < \varepsilon \) for all \(n>N\) and \(x\in E\). Thus \(f_n \longrightarrow f\) uniformly on \(E\). □

Theorem 2.8.12 (Dini’s Theorem). Let \(f_1, f_2, \dots \) be continuous functions of real numbers on the compact set \(E\), and assume that the \(f_n\) form a monotone sequence: either \(f_{n+ 1}(x) \leq f_n(x)\) for all \(x\in E\) and all \(n = 1, 2, \dots \), or \(f_{n+1}(x) \geq f_n(x)\) for all \(x\in E\) and all \(n = 1, 2, \dots \). If \(f_n \longrightarrow f\) point wise on \(E\) and \(f\) is continuous on \(E\), then \(f_n\longrightarrow f\) uniformly on \(E\).

Proof. We may assume that the \(f_n\) form a decreasing sequence (in the case of increasing case consider the functions \(- f_n\)). If \(g_n = f_n - f\), then \(g_n\) form a decreasing sequence of non-negative continuous functions converging point wise to zero. If \(\varepsilon > 0\), let \(V_n = \{x\in E: \, g_n(x) < \varepsilon \}\) which is an open set by continuity of \(g_n\). If \(x\in E\) then \(g_n(x) < \varepsilon \) eventually, hence \(\bigcup ^{\infty }_{n=1}\, V_n = E\). Since \(E\) is compact, \(\bigcup ^N_{n=1}\, V_n = E\) for some \(N\). But since \(g_n\) decreases we have \(V_n \subseteq V_{n + 1}\) for all \(n\). Therefore \(\bigcup ^N_{n=1}\, V_n = V_N\). Thus if \(x\in E\), then \(x\in V_N\); that is \(g_N(x) < \varepsilon \). If \(n>N\), we have \(0\leq g_n(x) \leq g_N(x) <\varepsilon \). Thus \(g_n \longrightarrow 0\) uniformly on \(E\). i.e \(g_n = f_n - f\longrightarrow \) uniformly on \(E\) or \(f_n\longrightarrow f\) uniformly on \(E\).

The uniform convergence of a series of functions \(\displaystyle {\sum ^{\infty }_{n = 1} f_n}\) means, by definition uniform convergence of the sequence of \(n^{\text {th}}\) partial sums \(\displaystyle {S_n = \sum ^{n}_{k = 1} \, f_k}\). □

Theorem 2.8.13 (Weiestrass M-Test). Let \(f_1,\, f_2\, \dots \) be a sequence of real valued functions on a set \(E\). If \(|f_n (x)| \leq M_n\) for all \(x\in E\) and all \(n = 1, \, 2,\, \dots \) where \(\displaystyle {\sum ^{\infty }_{n = 1} M_n < \infty }\), then the series \(\displaystyle {\sum ^{\infty }_{n=1} f_n}\) converges uniformly on \(E\). Thus, if each \(f_n\) is continuous on \(E\), then \(\displaystyle {\sum ^{\infty }_{n = 1} f_n}\) is continuous on \(E\).

Proof. If \(S_n\) is the \(n^{\text {th}}\) partial sum of the series, then for \(m< n\) \begin {align*} |S_n(x) - S_m(x)| & = \left |\displaystyle {\sum ^n_{k = m + 1} f_k(x)}\right |\\ & \leq \sum ^n_{k = m + 1} |f_k(x)|\\ & \leq \sum ^n_{k = m + 1} M_k\\ & \leq \sum ^{\infty }_{k=m + 1} M_k \end {align*}

which goes to zero as \(m\longrightarrow \infty \) since \(\displaystyle {\sum ^{\infty }_{n = 1}M_n < \infty }\). Thus, the sequence \(\{S_n\}\) has uniform Cauchy property an therefore converges uniformly. □

Example 2.8.14. Let \(f_n(x) = \dfrac {\sin nx}{x^2},\quad x\in \mathbb {R}\). Then \(|f_n(x)|\leq M_n = \dfrac {1}{n^2}\) for all \(x\). Then \[\sum |f_n(x)| = \sum \left |\dfrac {\sin nx }{n^2}\right | \leq \sum \dfrac {1}{n^2}\] But we know that the series \(\displaystyle {\sum ^{\infty }_{n = 1}\, \dfrac {1}{n^2}}\) is convergent. Therefore, \(\displaystyle {\sum ^{\infty }_{n=1}\, \dfrac {\sin nx}{n^2}}\) converges on \(\mathbb {R}\).
