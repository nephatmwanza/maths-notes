4.5 Taylor’s Theorem

Theorem 4.5.1. Suppose that \(f\) possesses derivatives of all orders upto and including the \((n - 1)^{\text {th}}\) derivative on the closed interval \([a,b]\)

(i).
\(f\) and its \((n - 1)\) derivatives are continuous on the closed interval \([a,b]\)
(ii).
\(f\) has an \(n^{\text {th}}\) order derivative on the open interval \((a,b)\), then there is some number \(c\) with \(a < c< b\) such that \begin {align*} f(b) = f(a) &+ f'(a)\, (b-a) + \frac {f''(a)}{2!}\, (b - a)^2 + \cdots \\ &+ \frac {f^{(n-1)}(a)}{(n - 1)!} \, (b - a)^{n - 1} + \frac {f^{(n)}(c)}{n!} \,(b - a)^n \end {align*}

Proof. We shall prove the theorem the way we proved the mean value theorem. We shall construct a suitable function \(F\) and then apply Rolle’s Theorem which we shall use repeatedly.

Define a function \(F\) by \begin {equation} \label {eq:taylorF} \begin {split} F(x) = f(x) - f(a) &- f'(a)\, (x - a) - \frac {f''(a)}{2!}\, (x - a)^2 - \cdots \\ &-\frac {f^{(n - 1)} (a)}{(n - 1)!}\, (x - a)^{n - 1} - K\, (x -a)^n , \end {split} \end {equation} where \(K\) is chosen so that \(F(b) = F(a)\). Since \(F(a) = 0\), this gives \begin {equation} \label {eq:taylorK} K = \dfrac {f(b) - f(a) -\sum \limits _{r = 1}^{n - 1}\, \dfrac {f^{(r)} (a)}{r!}\, (b - a)^r}{(b - a)^n}. \end {equation} Now \(F\) is continuous on \([a,b]\), differentiable on \((a,b)\), and \(F(a) = 0 = F(b)\). By Rolle’s Theorem there is some \(c_1\) with \(a < c_1 < b\) such that \(F'(c_1) = 0\). Differentiating (4.7) gives \begin {align*} F'(x) = f'(x) - f'(a) &- f''(a) \, (x-a)-\cdots \\ &- \frac {f^{(n-1)} (a)}{(n - 2)!}\, (x - a)^{n - 2}- K\, n\, (x - a)^{n - 1}, \end {align*}

so \(F'(a) = 0\). If \(n\geq 2\), then \(F'\) is continuous on \([a,c_1]\), differentiable on \((a,c_1)\), and \(F'(a) = F'(c_1) = 0\). Again by Rolle’s Theorem there is a \(c_2\) with \(a< c_2 < c_1 < b\) and \(F''(c_2) = 0\).

In the same way \(F^{(k)}(a) = 0\) for \(1 \leq k \leq n - 1\). In particular, if \(n\geq 3\), then \(F''(a) = 0 = F''(c_2)\), and Rolle’s Theorem applied to \(F''\) on \([a,c_2]\) gives a number \(c_3\) with \(a < c_3 < c_2 < c_1 <b\) and \(F'''(c_3) = 0\). Repeating the process, we obtain a number \(c_n\) such that \(a < c_n < c_{n-1} < \cdots < c_2 < c_1 < b\) and \begin {equation} \label {eq:taylorFn} F^{(n)}(c_n) = 0 . \end {equation} From (4.7) we have \(F^{(n)}(x) = f^{(n)}(x) - n!\,K\) for \(a < x <b\). Writing \(c = c_n\), equation (4.9) gives \(f^{(n)}(c) = n!\, K\), that is, \(K = \frac {f^{(n)} (c)}{n!}\). Comparing with (4.8), \[\dfrac {f^{(n)}(c)\, (b - a)^n}{n!} = f(b) - f(a) - \sum ^{n - 1}_{r=1}\dfrac {f^{(r)}(a)}{r!}\, (b - a)^r .\] Solving for \(f(b)\) gives \[f(b) = f(a) + \sum ^{n -1}_{r =1} \dfrac {f^{(r)}(a)}{r!}(b - a)^r + \dfrac {f^{(n)}(c)}{n!}\,(b - a)^n ,\] as required. □

Example 4.5.2. Use the Taylor’s formula with remainder to show that the power series \(e^x = \sum ^{\infty }_{n = 0} \frac {x^n}{n!}\) is valid for all \(x\).

Solution. Expanding \(e^x\) into power series, we have \[e^x = 1 + x + \dfrac {x^2}{2!} + \dfrac {x^3}{3!} + \dots + \dfrac {x^{n -1}}{(n - 1)!} + R_n(x)\] where \(R_n(x) = \frac {f^{(n)}(c)\, x^n}{n!}\) for some \(c\) such that \(0 < c < x\). But \(f^{(n)}(c) = e^c\). Thus \(|R_n(x)| \leq \frac {e^{|x|}\, x^n}{n!}\longrightarrow 0\) as \(n\longrightarrow \infty \). That is the series converges to \(e^x\).
