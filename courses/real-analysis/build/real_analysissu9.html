2.2 Continuous functions

Definition 2.2.1. Let \(X\) and \(Y\) be subsets of \(\mathbb {R}\). Suppose \(E\subset X,\, P\in E\) and \(f\) maps \(E\) into \(Y\). Then \(f\) is said to be continuous at \(p\) if for every \(\, \varepsilon > 0,\, \exists \, \delta > 0\, \ni \, |f(x) - f(p)| < \varepsilon \,\) for all points \(x\in E\) for which \(|x - p| < \delta \).

From the definition of continuity, it must be noted that \(\delta \) depends not only on \(\varepsilon \) but also on the point at which continuity is defined. If \(f\) is continuous at every point of \(E\), then \(f\) is said to be continuous on \(E\). Note that \(f\) has to be defined at \(p\) in order to be continuous.

Definition 2.2.2. Let \(X\) and \(Y\) be subsets of \(\mathbb {R}\). Suppose \(E\subset X, \, p\in E\) and \(f\) maps \(E\) into \(Y\), and \(\displaystyle {\lim _{x\rightarrow p} f(x) = q}\). If \(p\) is assumed to be the limit point of \(E\), then \(f\) is continuous at \(p\) if and only if \(\displaystyle {\lim _{x\rightarrow p} f(x) = f(p)}\).

Proof. Clearly, if \(\,\displaystyle {\lim _{x\rightarrow p} f(x) = q}\,\) and \(f\) is continuous at \(p\), then for every \(\varepsilon > 0\, \exists \, \delta > 0 \, \ni \, |f(x) - q| = |f(x) - f(p)| < \varepsilon \) whenever \(|x - p| < \delta \). Hence \(\,\displaystyle {\lim _{x\rightarrow p} f(x) = f(p)}\).
Conversely, if \(\, \displaystyle {\lim _{x\rightarrow p} f(x) = f(p)\,}\), then for any given \(\, \varepsilon > 0 \, \exists \, \delta > 0\, \ni |f(x) - f(p)| < \varepsilon \, \, \forall \, x \in E\, \) for which \(\, |x - p| < \delta \). Hence \(f\) is continuous at \(p\in E\). □

Theorem 2.2.3 (Sequential Criterion). Let \(f\) be a real valued function on \(E(\subseteq \mathbb {R})\) and \(p\in E\). Then \(f\) is continuous at \(p\) if and only if for every sequence \(\{x_n\}^{\infty }_{n = 1}\,\) with \(\,\displaystyle {\lim _{n\rightarrow \infty } x_n = p}\), we have \(\displaystyle {\lim _{n\rightarrow \infty } f(x_n) = f(p)}\).

Proof. Let \(f\) be continuous at \(p\). Then for every \(\, \varepsilon > 0\, \exists \, \delta > 0 \, \ni \, |f(x) - f(p)| < \varepsilon \) whenever \(\, |x - p| < \delta \hspace {0.3cm} \cdots \cdots \hspace {0.3cm} (I)\) Also let \(\displaystyle {\lim _{n\rightarrow \infty } x_n = p}\). Then for \(\delta > 0\, \exists \, N\in \mathbb {N}\, \ni \, |x_n - p| < \delta \, \, \forall \, n > \mathbb { N}\hspace {0.3cm} \cdots \cdots \hspace {0.3cm} (II)\). Putting \(x= x_n\) in \((I)\) we get \(|f(x_n) - f(p)| < \varepsilon \) whenever \(|x_n - p| < \delta \). \(\, \implies \, |f(x_n) - f(p)| < \varepsilon \hspace {0.2cm} \forall \, n \> N\hspace {0.3cm}\) (by \((II)\)) \(\, \implies \, \displaystyle {\lim _{n\rightarrow \infty } f(x_n) = f(p)}\)
Conversely, let \(f\) not be continuous at \(p\). Then \(\, \exists \,\) at least one \(\varepsilon > 0\, \ni \, \forall \, \delta > 0\, \exists \,\) a \(\, p\in E\, \ni \, |x - p| < \delta \) but \(|f(x) - f(p)|\geq \varepsilon \). We take \(\delta = \dfrac {1}{n}\, ,\, n\in \mathbb {N}\). Then for each \(n\, \exists \) and \(x_n\, |x_n - p| < \dfrac {1}{n}\hspace {0.3cm}\cdots \cdots \hspace {0.3cm} (III)\) and \(|f(x_n) - f(p)|\geq \varepsilon \hspace {0.3cm} \cdots \cdots \hspace {0.3cm} (IV)\). Now, \((III)\) gives \(\displaystyle {\lim _{n\rightarrow \infty } x_n = p}\). But \((IV)\) suggest that \(\displaystyle {\lim _{n\rightarrow \infty } f(x_n) \neq f(p)}\). This is a contradiction. Hence \(f\) is continuous. □

Corollary 2.2.4 (Discontinuity Criterion). Let \(f\) be a real valued function defined on \(E(\subseteq \mathbb {R})\) and \(p\in E\). Then \(f\) is discontinuous at \(p\) if and only if \(\, \exists \,\) a sequence \(\, \{x_n\}^{\infty }_{n=1}\,\) in \(E\) with \(\displaystyle {\lim _{n\rightarrow \infty } x_n = p}\, \ni \, \displaystyle {\lim _{n\rightarrow \infty } f(x_n) \neq f(p)}\).

Example 2.2.5. The function \(\, f(x) = \dfrac {1}{x}\, ,\, x\in [0,1]\) is not continuous at \(x=0\).

Proof. Note that \(\, \left \{\dfrac {1}{n}\right \}^{\infty }_{n=1}\,\) is such that \(\, \displaystyle {\lim _{n\rightarrow \infty }\dfrac {1}{n} = 0}\), but \(\, \displaystyle {\lim _{n\rightarrow \infty } f\left (\dfrac {1}{n}\right ) = \lim _{n\rightarrow \infty } = n = \infty }\,\). But \(f(0)\) is not defined. Therefore, by the above corollary \(f\) is discontinuous at \(x = 0\). □

Theorem 2.2.6. Let \(f\) and \(g\) be continuous at some point \(p\in E(\subseteq \mathbb {R})\) and let \(\alpha \in \mathbb {R}\). Then

1.
the functions \(f\pm g\,, \hspace {0.2cm} \alpha \,f\) and \(fg\) are continuous at \(p\).
2.
then function \(\frac {f}{g}\) is continuous at \(p\) provided \(g(p) \neq 0\).

Proof. Each part follows from the corresponding limit law, since continuity at \(p\) says that \(\lim _{x\rightarrow p}f(x) = f(p)\).

For the sum, given \(\varepsilon >0\) choose \(\delta _1\) and \(\delta _2\) so that \(|f(x)-f(p)|<\frac {\varepsilon }{2}\) and \(|g(x)-g(p)|<\frac {\varepsilon }{2}\) on the respective neighbourhoods; then \(\delta =\min (\delta _1,\delta _2)\) gives \[|(f+g)(x)-(f+g)(p)| \leq |f(x)-f(p)| + |g(x)-g(p)| < \varepsilon .\] Scalar multiples are the case \(g\) constant. For the product, write \[fg(x)-fg(p) = f(x)[g(x)-g(p)] + g(p)[f(x)-f(p)],\] and note \(f\) is bounded near \(p\) because it is continuous there; both terms are then made small. For the quotient the same device applies once \(g(p)\neq 0\) guarantees \(|g(x)|>\frac {|g(p)|}{2}\) near \(p\), which keeps the denominator away from zero. □

Theorem 2.2.7. Let \(f\) be a continuous real valued function defined of \(E(\subseteq \mathbb {R})\). Then the function \(|f|\) defined by \(\, |f|\, (x) = |f(x)|\, \hspace {0.2cm} x\in E\) is also continuous on \(E\).

Proof. Let \(f\) be continuous at \(p\in E\). Then for each \(\, \varepsilon > 0\, \exists \, \delta > 0\, \ni \, |f(x) - f(p)| < \varepsilon \) whenever \(|x - p| < \delta \). Now, \(||f(x)| - |f(p)|| \leq |f(x) - f(p)| < \varepsilon \) whenever \(|x-p| < \delta \). Therefore \(|f|\) is continuous.

Note that the converse of the above theorem is not generally true. For example, the function \(f\) defined by \[ f(x) = \begin {cases} 1 & x \hspace {0.2cm}\text {is rational}\\ -1 & x \hspace {0.2cm}\text {is irrational}\\ \end {cases}\] is discontinuous everywhere but \(|f|= 1\), being a constant function is continuous everywhere. □

Theorem 2.2.8 (Continuity of Composite functions). Let \(X,\, Y\) and \(Z\) be subsets of \(\mathbb {R}\). Suppose \(E\subseteq X,\, f\) maps \(E\) into \(Y\), \(\, g\) maps the range of \(f\), \(\, (f(E)),\,\) into \(z\), and \(h\) is the mapping of \(E\) into \(z\) and is defined by \(\hspace {0.2cm} h(x) = g(f(x)) \, x\in E\). If \(f\) is continuous at a point \(p\in E\) and if \(g\) is continuous at a point \(f(p)\), then \(h\) is also continuous at \(p\).

Proof. Let \(\varepsilon > 0\) be given. Since \(g\) is continuous at \(f(p),\, \exists \, \eta > 0\, \ni \, |g(y) - g(f(p))| < \varepsilon \) if \(|y - f(p)| < \eta \,\) where \(y \in f(E)\). Since \(f\) is continuous at \(p, \, \exists \, \delta > 0 \, \ni \, |f(x) - f(p)| < \eta \,\) if \(\, |x - p| < \delta \, , \, x\in E\). Hence, \(|h(x) - h(p)| = |g(f(x)) - g(f(p))| < \varepsilon ,\,\) whenever \(|x - p| < \delta \) and \(x\in E\). Therefore, \(h\) is continuous at \(p\). □

Theorem 2.2.9. Let \(X\) and \(Y\) be subsets of \(\mathbb {R}\). A function \(f\) of \(X\) into \(Y\) is continuous on \(X\) if and only if \(f^{-1}(O)\) is open in \(X\) for every open set \(O\) in \(Y\).

Proof. Suppose \(f\) is continuous on \(X\) and \(O\) is an open set in \(Y\). We need to show that every point of \(f^{-1}(O)\) is an interior point of \(f^{-1}(O)\). So, suppose \(p\in X\) and \(f(p)\in O\). Since \(O\) is open, \(\, \exists \,\varepsilon \, > 0\, \ni \, y \in O\) if \(|f(x) - y| < \varepsilon \), and since \(f\) is continuous at \(p,\, \exists \, \delta \, > 0 \, \ni \, |f(x) - f(p)| < \varepsilon \,\) if \(|x - p| < \delta \). Thus \(\, x \in f^{-1}(O)\,\) as soon as \(\, |x - p| < \delta \).
Conversely, suppose \(f^{-1}(O)\) is open in \(X\) for every open set \(O\) in \(Y\). Fix \(p\in X\) and let \(\varepsilon > 0\) be given. Also let \(O\) be the set of all \(y \in Y \,\ni \, |f(x) - f(p)| < \varepsilon \). Then \(O\) is open. Hence \(\, \exists \, \delta > 0\, \ni \, x\in f^{-1}(O)\) as soon as \(|x - p|< \delta \). But if \(x \in f^{-1}(O)\), then \(f(x) \in O\) so that \(|f(x) - f(p)| < \varepsilon \). Thus, for every \(\varepsilon > 0\, \exists \, \delta > 0\, \ni \, |f(x) - f(p)| < \varepsilon \,\) whenever \(|x - p| < \delta \). Therefore, \(f\) is continuous at \(p\). Hence, \(p\) being arbitrary in \(X\), \(\, f\) is continuous on \(X\). □

Corollary 2.2.10. A function \(f\) of \(X(\subseteq \mathbb {R})\) into \(Y(\subset \mathbb {R})\) is continuous if and only if \(f^{-1}(C)\) is a closed set in \(X\) for every closed set \(C\) in \(Y\).

Proof. This follows from the theorem sine a set is closed if and only if its complement is open, and \(f^{-1}(C^c) = [f^{-1}(C)]^c\) for every \(C\) in \(Y\). □
