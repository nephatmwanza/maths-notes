1.2 Closed Sets

Definition 1.2.1. A set \(A\) of real numbers is said to be closed if, whenever a convergent sequence has all of its terms in \(A\), its limit also lies in \(A\). That is, \(A\) is closed if for every sequence \(\{ x_n \}^{\infty }_{n = 1}\) with \(x_n \in A\) for all \(n\) and \(x_n \longrightarrow x\), we have \(x \in A\).

In particular the empty set \(\emptyset \) is closed, since there is no sequence in it.

Example 1.2.2.

1.
\(\mathbb {R}\) is closed, since every convergent sequence in \(\mathbb {R}\) converges to a point of \(\mathbb {R}\).
2.
Every singleton set \(\{a\}\), \(a\in \mathbb {R}\), is closed, since the only sequence in \(\{a\}\) is the constant sequence \(x_n = a\), which converges to \(a\in \{a\}\).
3.
For every real number \(c\), the half-lines \([c, \infty )\) and \((-\infty ,c]\) are closed. For example, if \(x_n \longrightarrow x\) and \(x_n \geq c\) for every \(n\), then \(x\geq c\), so \(x\in [c,\infty )\).

Note. The sets \([c,\infty )\) and \((-\infty , c]\) are closed sets and they are intervals, but they are not called closed intervals: that term is reserved for \([a,b]\) with \(a,b\in \mathbb {R}\).

Lemma 1.2.3. If \(A\) is a closed subset of \(\mathbb {R}\), \(x_n \longrightarrow x\) in \(\mathbb {R}\), and \(x_n \in A\) frequently (that is, for infinitely many \(n\)), then \(x\in A\).

Proof. Since \(x_n\in A\) for infinitely many \(n\), we can choose indices \(n_1<n_2<n_3<\cdots \) with \(x_{n_k}\in A\) for every \(k\). The subsequence \(\{x_{n_k}\}\) lies in \(A\) and converges to \(x\), because every subsequence of a convergent sequence converges to the same limit. Since \(A\) is closed, \(x\in A\). □

Note. “Frequently” is weaker than “eventually” and is all that is needed: the argument only requires some term beyond each stage to lie in \(A\). The lemma is often the easiest way to show that a limit lies in a closed set.

Theorem 1.2.4.

1.
\(\emptyset \) and \(\mathbb {R}\) are closed sets.
2.
If \(A\) and \(B\) are closed sets in \(\mathbb {R}\), then so is their union \(A\cup B\).
3.
If \(\Omega = \{ S_i : i \in I\}\) is any family of closed sets in \(\mathbb {R}\), then their intersection \(S = \bigcap _{i\in I} S_i\) is also closed. That is, the intersection of an arbitrary family of closed sets is closed.

Proof.

1.
This was noted in the definition and in the example above.
2.
Suppose \(x_n \in A\cup B\) for every \(n\) and \(x_n \longrightarrow x\). Then \(x_n\in A\) for infinitely many \(n\) or \(x_n\in B\) for infinitely many \(n\) (or both). In the first case \(x\in A\) by Lemma 1.2.3, and in the second case \(x \in B\) by the same lemma. Either way \(x\in A\cup B\), so \(A\cup B\) is closed.
3.
Suppose \(x_n \in S\) for every \(n\) and \(x_n \longrightarrow x\). For each \(i\in I\) the sequence lies in \(S_i\), and \(S_i\) is closed, so \(x\in S_i\). Since this holds for every \(i\in I\), \(x\in \bigcap _{i \in I} S_i = S\). Hence \(S\) is closed.
□

Example 1.2.5. Every closed interval \([a,b]\) is a closed set.

Proof. Let \(a\leq b\). Then \([a,b]= (-\infty , b]\cap [a,\infty )\), and \((-\infty , b]\) and \([a,\infty )\) are closed sets. Therefore, by the third part of Theorem 1.2.4, \([a,b]\) is a closed set. □

Example 1.2.6. If \(A_1, A_2, \dots , A_r\) is a finite list of closed sets in \(\mathbb {R}\), then their union \(A_1\cup A_2\cup \dots \cup A_r\) is also closed. That is, the union of finitely many closed sets is closed.

Proof. This follows by induction from the second part of Theorem 1.2.4.

The union of an infinite family of closed sets need not be closed. For example, if \(A_n = \left [ 1 + \frac {1}{n}, 5 - \frac {1}{n}\right ]\) for \(n \in \mathbb {N}\), then \(\bigcup _{n\in \mathbb {N}} A_n = (1,5)\), which is not closed: the sequence \(1+\frac {1}{n}\) lies in \((1,5)\) for \(n\geq 2\) but its limit \(1\) does not. □

Definition 1.2.7. A non-empty set \(A\) is said to be finite if there exist a positive integer \(n\) and a surjection \(f:\{ 1, 2, \dots , n\} \longrightarrow A.\) By convention, \(\emptyset \) is also finite.

A set is said to be infinite if it is not finite.

Example 1.2.8. Every finite subset \(A = \{ a_1, a_2, \dots , a_r\}\) of \(\mathbb {R}\) is closed.

Proof. We can write \[A = \{a_1\} \cup \{ a_2\}\cup \cdots \cup \{ a_r\},\] and each singleton set \(\{a_i\}\) is closed. A finite union of closed sets is closed, so \(A\) is closed. □

Definition 1.2.9. Let \(A\subseteq \mathbb {R}\). Then \(A\) is a neighbourhood of a point \(x\in \mathbb {R}\) if there exists \(\varepsilon > 0\) such that \((x-\varepsilon , x + \varepsilon ) \subseteq A\); that is, if \(y \in A\) whenever \(|y - x| < \varepsilon \).

Definition 1.2.10. Let \(A\) be a subset of \(\mathbb {R}\). A real number \(x\) is called a limit point of \(A\) if for every \(\varepsilon > 0\) there exists \(y \in A\) such that \(0 < |y - x| < \varepsilon \). Equivalently, \(x\) is a limit point of \(A\) if for every \(\varepsilon > 0\) \[(x-\varepsilon , x + \varepsilon ) \cap (A \setminus \{x\}) \neq \emptyset ,\] that is, every neighbourhood \((x - \varepsilon , x + \varepsilon )\) of \(x\) contains at least one point of \(A\) other than \(x\).

Theorem 1.2.11. A point \(x\) is a limit point of \(A\) if and only if, for each \(\varepsilon > 0\), the set \((x - \varepsilon , x + \varepsilon ) \cap A\) is infinite.

Proof. If every set \((x - \varepsilon , x + \varepsilon ) \cap A\) is infinite, then each contains a point of \(A\) other than \(x\), so \(x\) is a limit point of \(A\).

Conversely, let \(x\) be a limit point of \(A\) and suppose that, for some \(\varepsilon > 0\), the set \((x - \varepsilon , x + \varepsilon ) \cap A\) is finite. Its points other than \(x\), say \(y_1, \dots , y_k\), are finitely many, and there is at least one of them because \(x\) is a limit point. Put \[\varepsilon ' = \min \{|y_1 - x|, \dots , |y_k - x|\} > 0 .\] Then \((x - \varepsilon ', x + \varepsilon ')\) contains no point of \(A\) other than \(x\), contradicting the fact that \(x\) is a limit point of \(A\). Hence every set \((x - \varepsilon , x + \varepsilon ) \cap A\) is infinite. □

Definition 1.2.12. The set of all limit points of \(A\), whether or not \(A\) is closed, is called the derived set of \(A\) and is denoted by \(A'\).

Theorem 1.2.13. Let \(A\) be a subset of \(\mathbb {R}\). A real number \(x\) is a limit point of \(A\) if and only if there exists a sequence \(\{x_n\}^{\infty }_{n = 1}\) in \(A\) with \(x_n\neq x\) for every \(n\) and \(x_n \longrightarrow x\) as \(n \longrightarrow \infty \).

Proof. Suppose \(x\) is a limit point of \(A\). Taking \(\varepsilon = \frac {1}{n}\) in the definition, for every \(n \in \mathbb {N}\) there exists \(x_n \in A\) such that \(0 < |x_n - x| < \frac {1}{n}\). Then \(x_n\neq x\), and \(x_n \longrightarrow x\) because \(\frac {1}{n}\longrightarrow 0\).

Conversely, suppose \(\{ x_n \}\) is a sequence in \(A\) with \(x_n\neq x\) and \(x_n \longrightarrow x\). Let \(\varepsilon > 0\) be given. There exists \(N \in \mathbb {N}\) such that \(| x_n - x| < \varepsilon \) for every \(n > N\), so \(y = x_{N+1}\) is a point of \(A\) with \(0<|y-x|<\varepsilon \). Hence \(x\) is a limit point of \(A\). □

Definition 1.2.14. The closure of a subset \(A\) of \(\mathbb {R}\), denoted by \(\overline {A}\), is the set \(\overline {A} = A \cup A'\).

Theorem 1.2.15. Let \(A\) be any subset of \(\mathbb {R}\). Then \(\overline {A}\) is the smallest closed set containing \(A\). More precisely:

(i)
\(A \subseteq \overline {A}\);
(ii)
if \(B\) is a closed set with \(A\subseteq B\), then \(\overline {A}\subseteq B\);
(iii)
\(A\) is closed if and only if \(\overline {A} = A\);
(iv)
a real number \(x\) belongs to \(\overline {A}\) if and only if for every \(\varepsilon > 0\) there exists \(y \in A\) with \(|x - y| < \varepsilon \);
(v)
\(\overline {A}\) is a closed set.

Proof. We prove (iv) first, since the other parts use it.

(iv)

Let \(x\in \overline {A}\). If \(x\in A\), take \(y = x\). Otherwise \(x\in A'\), and the definition of a limit point gives \(y\in A\) with \(|x-y|<\varepsilon \). Conversely, suppose every \(\varepsilon >0\) has such a \(y\). If \(x\in A\) then \(x\in \overline {A}\). If \(x\notin A\), then each such \(y\) differs from \(x\), so \(0<|x-y|<\varepsilon \) and \(x\in A'\subseteq \overline {A}\).

Taking \(\varepsilon = \frac {1}{n}\), part (iv) says that \(x \in \overline {A}\) if and only if \(x\) is the limit of some sequence \(\{y_n\}\) in \(A\).

(i)

This is immediate from \(\overline {A} = A \cup A'\).

(ii)

Let \(x\in \overline {A}\). By the remark after (iv), \(x\) is the limit of a sequence in \(A\), hence of a sequence in \(B\). Since \(B\) is closed, \(x\in B\). Thus \(\overline {A}\subseteq B\).

(v)

Suppose \(x_n\in \overline {A}\) for every \(n\) and \(x_n\longrightarrow x\). Let \(\varepsilon >0\). Choose \(n\) with \(|x_n - x|<\frac {\varepsilon }{2}\), and then, by (iv), \(y\in A\) with \(|x_n - y|<\frac {\varepsilon }{2}\). By the triangle inequality, \[|x - y| \leq |x - x_n| + |x_n - y| < \frac {\varepsilon }{2} + \frac {\varepsilon }{2} = \varepsilon .\] Hence, by (iv), \(x\in \overline {A}\), and \(\overline {A}\) is closed.

(iii)

If \(A\) is closed, then (ii) with \(B=A\) gives \(\overline {A}\subseteq A\), and with (i) this gives \(\overline {A}=A\). Conversely, if \(\overline {A}=A\) then \(A\) is closed by (v). □

Note. By (iii), a set is closed exactly when it contains all its limit points.

Definition 1.2.16. A subset \(A\) of \(\mathbb {R}\) is bounded if there exists a real number \(K\) such that \(|x| \leq K\) for every \(x\in A\).

Theorem 1.2.17 (Bolzano–Weierstrass Theorem). Every bounded infinite set \(S\) of real numbers has at least one limit point.

Proof. Since \(S\) is bounded, \(S\subseteq [h,k]\) for some real numbers \(h<k\). Let \[T = \{t\in \mathbb {R}: S \cap (-\infty , t) \text { is finite}\}.\] Then \(h \in T\), since \(S\cap (-\infty ,h) = \emptyset \). If \(t > k\) then \(S \cap (-\infty , t) = S\) is infinite, so \(t\notin T\); hence \(k\) is an upper bound of \(T\). Note also that if \(t\in T\) and \(s<t\) then \(s\in T\). By the completeness axiom \(T\) has a supremum; let \(\xi = \sup T\).

Let \(\varepsilon > 0\). Since \(\xi -\varepsilon \) is not an upper bound of \(T\), there is \(t\in T\) with \(t>\xi -\varepsilon \), and so \(S\cap (-\infty ,\xi -\varepsilon ]\subseteq S\cap (-\infty ,t)\) is finite. On the other hand \(\xi + \varepsilon \notin T\), so \(S\cap (-\infty , \xi +\varepsilon )\) is infinite. Therefore \[S \cap (\xi - \varepsilon , \xi + \varepsilon ) = \bigl (S\cap (-\infty , \xi +\varepsilon )\bigr ) \setminus \bigl (S\cap (-\infty ,\xi -\varepsilon ]\bigr )\] is infinite. Since \(\varepsilon >0\) was arbitrary, \(\xi \) is a limit point of \(S\) by Theorem 1.2.11. □
