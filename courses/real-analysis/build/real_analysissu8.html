2.1 Limits of functions

Definition 2.1.1. Let \(X\) and \(Y\) be subsets of \(\mathbb {R}\). Suppose \(E\subset X\), \(f\) maps \(E\) into \(Y\) and \(p\) is a limit point of \(E\). We say that the limit of \(f(x)\) as \(x\) approaches \(p\) in \(E\) is \(q\) and write \[\lim _{x\longrightarrow p} f(x) = q\] If there is a point \(q\in Y\) such that for every \(\varepsilon >0\, \exists \) a \(\delta (\varepsilon ) > 0\) such that \(|f(x) - q| < \varepsilon \,\, \forall \, x \in E\) for which \(0 < |x - p| < \delta \).

This definition can be recast in terms of limits of sequences as follows:

Theorem 2.1.2. Let \(X\) and \(Y\) be subsets of \(\mathbb {R}\). Suppose \(E\subset X\), \(f\) maps \(E\) into \(Y\) and \(p\) is a limit point of \(E\). Then \begin {equation} \label {eq:limfx} \lim _{x\rightarrow p} f(x) = q \end {equation} if and only if \begin {equation} \label {eq:limfpn} \lim _{n\rightarrow \infty } f(p_n) = q \end {equation} for every sequence \(\{p_n\}^{\infty }_{n = 1}\) in \(E\) such that \begin {equation} \label {eq:pnp} p_n \neq p \quad \text {for all } n \qquad \text {and}\qquad \lim _{n\rightarrow \infty } p_n = p. \end {equation}

Proof. Suppose (2.1) holds, and choose a sequence \(\{p_n\}^{\infty }_{n= 1}\) in \(E\) satisfying (2.3). Let \(\varepsilon > 0\) be given. Then there is a \(\delta > 0\) such that \(|f(x) - q| < \varepsilon \) whenever \(x \in E\) and \(0 < |x - p| < \delta \). By (2.3) there is an \(N \in \mathbb {N}\) such that \(0 <|p_n - p| < \delta \) for all \(n > N\). Thus \(|f(p_n) - q| < \varepsilon \) for all \(n > N\), which shows that (2.2) holds.

Conversely, suppose (2.1) is false. Then there is some \(\varepsilon > 0\) such that for every \(\delta > 0\) there is a point \(x \in E\) (depending on \(\delta \)) with \(0 < |x - p| < \delta \) but \(|f(x) - q|\geq \varepsilon \). Taking \(\delta _n = \frac {1}{n}\), \(n = 1, 2, \dots \), we obtain a sequence in \(E\) satisfying (2.3) for which (2.2) is false. Hence, if (2.2) holds for every sequence satisfying (2.3), then (2.1) holds. □

Corollary 2.1.3. If \(f\) has a limit at \(p\) thus limit is unique.

Proof. The proof follows from the fact that the limit of sequence is unique. □

Theorem 2.1.4. If \(\displaystyle {\lim _{x\rightarrow p} \, f(x) = q \neq 0\, , \, \exists K \in \mathbb {R}^+\,}\) and \(\delta > 0\) such that \(0<|x - p| < \delta \, \implies \, |f(x)| > K\).

Proof. Since \(\displaystyle {\lim _{x\rightarrow p} f(x)= q \neq 0}\), for \(\varepsilon = \dfrac {1}{2}\,|q|\, \exists \, \delta > 0,\) such that \(0 < |x - p|< \delta \, \implies |f(x) - q| < \dfrac {1}{2}\, |q|\, \implies |q| - |f(x)| < \dfrac {1}{2}\, |q|\) i.e \(|f(x)| > \dfrac {1}{2}\,|q|\). Hence, the number \(K = \dfrac {1}{2}\, |q|\in \mathbb {R}^+\) as required. □

Theorem 2.1.5. Let \(X\) and \(Y\) be subsets of \(\mathbb {R}\). Suppose \(E\subset X,\, p\) is a limit point of \(E\) and \(f\) and \(g\) are real valued functions on \(E\), and \(\displaystyle {\lim _{x\rightarrow p} f(x) = A}\, ,\quad \displaystyle {\lim _{x\rightarrow p} g(x) = B}\), then

(a).
\(\displaystyle {\lim _{x\rightarrow p} (f + g)(x) = A + B}\)
(b).
\(\displaystyle {\lim _{x\rightarrow p} (fg)(x) = AB}\)
(c).
\(\displaystyle {\lim _{x\rightarrow p} \left (\dfrac {f}{g}\right )(x) = \dfrac {A}{B}\quad }\) if \(B\neq 0\).

Proof. These assertions follow immediately from analogous properties of sequences. □
