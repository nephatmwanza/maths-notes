1.2 The Triangle Inequality

For any complex numbers \(z_1\) and \(z_2\), we have \(\hspace {0.3cm} \begin {vmatrix} z_1 + z_2\\ \end {vmatrix} \leq \begin {vmatrix} z_1\\ \end {vmatrix} + \begin {vmatrix} z_2\\ \end {vmatrix}\)

Proof \begin {align*} \begin {vmatrix} z_1 + z_2\\ \end {vmatrix}^2 & = \big (z_1 + z_2\big )\cdot \overline {\big (z_1 + z_2\big )}= \big (z_1 + z_2\big )\cdot \big (\overline {z_1} + \overline {z_2}\big )\\ & = z_1\overline {z_1} + z_2\overline {z_2} + \overline {z_1}z_2 + z_1\overline {z_2}\\ & = \begin {vmatrix} z_1\\ \end {vmatrix}^2 + \begin {vmatrix} z_2\\ \end {vmatrix}^2 + z_1\overline {z_2} + \overline {z_1\overline {z_2}}\\ & = \begin {vmatrix} z_1\\ \end {vmatrix}^2 + \begin {vmatrix} z_2\\ \end {vmatrix}^2 + 2 Re \big (z_1\overline {z_2}\big )\\ & \leq \begin {vmatrix} z_1\\ \end {vmatrix}^2 + \begin {vmatrix} z_2\\ \end {vmatrix}^2 + 2\begin {vmatrix} z_1 \overline {z_2}\\ \end {vmatrix}\\ & = \begin {vmatrix} z_1\\ \end {vmatrix}^2 + \begin {vmatrix} z_2\\ \end {vmatrix}^2 + 2\begin {vmatrix} z_1\\ \end {vmatrix}\begin {vmatrix} \overline {z_2}\\ \end {vmatrix}\\ & = \begin {vmatrix} z_1\\ \end {vmatrix}^2 + \begin {vmatrix} z_2\\ \end {vmatrix}^2 + 2\begin {vmatrix} z_1\\ \end {vmatrix}\begin {vmatrix} z_2\\ \end {vmatrix}\\ & = \Big (\begin {vmatrix} z_1\\ \end {vmatrix} + \begin {vmatrix} z_2\\ \end {vmatrix}\Big )^2 \end {align*}

\[\therefore \hspace {1cm} \begin {vmatrix} z_1 + z_2\\ \end {vmatrix}\leq \begin {vmatrix} z_1\\ \end {vmatrix} + \begin {vmatrix} z_2\\ \end {vmatrix}\]

The triangle inequality can be extended to include any number of sumands that is we can write \begin {align*} \begin {vmatrix} z_1 + z_2 + z_3\\ \end {vmatrix} & \leq \begin {vmatrix} z_1 + z_2\\ \end {vmatrix} + \begin {vmatrix} z_3\\ \end {vmatrix}\\ & \leq \begin {vmatrix} z_1\\ \end {vmatrix} + \begin {vmatrix} z_2\\ \end {vmatrix} + \begin {vmatrix} z_3\\ \end {vmatrix}\\ \end {align*}

Which we can generalize \(\hspace {0.3cm}\begin {vmatrix} \displaystyle {\sum ^n_{k =1} z_k}\\ \end {vmatrix} \leq \displaystyle {\sum ^n_{k = 1} \begin {vmatrix} z_k\\ \end {vmatrix}}\)

\[\begin {vmatrix} z_1 + z_2 + \cdots \cdots \cdots + z_n\\ \end {vmatrix} \leq \begin {vmatrix} z_1\\ \end {vmatrix} + \begin {vmatrix} z_2\\ \end {vmatrix} + \cdots \cdots \cdots \begin {vmatrix} z_n\\ \end {vmatrix}\] Prove using mathematical induction.

\(\implies \hspace {0.3cm}\begin {vmatrix} z_1\\ \end {vmatrix} = \begin {vmatrix} z_1 - z_2 + z_2\\ \end {vmatrix}\leq \begin {vmatrix} z_1 - z_2\\ \end {vmatrix} + \begin {vmatrix} z_2\\ \end {vmatrix}\)

\(\implies \hspace {0.3cm} \begin {vmatrix} z_1\\ \end {vmatrix} - \begin {vmatrix} z_2\\ \end {vmatrix} \leq \begin {vmatrix} z_1 - z_2\\ \end {vmatrix}\)

Similarly, \(\hspace {0.3cm} \begin {vmatrix} z_1 - z_2\\ \end {vmatrix} \geq \begin {vmatrix} z_2\\ \end {vmatrix} - \begin {vmatrix} z_1\\ \end {vmatrix}\). Thus \(\hspace {0.2cm} \begin {vmatrix} z_1 - z_2\\ \end {vmatrix} \geq \begin {vmatrix} \begin {vmatrix} z_1\\ \end {vmatrix} - \begin {vmatrix} z_2\\ \end {vmatrix} \end {vmatrix}\)

Lemma
For any complex numbers \(z_1\) and \(z_2\) the following holds

i).
\(\begin {vmatrix} \begin {vmatrix} z_1\\ \end {vmatrix} - \begin {vmatrix} z_2\\ \end {vmatrix} \end {vmatrix} \leq \begin {vmatrix} z_1 + z_2\\ \end {vmatrix}\)
ii).
\(\begin {vmatrix} \begin {vmatrix} z_1\\ \end {vmatrix} - \begin {vmatrix} z_2\\ \end {vmatrix} \end {vmatrix} \leq \begin {vmatrix} z_1 - z_2\\ \end {vmatrix}\)

Example
Find an upper bound for \(\hspace {0.2cm}\displaystyle {\begin {vmatrix} \dfrac {-1}{z^4 - 5z + 1} \end {vmatrix}}\hspace {0.2cm}\) if \(z = 2\)

Solution
We need to find a number \(M\) such that \[\begin {vmatrix} \dfrac {-1}{z^4 - 5z + 1} \end {vmatrix}\leq M\]

Note that \begin {align*} \begin {vmatrix} z^4 - 5z + 1\\ \end {vmatrix} & = \begin {vmatrix} z^4 - (5z -1)\\ \end {vmatrix}\\ & \geq \begin {vmatrix} \begin {vmatrix} z\\ \end {vmatrix}^4 - \begin {vmatrix} 5z - 1\\ \end {vmatrix} \end {vmatrix} \end {align*}

We make the last expression as small as possible. This is only possible when \(\begin {vmatrix} 5z - 1\\ \end {vmatrix}\) is large \[\begin {vmatrix} 5z - 1\\ \end {vmatrix} \leq 5\begin {vmatrix} z\\ \end {vmatrix} + \begin {vmatrix} -1\\ \end {vmatrix} = 5\begin {vmatrix} z\\ \end {vmatrix} + 1\]

So we get \begin {align*} \begin {vmatrix} z^4 - 5z + 1\\ \end {vmatrix}& \geq \begin {vmatrix} \begin {vmatrix} z\\ \end {vmatrix}^4 - \begin {vmatrix} 5z - 1\\ \end {vmatrix} \end {vmatrix}\\ & \geq \begin {vmatrix} \begin {vmatrix} z\\ \end {vmatrix}^4 - \big (5\begin {vmatrix} z\\ \end {vmatrix} + 1\big ) \end {vmatrix}\\ & = \begin {vmatrix} 16 - 10 -1\\ \end {vmatrix}\\ & = 5 \end {align*}

Hence for \(z = 2\), we get \(\hspace {0.2cm}\displaystyle {\begin {vmatrix} \dfrac {-1}{z^4 - 5z + 1}\\ \end {vmatrix} \leq \dfrac {1}{5}}\)
