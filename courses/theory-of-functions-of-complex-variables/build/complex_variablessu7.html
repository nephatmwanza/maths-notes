2.1 Sequences

Definition
A sequence \(\{z_n\}\) is a function where the domain is the set of positive integers and whose range is a subset of the complex numbers.

If \(\lim \limits _{n \rightarrow \infty } z_n = L\), we say the sequence \(\{z_n\}\) is convergent. The number \(L\) is called the limit of \((z_n)\)

Definition
A sequence \(\{z_n\}\) converges to the number \(L\) if \(\forall \hspace {0.1cm} \varepsilon > 0\) and \(N\) exist such that \(\hspace {0.2cm}\begin {vmatrix} z_n - L\\ \end {vmatrix} < \varepsilon \hspace {0.2cm}\) whenever \(n<N\).

A sequence that is not convergent is said to be divergent.

Example
The sequence \(\hspace {0.2cm}\displaystyle {\Big \{\dfrac {i^{n + 1}}{n}\Big \}}\hspace {0.2cm}\) converges, since \(\hspace {0.2cm} \lim \limits _{n\rightarrow \infty } \dfrac {i^{1 + n}}{n} = 0\).

As we see from this \(\hspace {0.2cm}\displaystyle {-1,\hspace {0.2cm} \dfrac {-i}{2}, \hspace {0.2cm} \dfrac {1}{3},\hspace {0.2cm}\dfrac {i}{1}, \hspace {0.2cm}, \dfrac {-1}{5}}\).

Theorem
A sequence \(\{z_n\}\) converges to a complex number \(L = a + ib\) if and only if \(Re(z_n)\) converges to \(Re(L)= a\) and \(Im(z_n)\) converges to \(Im(L) = b\).

Proof
Assume that \(z_n \longrightarrow L\). Then \(\forall \hspace {0.1cm} \varepsilon > 0\hspace {0.1cm} \exists \hspace {0.1cm} N_{\varepsilon } \ni \begin {vmatrix} z_n - L\\ \end {vmatrix} < \varepsilon \hspace {0.2cm} \forall \hspace {0.1cm} n> N_{\varepsilon }\). But \[\begin {vmatrix} Re(z_n - L)\\ \end {vmatrix} \leq \begin {vmatrix} z_n - L\\ \end {vmatrix}< \varepsilon \] That is, \(Re(z_n) \longrightarrow Re(L)\). Similarly, one can show that \(Im(z_n) \longrightarrow Im (L)\).

Conversely, assume that (abbreviating \(x = Re (L)\) and \(y = Im (L))\)
\(\hspace {0.2cm} \forall \hspace {0.1cm} \varepsilon > 0\hspace {0.1cm} \exists \hspace {0.1cm} N_{\varepsilon } \ni \begin {vmatrix} x_n - x\\ \end {vmatrix},\hspace {0.1cm}\begin {vmatrix} y_n - y\\ \end {vmatrix} < \dfrac {\varepsilon }{2}\hspace {0.2cm}\forall \hspace {0.1cm}n>N_{\varepsilon }\). Then by the triangle inequality \[ \begin {vmatrix} z_n - L\\ \end {vmatrix} \leq \begin {vmatrix} x_n - x\\ \end {vmatrix} + \begin {vmatrix} y_n - y\\ \end {vmatrix} < \dfrac {\varepsilon }{2} + \dfrac {\varepsilon }{2} = \varepsilon \] \(\implies \hspace {0.2cm} z_n \longrightarrow L\) as \(n \longrightarrow \infty .\)


Example
Consider the sequence \(\displaystyle {\Big \{\dfrac {3 + ni}{n + 2ni}\Big \}}\)

Solution \begin {align*} \text {From}\hspace {1cm} z_n & = \dfrac {3 + ni}{n + 2ni} = \dfrac {(3 + ni) (n-2ni)}{n^2 + 4n^2}\\\\ & = \dfrac {2n^2 + 3n}{5n^2} + i\hspace {0.1cm}\dfrac {n^2 - 6n}{5n^2} \end {align*}

we see that

\(Re(z_n) = \dfrac {2n^2 + 3n}{5n^2} = \dfrac {2}{5} + \dfrac {3}{5n} \longrightarrow \dfrac {2}{5}\) as \(n\longrightarrow \infty \)

\(Im(z_n) = \dfrac {n^2 - 6n}{5n^2} = \dfrac {1}{5} - \dfrac {6}{5n}\longrightarrow \dfrac {1}{5}\) as \(n \longrightarrow \infty \)

Hence \(\hspace {0.2cm} z_n \longrightarrow \dfrac {2}{5} + i\hspace {0.1cm}\dfrac {1}{5}\)


Definition
A sequence \(\{z_n\}_{n\geq 1}\) is said to be Cauchy if \(\forall \hspace {0.1cm} \varepsilon > 0, \exists \hspace {0.1cm} n_0 \in \mathbb {N} \ni n,m \geq n_0,\hspace {0.1cm}\begin {vmatrix} z_m - z_n\\ \end {vmatrix} < \varepsilon \).

Proposition
A complex sequence is convergent if and only if it is a Cauchy sequence.
