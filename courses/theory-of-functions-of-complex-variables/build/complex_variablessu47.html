7.5 Cauchy Inequality

Let \(f(z)\) be analytic in a simply connected domain \(D\) containing a circular contour \(C\) of radius \(R\) centered on \(z_0\). If at each point \(z\) on \(C\), \(\hspace {0.2cm}\begin {vmatrix} f(z)\\ \end {vmatrix} \leq M\hspace {0.2cm}\), then \[\begin {vmatrix} f^n(z_0)\\ \end {vmatrix} \leq \dfrac {n! M}{R^n}\hspace {0.2cm}, \hspace {0.4cm} \text {for}\hspace {0.2cm} n = 1, 2, 3, \cdots \cdots \cdots \]

Proof
Use the Cauchy integral formula, set \(\hspace {0.2cm} z - z_0 = Re^{i\theta }\hspace {0.2cm} , \hspace {0.3cm} 0\leq \theta \leq 2\pi \hspace {0.2cm}, \hspace {0.3cm} dz = iRe^{i\theta }d\theta \) \begin {align*} f^n(z_0) & = \dfrac {n!}{2\pi i}\int \dfrac {f(z)}{\big (z - z_0\big )^{n+1}}dz\\\\ & = \dfrac {n!}{2\pi i}\int ^{2\pi }_0\dfrac {f\Big (z_0 + Re^{i\theta }\Big )}{\Big (Re^{i\theta }\Big )^{n+1}}\cdot iRe^{i\theta }d\theta \\\\ & = \dfrac {n!}{2\pi i}\int ^{2\pi }_0\dfrac {f\big (z_0 + Re^{i\theta }\big )\cdot iRe^{i\theta }}{R^{n + 1} e^{i\theta (n + 1)}} d\theta \end {align*}

Taking modulus \begin {align*} \begin {vmatrix} f^n(z_0)\\ \end {vmatrix} & \leq \dfrac {n!}{2\pi i}\int ^{2\pi }_0\begin {vmatrix} \dfrac {f\big (z_0 + Re^{i\theta }\big )\cdot iRe^{i\theta }}{R^{n + 1} e^{i\theta (n + 1)}}\\ \end {vmatrix}d\theta \\\\ & \leq \dfrac {n!}{2\pi i}\int ^{2\pi }_0\dfrac {M}{R^n}d\theta \\\\ & = \dfrac {n!M}{2\pi R^n}\int ^{2\pi }_0 d\theta \\\\ & = \dfrac {n!M}{R^n} \end {align*}

Thus \(\hspace {0.3cm} \begin {vmatrix} f^n(z_0)\\ \end {vmatrix} \leq \dfrac {n!M}{R^n}\)

Example
Show that \(\hspace {0.2cm} f(z) = \dfrac {1}{z + 1}\hspace {0.2cm}\) satisfies the Cauchy inequality on the circle \(\hspace {0.2cm}\begin {vmatrix} z - 4\\ \end {vmatrix} = 3\).

Working
\(f(z) = \dfrac {1}{z + 1}\hspace {0.1cm}\) is analytic everywhere except at \(\hspace {0.1cm} z = -1\). Hence \(f(z)\) is analytic inside the region \(\hspace {0.2cm} \begin {vmatrix} z - 4\\ \end {vmatrix} = 3\).

\(f'(z) = \dfrac {-1}{\big (z + 1\big )^2}\)

\(f''(z) = \dfrac {2}{\big (z + 1\big )^3}\)

\(f'''(z) = \dfrac {-6}{\big (z + 1\big )^4}\)

\(f^4(z) = \dfrac {4!}{\big (z + 1\big )^5}\)

\(\vdots \)

\(f^n(z) = \dfrac {(-1)^n\hspace {0.1cm}n!}{\big (z + 1\big )^{n + 1}}\)

Thus

\(\begin {vmatrix} f^n(z)\\ \end {vmatrix} = \begin {vmatrix} \dfrac {(-1)^n\hspace {0.1cm}n!}{\big (z + 1\big )^{n + 1}}\\ \end {vmatrix} = \dfrac {n!}{\big (z + 1\big )^{n + 1}}\)

\(\begin {vmatrix} f^n(4)\\ \end {vmatrix} = \dfrac {n!}{\big (4 + 1\big )^{n + 1}} = \dfrac {n!}{5^{n + 1}}\)

\(\dfrac {n! M}{R^n} = \dfrac {n! M}{3^n}\)

\(M\) is the maximum value of \(\begin {vmatrix} f(z)\\ \end {vmatrix}\) where \(z\) is on or inside \(\hspace {0.2cm} \begin {vmatrix} z - 4\\ \end {vmatrix} = 3\)

\[\therefore \hspace {0.3cm} \begin {vmatrix} f(z)\\ \end {vmatrix} \leq \dfrac {1}{2}\]

Set \(\hspace {0.2cm} M = \dfrac {1}{2}\)

\[\therefore \hspace {0.3cm} \dfrac {n! M}{R^n} = \dfrac {n! M}{3^n} = \dfrac {n!}{2\cdot 3^n}\]

Theorem
Let \(f(z)\) be analytic for \(\hspace {0.2cm} \begin {vmatrix} z\\ \end {vmatrix} < R\hspace {0.2cm}\) and such that \(\hspace {0.2cm} \begin {vmatrix} f(z)\\ \end {vmatrix} < M\hspace {0.2cm}\) then \[\begin {vmatrix} f^m\big (re^{i\theta }\big )\\ \end {vmatrix} \leq \dfrac {m! MR}{\big (R - r\big )^{m+1}}\hspace {0.2cm},\hspace {0.8cm}\text {for}\hspace {0.2cm} m = 0, 1, \cdots \cdots \hspace {0.8cm} 0\leq r\leq R\]

Proof
From the Cauchy integral formula for higher derivatives \[f^m(z_0) = \dfrac {m!}{2\pi i}\int _C\dfrac {f(z)}{\big (z - z_0\big )^{m + 1}}dz\] For a simple closed curve around \(z_0\). Take \(C\) to be the circle \(\hspace {0.2cm}\begin {vmatrix} z\\ \end {vmatrix} = R\hspace {0.2cm}\) so that \(\hspace {0.2cm} z = Re^{i\theta },\\ \hspace {0.5cm} 0\leq \theta \leq 2\pi \). Let \(\hspace {0.2cm} z_0 = re^{i\phi }\hspace {0.2cm}\) with \(\hspace {0.2cm} 0\leq r \leq R\)

\[f^m\big (re^{i\phi }\big ) = \dfrac {m!}{2\pi i}\int ^{2\pi }_0 \dfrac {f\big (Re^{i\theta }\big )}{\big (Re^{i\theta } - re^{i\phi }\big )^{m+1}}\hspace {0.1cm}iRe^{i\theta }d\theta \]

\begin {align*} \begin {vmatrix} f^m\big (re^{i\phi }\big )\\ \end {vmatrix} & = \begin {vmatrix} \dfrac {m!}{2\pi i}\displaystyle {\int ^{2\pi }_0 }\dfrac {f\big (Re^{i\theta }\big )}{\big (Re^{i\theta } - re^{i\phi }\big )^{m+1}}\hspace {0.1cm}iRe^{i\theta }d\theta \\ \end {vmatrix}\\\\ & \leq \dfrac {m!}{2\pi i}\int ^{2\pi }_0\begin {vmatrix} \dfrac {f\big (Re^{i\theta }\big )}{\big (Re^{i\theta } - re^{i\phi }\big )^{m+1}}\hspace {0.1cm}iRe^{i\theta }\\ \end {vmatrix}d\theta \\\\ & \leq \dfrac {m!}{2\pi }\int ^{2\pi }_0\dfrac {\begin {vmatrix} f\big (Re^{i\theta }\big )\\ \end {vmatrix} \cdot R d\theta }{\big (R - r\big )^{m + 1}}\\\\ & \leq \dfrac {m! RM}{2\pi \big (R - r\big )^{m + 1}}\int ^{2\pi }_0d\theta \\ & = \dfrac {m! MR}{\big (R - r\big )^{m + 1}}\\\\ \end {align*}

Assignment
Let \(f(z)\) be analytic everywhere in the finite complex plane and take \(a\) and \(b\) be any two distinct points inside the circle \(C\) with equation \(\hspace {0.2cm}\begin {vmatrix} z\\ \end {vmatrix} = R.\hspace {0.2cm}\) Using the Cauchy integral formula and considering the difference \(\hspace {0.2cm}f(a) - f(b)\hspace {0.2cm}\) prove that if \(f(z)\) is bounded, then \(f(z) \equiv \) constant.
