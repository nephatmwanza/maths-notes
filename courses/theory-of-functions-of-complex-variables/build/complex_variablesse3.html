3 Elementary Point Set Topology of \(\mathbb {C}\)

Definition
A metric space is a pair \((X,d)\) where \(X\) is a set and \(d\) is a function from \(X\times X\) into \(\mathbb {R}\), called a distance function or metric, which satisfies the following conditions for \(x,y, z \in X\).

1.
\(d(x,y) \geq 0\)
2.
\(d(x,y) = 0\hspace {0.2cm}\) if and only if \(\hspace {0.2cm} x = y\)
3.
\(d(x,y) = d(y,x)\hspace {0.2cm}\) (symmetry)
4.
\(d(x,z) \leq d(x,y) + d(y,z)\hspace {0.2cm}\) (triangle inequality)

\(*\hspace {0.2cm} B(a;r) = \big \{z \in \mathbb {C}:\hspace {0.2cm} \begin {vmatrix} z - a\\ \end {vmatrix} < r\big \}\hspace {0.2cm}\) (open ball of radius \(r\), centred at \(a\))

\(\begin {vmatrix} z\\ \end {vmatrix}:\hspace {0.2cm}\) distance between 0 and \(z\) in the complex plane.

\(\implies \hspace {0.2cm} \begin {vmatrix} z_1 - z_0\\ \end {vmatrix}:\hspace {0.2cm}\) distance between complex numbers \(z_1\) and \(z_0\) in the complex number.

Example

\(B(i;1) = \{z \in \mathbb {C}:\hspace {0.2cm}\begin {vmatrix} z - i\\ \end {vmatrix} < 1\}\)

\(*\hspace {0.2cm} \overline {B(a; r)} = \big \{ z \in \mathbb {C}: \hspace {0.2cm} \begin {vmatrix} z - a\\ \end {vmatrix} \leq r\big \}\hspace {0.2cm}\) ( closed ball of radius \(r\) centred at \(a\))

\(*\hspace {0.2cm} \overline {B(a ; r)} - B(a ; r) = \big \{z\in \mathbb {C}:\hspace {0.2cm} \begin {vmatrix} z - a\\ \end {vmatrix} = r \big \}\hspace {0.2cm}\) ( sphere)

\(\implies \hspace {0.3cm}\) upper half plane is the set \[\boxed {\pi = \big \{z \in \mathbb {C}:\hspace {0.2cm} Im (z) > 0\big \}}\]

\(\implies \hspace {0.3cm} \) Annulus: A set of the kind \[\boxed {\big \{ z \in \mathbb {C}:\hspace {0.2cm} r_1 < \begin {vmatrix} z - a\\ \end {vmatrix} < r_2\big \}}\]

Definition
The deleted neighbourhood of point \(a\in \mathbb {C}\) is the set \[ \big \{z \in \mathbb {C}:\hspace {0.2cm} 0 < \begin {vmatrix} z - a\\ \end {vmatrix} < r\big \}\] for some positive real number \(r\). This is denoted by \(B'(a ; r)\).

Definition
A set \(\hspace {0.2cm} A \subseteq \mathbb {C}\hspace {0.2cm}\) is open if for every \(z \in A\), there exist \(r>0,\hspace {0.2cm} r(z)\hspace {0.2cm}\) such that \(\hspace {0.2cm} B(z ; r )\subseteq A\).

Example
\(B(a ; r)\hspace {0.2cm}\) is an open set.

Proof
Let \(\hspace {0.2cm} z \in B(a; r) = \big \{ z \in \mathbb {C}:\hspace {0.2cm} \begin {vmatrix} z -a\\ \end {vmatrix} < r\big \}\)

\(\begin {vmatrix} z - a\\ \end {vmatrix} < r\hspace {0.2cm}\) so \(\hspace {0.2cm} 0 < r - \begin {vmatrix} z - a\\ \end {vmatrix}\)

Let \(\hspace {0.2cm} \delta \hspace {0.2cm}\) be \(\ni \hspace {0.2cm} 0 < \delta < r - \begin {vmatrix} z - a\\ \end {vmatrix}\)

Then if \(\hspace {0.2cm} w \in B(z; \delta )\) \begin {align*} \begin {vmatrix} w - z\\ \end {vmatrix} < \delta \hspace {0.2cm} \implies \hspace {0.2cm} \begin {vmatrix} w - a\\ \end {vmatrix} & \leq \begin {vmatrix} w - z\\ \end {vmatrix} + \begin {vmatrix} z - a\\ \end {vmatrix}\\ & \leq \delta + \begin {vmatrix} z - a\\ \end {vmatrix}\\ &< r \end {align*}

Since \(\hspace {0.2cm} (0 < \delta < r - \begin {vmatrix} z - a\\ \end {vmatrix})\hspace {0.2cm}\) we have that \(\hspace {0.2cm}\begin {vmatrix} w - a\\ \end {vmatrix} < r\hspace {0.2cm}\) so \(\hspace {0.2cm} w \in B(a;r)\)

\(\implies \hspace {0.2cm} B(z; \delta ) \subseteq B(a; r)\)

Since \(z\) was arbitrary point of \(B(a;r),\hspace {0.2cm} B(a;r)\hspace {0.2cm}\) is an open set.
