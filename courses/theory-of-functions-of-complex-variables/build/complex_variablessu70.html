11.9 Harmonic Functions

Problem 11.101.

(a).
State Harnack’s inequality.
(b).
Prove Harnack’s inequality.

Problem 11.102. Show that a non-constant harmonic function on a domain in \(\mathbb {R}^{2}\) is an open map.

Problem 11.103. Let \(G\) be a region and \(u\) a non-constant harmonic function on \(G\). Show that \(u\) is an open map from \(G\) to \(\mathbb {R}\).

Problem 11.104. Prove that there is no harmonic function \(u\) on \(\Delta ^{*} = \{0 < \left |z\right | < 1\}\), continuous on \(\overline {\Delta ^{*}} = \{\left |z\right | \leq 1\}\), such that \(u \equiv 0\) on \(\{\left |z\right | = 1\}\) and \(u = 1\) at \(z = 0\).

Problem 11.105. Let \(G\) be a region and \(u\) a non-constant harmonic function on \(G\). Show that \(u\) is an open map.

Problem 11.106. State and prove Harnack’s Inequality for harmonic functions.

Problem 11.107. Let \(\Omega \subseteq G\) be a relatively compact region and \(f : \partial \Omega \rightarrow \mathbb {C}\) continuous.

(a).
Describe, without proof, Perron’s solution of the Dirichlet problem on \(\Omega \) with boundary value \(f\) on \(\partial \Omega \).
(b).
Let \(\Omega \) be the punctured disc \(\{z : 0 < \left |z\right | < 1\}\). Give an example of a continuous function \(f\) on \(\partial \Omega \) for which the Dirichlet problem is not solvable, and prove it.

Problem 11.108. A function \(u(x,y)\) of two real variables is harmonic if it is twice continuously differentiable and \(\dfrac {\partial ^{2}u}{\partial x^{2}} + \dfrac {\partial ^{2}u}{\partial y^{2}} = 0\). Prove that harmonic functions are infinitely differentiable.

Problem 11.109. Prove that a non-constant harmonic function on a region in \(\mathbb {R}^{2}\) is an open map.

Problem 11.110. State and prove Harnack’s Inequality for harmonic functions.

Problem 11.111. Let \(u : G \rightarrow \mathbb {R}\) be continuous on a region \(G \subseteq \mathbb {R}^{2}\) and satisfy the mean value property. Prove that \(u\) is harmonic, that is \(\Delta u = 0\).

Problem 11.112. Let \(u\) and \(v\) be harmonic functions on the whole of \(\mathbb {R}^{2}\) with \[u(x,y) \geq v(x,y) \hspace {0.5cm}\text {for all } (x,y) \in \mathbb {R}^{2}.\] Prove that there is a constant \(c\) such that \(u(x,y) = v(x,y) + c\) for all \((x,y) \in \mathbb {R}^{2}\).

Problem 11.113. Let \(B(a,R)\) be the open ball with centre \(a\) and radius \(R\), and \(\overline {B}(a,R)\) its closure. Let \(u : \overline {B}(a,R) \rightarrow \mathbb {R}\) be continuous with \(u(z) \geq 0\) for all \(z\). Show that if \(u\) is harmonic in \(B(a,R)\) then for \(0 \leq r < R\) and all \(\theta \), \[\dfrac {R - r}{R + r}\,u(a) \ \leq \ u\!\left (a + re^{i\theta }\right ) \ \leq \ \dfrac {R + r}{R - r}\,u(a).\]

Problem 11.114.

(a).
Let \(f\) be a continuous function on \(\partial \Delta = \{z \in \mathbb {C} : \left |z\right | = 1\}\). Write explicitly a harmonic function \(u\) on \(\Delta = \{z \in \mathbb {C} : \left |z\right | \leq 1\}\) with boundary values \(f\). No proof is needed.
(b).
Evaluate the integral \(\displaystyle \int _{\left |z\right | = 1} \dfrac {d\theta }{\left |z - \tfrac {1}{2}\right |^{2}}\), where \(z = e^{i\theta }\), \(\theta \in [0, 2\pi ]\).
(c).
Prove that a continuous function satisfying the mean-value equality must be harmonic.

Problem 11.115. Find the most general harmonic polynomial of the form \(ax^{3} + bx^{2}y + cxy^{2} + dy^{3}\). Determine the conjugate harmonic function and the corresponding analytic function of \(z = x + iy\).

Problem 11.116. Prove that a continuous function on a domain is harmonic if and only if it satisfies the mean value property.

Problem 11.117. Suppose \(\Omega \) is a bounded region in \(\mathbb {C}\) and \(f : \Omega \rightarrow \mathbb {R}\) is continuous on \(\overline {\Omega }\) and satisfies the mean-value equality \[f(z_0) = \dfrac {1}{2\pi }\int ^{2\pi }_{0} f\!\left (z_0 + \rho e^{i\theta }\right )d\theta \] for all \(z_0 \in \Omega \) and \(\rho > 0\) with \(\overline {B(z_0,\rho )} \subset \Omega \). Give a direct proof that if \(f\) attains the value \(M = \max _{z \in \overline {\Omega }} f(z)\) at an interior point of \(\Omega \), then \(f\) is constant.
