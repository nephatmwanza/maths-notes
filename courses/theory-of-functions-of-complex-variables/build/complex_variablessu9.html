2.3 Power Series

A Power Series: A series of the form \(\hspace {0.2cm}a_0 + a_1z + a_2z^2 + \cdots \cdots \cdots \hspace {0.2cm}\) where \(a_i\in \mathbb {C}\) is called a power series around 0 in the variable \(z\).

Note

\(\implies \)
Power series around \(0\) converges for \(z = 0\)
\(\implies \)
Power series around \(a\) converges for \(z = a\)

A power series is said to be convergent at a point \(z = z_0\) if the partial sums \(S_n\) evaluated at \(z_0\) converges to a limit.

Example: Geometric series

\(\displaystyle {1 + z + z^2 + \cdots \cdots \cdots \cdots }\)

\(\displaystyle {(1 - z)\big (1 + z + z^2 + \cdots \cdots \cdots + z^n\big ) = 1 - z^{n+1}}\)

\(\displaystyle {1 + z + z^2 + \cdots \cdots \cdots + z^n = \dfrac {1 - z^{n + 1}}{1 - z}}\hspace {0.2cm}\) if \(z\neq 1\)

Since \(\lim \limits _{n\rightarrow \infty } z^{n + 1} = 0\) if \( \begin {vmatrix} z\\ \end {vmatrix} < 1\).

when \(\begin {vmatrix} z\\ \end {vmatrix} < 1\) the geometric series \(\displaystyle {\sum ^{\infty }_{n = 0}z^n}\) converges to \(\dfrac {1}{1 - z}\)

\(z^{n + 1}\) diverges for \(\begin {vmatrix} z\\ \end {vmatrix}> 1\).

So, \(\displaystyle {\sum z^n = \begin {cases} \text {converges}\hspace {0.2cm} \dfrac {1}{1 - z}\hspace {0.2cm}\text {when}\hspace {0.2cm} \begin {vmatrix} z \end {vmatrix} < 1\\\\ \text {diverges when}\hspace {0.2cm}\begin {vmatrix} z\\ \end {vmatrix}> 1\\ \end {cases} }\)

Theorem
To each power series \(\displaystyle {\sum a_n z^n}\) there exists a corresponding \(R\) with \(0\leq R\leq \infty \) called the radius of convergence, with the following properties

i).
\(\displaystyle {\sum a_n z^n}\) converges absolutely for every \(z\) with \(\begin {vmatrix} z\\ \end {vmatrix} < R\).
ii).
If \(\begin {vmatrix} z\\ \end {vmatrix}> R\), the terms of the series are unbounded and hence the series is divergent.

Proof

i).
Let \(R = \sup \big \{\begin {vmatrix} z\\ \end {vmatrix}:\hspace {0.2cm} \sum \begin {vmatrix} a_n z^n\\ \end {vmatrix}\hspace {0.2cm} \text {converges}\big \}\). If \(\begin {vmatrix} z\\ \end {vmatrix} < R\) then there is a \(z_1\ni \begin {vmatrix} z\\ \end {vmatrix} < \begin {vmatrix} z_1\\ \end {vmatrix} < R\) and \(\displaystyle {\begin {vmatrix} a_nz_1^n\\ \end {vmatrix}}\) converges.
Now there is an \(\hspace {0.2cm}M\geq 0 \ni \begin {vmatrix} a_nz_1^n\\ \end {vmatrix}\leq M \hspace {0.2cm} \forall n \geq 0\hspace {0.2cm} \cdots \cdots \cdots \hspace {0.2cm}(*) \hspace {0.3cm}\) then \begin {align*} \begin {vmatrix} a_nz^n\\ \end {vmatrix} & = \begin {vmatrix} a_n\\ \end {vmatrix}\hspace {0.1cm}\begin {vmatrix} \dfrac {z}{z_1}\\ \end {vmatrix}^n\hspace {0.1cm}\begin {vmatrix} z_1\\ \end {vmatrix}^n\\\\ & \leq M\hspace {0.1cm}\begin {vmatrix} \dfrac {z}{z_1}\\ \end {vmatrix}^n\hspace {0.3cm} \text {by}\hspace {0.2cm}(*) \end {align*}

Since \(\hspace {0.1cm}\displaystyle {\begin {vmatrix} \dfrac {z}{z_1}\\ \end {vmatrix} < 1}\)

\(\displaystyle {\sum M \begin {vmatrix} \dfrac {z}{z_1}\\ \end {vmatrix}^n = M \sum \begin {vmatrix} \dfrac {z}{z_1}\\ \end {vmatrix}^n}\hspace {0.2cm}\) converges and so by comparison test \(\displaystyle {\sum a_n z^n}\) converges absolutely.

ii).
If \(\begin {vmatrix} z\\ \end {vmatrix}>R\) and if \(\displaystyle {a_nz^n}\) is convergent then there is an \(M\geq 0 \ni \begin {vmatrix} a_n z^n\\ \end {vmatrix} \leq M,\hspace {0.2cm} \forall \hspace {0.1cm} n\geq 0\).
So, \(\forall \hspace {0.1cm} w \in \mathbb {C}\) with \(\begin {vmatrix} z\\ \end {vmatrix} > \begin {vmatrix} w\\ \end {vmatrix} >R\) \[\begin {vmatrix} a_nw^n\\ \end {vmatrix} \leq \begin {vmatrix} a_nz^n\\ \end {vmatrix}\hspace {0.1cm}\begin {vmatrix} \dfrac {w}{z}\\ \end {vmatrix}^n \leq M\hspace {0.1cm}\begin {vmatrix} \dfrac {w}{z}\\ \end {vmatrix}^n\] Since \(\displaystyle {\sum M\hspace {0.1cm}\begin {vmatrix} \dfrac {w}{z}\\ \end {vmatrix}^n}\) is a convergent geometric series. \(\displaystyle {\sum \begin {vmatrix} a_nw^n\\ \end {vmatrix}}\) is also convergent by comparison test.
This is a contradiction to the definition of \(R\). So \(\displaystyle {\sum a_n z^n}\) is divergent for \(\begin {vmatrix} z\\ \end {vmatrix}> R\).

\(\star \) Determination of the radius of convergence of a given power series can be done using the ratio or the root test.

Example
Consider the series \(\hspace {0.2cm}\displaystyle {\sum ^{\infty }_{n = 0} \dfrac {z^n}{n!}}\)

\(\therefore \) By ratio test, this series converges absolutely when \begin {align*} \lim \limits _{n\rightarrow \infty } \begin {vmatrix} \dfrac {z^{n+1}\big /\big (n+1\big )!}{z^n\big /n!}\\ \end {vmatrix}& < 1\\\\ \lim \limits _{n \rightarrow \infty } \begin {vmatrix} \dfrac {z}{n+1}\\ \end {vmatrix} & < 1 \end {align*}

\(0 < 1 \hspace {0.1cm}\) is always true independent for any \(z\in \mathbb {C}\), this converges absolutely. i.e the radius of convergence is \(\infty \).

\(\star \) Cauchy\(-\)Hadamad formula for radius of convergence.
\(\therefore \) The series \(\displaystyle {\sum a_n z^n}\) has radius of convergence \(R\) where \(R\) is given by \[\dfrac {1}{R} = \lim \sup \Big \{\sqrt [n]{\begin {vmatrix} a_n\\ \end {vmatrix}}\Big \}\]

\[\dfrac {1}{0} = \infty \hspace {0.2cm}, \hspace {0.2cm} \dfrac {1}{\infty }= 0\]

Note: this limit always exists it could equal \(\infty \).

Example
Determine the radius of convergence \(R\) of the power series \(\hspace {0.2cm} \displaystyle {\sum ^{\infty }_{n = 0} \dfrac {\big (2n\big )!}{\big (n!\big )^2}\hspace {0.1cm}\big (z - 3i\big )^n}\)

\begin {align*} L^* & = \lim \limits _{n\rightarrow \infty } \begin {vmatrix} \dfrac {\big (2n + 2\big )!}{\big ((n+1)!\big )^2}\div \dfrac {\big (2n)!}{\big (n!\big )^2} \end {vmatrix}\\\\ & = \lim \limits _{n\rightarrow \infty } \dfrac {\big (2n + 2\big )\big (2n+1\big )}{\big (n + 1\big )^2}\\\\ & = 4 \end {align*}

Hence \(R = \dfrac {1}{L^*} = \dfrac {1}{4}\). The series converges in the disk \(\begin {vmatrix} z - 3i\\ \end {vmatrix}< \dfrac {1}{4}\) of radius \(\dfrac {1}{4}\) and center \(3i\).
