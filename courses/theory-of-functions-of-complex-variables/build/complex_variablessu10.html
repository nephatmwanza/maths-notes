3.1 Generating Open Sets

1.
The empty set is open
2.
The entire complex plane is an open set.
3.
If \(\hspace {0.2cm} S_1, \hspace {0.1cm} S_2\hspace {0.2cm}\) are open sets then \(S_1 \cap S_2\) is open.
4.
If \(\big \{S_{\alpha }\big \}_{\alpha \in A}\hspace {0.2cm}\) (\(A\) is some index set) is an arbitrary collection open sets in \(\mathbb {C}\) then \(\hspace {0.2cm} \bigcup \limits _{\alpha \in A}S_{\alpha }\hspace {0.2cm}\) is an open set.

Example

1.
\(\hspace {0.2cm} \big \{z \in \mathbb {C}:\hspace {0.2cm} \begin {vmatrix} z - a\\ \end {vmatrix} > r\big \}\hspace {0.2cm}\) is an open set.
2.
\(\hspace {0.2cm} \big \{z \in \mathbb {C}:\hspace {0.2cm} \begin {vmatrix} z - a\\ \end {vmatrix} > r_1\big \} \cap \big \{z \in \mathbb {C}:\hspace {0.2cm} \begin {vmatrix} z - a\\ \end {vmatrix} < r_2\big \}\hspace {0.2cm}\) where \(\hspace {0.2cm} r_1 < r_2\).

\(= \big \{z \in \mathbb {C}:\hspace {0.2cm}r_1 < \begin {vmatrix} z - a\\ \end {vmatrix} < r_2\big \}\hspace {0.2cm}\) is an open set.

Exercise
\(\pi = \big \{ z \in \mathbb {C}:\hspace {0.2cm} Im(z) > 0\big \}\hspace {0.2cm}\) is open.
