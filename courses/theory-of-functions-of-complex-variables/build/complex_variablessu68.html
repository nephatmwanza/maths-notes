11.7 The Argument Principle and Rouché’s Theorem

Problem 11.76. State and prove Rouché’s theorem.

Problem 11.77. Count the number of zeros of \(z^{4} + 3z^{3} + 6 = 0\) inside the circle \(\left |z\right | = 2\). Give reasons and show the detail of your computation.

Problem 11.78. State and prove Rouché’s Theorem.

Problem 11.79. Show that all the roots of \(e^{z} = 3z^{2}\) in the unit disc \(\{z : \left |z\right | < 1\}\) are real.

Problem 11.80. State and prove the Argument Principle.

Problem 11.81. Show that \(z^{5} + 6z^{3} - 10\) has exactly two zeros, counting multiplicities, in the annulus \(2 < \left |z\right | < 3\).

Problem 11.82. Let \[n(\gamma ; z) = \dfrac {1}{2\pi i}\int _{\gamma }\dfrac {dw}{w - z}\] be the winding number of a closed contour \(\gamma \) about a point \(z\) not on \(\gamma \). Prove that this is a constant function of \(z\) on each connected component of \(\mathbb {C}\setminus \{\gamma \}\).

Problem 11.83.

(a).
State Rouché’s Theorem.
(b).
Give a proof of the Fundamental Theorem of Algebra using Rouché’s Theorem.

Problem 11.84.

(a).
Let \(\gamma \) be a closed rectifiable path in \(\mathbb {C}\). Show that the winding number \(n(\gamma ; a) := \dfrac {1}{2\pi i}\displaystyle \int _{\gamma }\dfrac {1}{z - a}\,dz\) is a continuous function on each connected component of \(\mathbb {C}\setminus \{\gamma \}\).
(b).
Show that \(n(\gamma ; a) = 0\) if \(a\) lies in the unbounded component of \(\mathbb {C}\setminus \{\gamma \}\).

Problem 11.85. Determine the number of solutions of \(e^{z} - 5z^{4} + 2 = 0\) inside the unit circle. Give reasons and show your method.

Problem 11.86. Find the number of zeros of \[2z^{5} - 6z^{2} + z + 1 = 0\] in the annulus \(1 \leq \left |z\right | \leq 2\).

Problem 11.87.

(a).
Define the winding number of a closed rectifiable curve about a point of the complex plane.
(b).
Suppose \(\gamma \) is a closed rectifiable curve. Show that if \(a\) and \(b\) lie in the same path-connected component of \(\mathbb {C}\setminus \{\gamma \}\), then the winding numbers \(n(\gamma ; a)\) and \(n(\gamma ; b)\) are equal.
