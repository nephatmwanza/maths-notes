3.3 Compactness

Definition 3.20. A set \(\, S\subseteq \mathbb {C}\,\) is said to be bounded if there is an \(\,M > 0 \ni \left |z\right | < M\, \forall z \in S\).

Definition 3.21. Let \(\, S\subseteq \mathbb {C}\). An open covering of \(S\) is a collection of open sets \(\, G \ni \bigcup \limits _{g \in G}g\supseteq S\).

Definition 3.22. A set \(\, S\subseteq \mathbb {C}\,\) is said to be compact if every open covering of \(S\) has a finite sub-cover.

Example 3.23.

\(B(0; 1) \quad G = \big \{B(0; r): \, r \in [ 0,1) \subseteq \mathbb {R}\big \}\)

\(\bigcup \limits _{r\in [0,1)}B(0; r) \supset B(0; 1)\)

No subcollection of \(G\) contains \(\, B(0; 1)\)

E.g \(\, \big \{ n + i0: \, n \in \mathbb {N}\big \} \subset \mathbb {C}\)

\(G = \big \{ B(0; n):\, n\in \mathbb {N}\big \}\)

\(B(0; 2)\quad B(0; n)\quad B(0; n- 1)\)

Theorem 3.24 (Heine–Borel). A set \(\, S \subseteq \mathbb {C}\,\) is compact if and only if it is closed and bounded in \(\mathbb {C}\).

Example

1.
Unit circle in \(\mathbb {C}\) is compact

Theorem 3.25 (Cantor’s Theorem). Let \(\, K_j'\)s be compact subsets of \(\mathbb {C},\, j \in \mathbb {N}\,\) with \(\, K_1\supset K_2\supset K_3\supset \cdots \,\) Then \(\bigcap \limits _{j= 1}^{\infty }K_j\,\) is nonempty.

Proof. Suppose that \(\, \bigcap \limits ^{\infty }_{j = 1} K_j\,\) is empty. Then \(\, G = \big \{K^c_j : \, j\in \mathbb {N}\big \},\quad \mathbb {C} = \bigcup \limits ^{\infty }_{j= 1}K^c_j\,\) so that \(\,K_1\subset \bigcup \limits ^{\infty }_{j = 1} K^c_j\)
Since \(K_1\) is compact, there are numbers \[\, j_1, \, j_2,\ldots , j_n,\quad j_1< j_2< \cdots < j_n \quad \ni \quad K_1 \subset \bigcup \limits ^n_{m = 1}K^c_{j_m} \subset K^c_{j_{n+1}}\] \[\Big (\therefore \quad K_{j_{n+1}} \subset K_{j_n} \subset \cdots \subset K_{j_1}\Big )\] \(\implies \, K_1 \cap K_{j_{n+1}} = \emptyset \). Thus a contradiction to the given hypothesis. So \(\bigcup \limits ^{\infty }_{j = 1}K_j\,\) has to be nonempty. □

Proposition 3.26. A closed subset of a compact set is compact.
