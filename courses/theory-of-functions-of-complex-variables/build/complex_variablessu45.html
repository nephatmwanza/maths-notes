7.3 Liouville’s Theorem

If the function \(f(z)\) is analytic and bounded throughout the complex plane then \(f(z)\) is constant.

Proof
Taking \(C\) to be a circle of arbitrary radius say \(R\) on a point \(z_0\). It follows that \[f'(z_0) = \dfrac {1}{2\pi i}\int _C \dfrac {f(z)}{\big (z - z_0\big )^2}dz\] By hypothesis, if \(f(z)\) is bounded for all \(z\in \mathbb {C}\).
Then so is \(\begin {vmatrix} f(z)\\ \end {vmatrix}\), and thus there exist a positive constant \(M\) such that \(\hspace {0.2cm}\begin {vmatrix} f(z)\\ \end {vmatrix}< M\hspace {0.2cm}\) for all \(z\).

Setting \(\hspace {0.2cm} z - z_0 = Re^{i\theta }\hspace {0.2cm},\hspace {0.8cm} 0\leq \theta 2\pi \hspace {0.2cm}, \hspace {0.8cm} dz = iRe^{i\theta }d\theta \) \begin {align*} f'(z_0) & = \dfrac {1}{2\pi i}\int ^{2\pi }_0 \dfrac {f(z)\cdot iRe^{i\theta } d\theta }{R^2e^{2i\theta }}\\\\ & = \dfrac {1}{2\pi R}\int ^{2\pi }_0\dfrac {f(z)d\theta }{e^{i\theta }} \end {align*}

Take modulus on both sides \begin {align*} \begin {vmatrix} f'(z_0) \\ \end {vmatrix} & = \begin {vmatrix} \dfrac {1}{2\pi R}\displaystyle {\int ^{2\pi }_0}\dfrac {f(z)d\theta }{e^{i\theta }}\\ \end {vmatrix}\\\\ & \leq \dfrac {1}{2\pi R}\int ^{2\pi }_0\begin {vmatrix} \dfrac {f(z)}{e^{i\theta }}\\ \end {vmatrix}d\theta \\\\ & \leq \dfrac {M}{2\pi R}\int ^{2\pi }_0 d\theta \\\\ & = \dfrac {M}{R} \end {align*}

Thus \(\hspace {0.2cm}\begin {vmatrix} f'(z_0)\\ \end {vmatrix}\leq \dfrac {M}{R}\hspace {0.1cm},\hspace {0.2cm}\) Since \(R\) is arbitrary, i.e the inequality is true for all \(R>0\).

Take \(R\) arbitrary large \(\hspace {0.2cm} ( R\longrightarrow \infty )\) \[0 \leq \begin {vmatrix} f'(z_0)\\ \end {vmatrix} \leq \dfrac {M}{R}\] Then \(\hspace {0.2cm}\begin {vmatrix} f'(z_0)\\ \end {vmatrix} =0 \hspace {0.2cm}\) for all \(z_0\) in the complex plane. Thus, this is only possible if \(f(z)\) is identically constant. i.e \(\hspace {0.2cm} f(z) = \) constant.

This implies that if a non constant function is analytic in the entire plane then it cannot be bounded.

Example
Consider \(\sin z\) and \(\cos z\) ( they are not bounded).

Definition
A function \(f(z)\) which is analytic throughout the complex plane is called an entire function.
