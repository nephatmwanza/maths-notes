1.4 Minimal Sufficiency

The point of a sufficient statistic is to reduce the data without losing information about \(\theta \). Since there are many sufficient statistics, we want one that achieves the greatest reduction.

Definition 1.4.1. A sufficient statistic \(T(X)\) is minimal sufficient for \(\{f_\theta (x) : \theta \in \Omega \}\) if for every other sufficient statistic \(U(X)\) there is a function \(r\) with \(T(X) = r(U(X))\).

So a minimal sufficient statistic can be computed from any other sufficient statistic: it is the coarsest summary of the data that is still sufficient. The following theorem gives a practical way to find one.

Theorem 1.4.2. Suppose there is a statistic \(T(X)\) such that, for any two sample points \(x\) and \(y\), the ratio \(\frac {f_\theta (x)}{f_\theta (y)}\) is constant as a function of \(\theta \) if and only if \(T(x) = T(y)\). Then \(T(X)\) is minimal sufficient.

Proof. For simplicity assume \(f_\theta (x)>0\) for all \(x\) in the sample space and all \(\theta \).

\(T\) is sufficient

For each value \(t\) of \(T\) choose one sample point \(x_t\) with \(T(x_t) = t\). For any \(x\), the points \(x\) and \(x_{T(x)}\) have the same value of \(T\), so by hypothesis \(h(x) = \frac {f_\theta (x)}{f_\theta (x_{T(x)})}\) does not depend on \(\theta \). Then \[f_\theta (x) = f_\theta \left (x_{T(x)}\right )h(x) = g(T(x);\theta )h(x)\] with \(g(t;\theta ) = f_\theta (x_t)\), and \(T\) is sufficient by theorem 1.3.4.

\(T\) is minimal

Let \(U\) be any sufficient statistic, so \(f_\theta (x) = g'(U(x);\theta )h'(x)\). If \(U(x) = U(y)\), then \[\frac {f_\theta (x)}{f_\theta (y)} = \frac {g'(U(x);\theta )h'(x)}{g'(U(y);\theta )h'(y)} = \frac {h'(x)}{h'(y)},\] which does not depend on \(\theta \), and so \(T(x) = T(y)\) by hypothesis. Thus \(T\) takes the same value wherever \(U\) does, that is, \(T\) is a function of \(U\). □

Example 1.4.3. Let \(X_1, \dots , X_n\) be a random sample from \(f_\theta (x) = \theta x^{\theta - 1}\), \(0<x<1\), \(\theta >0\). Find a minimal sufficient statistic.

Solution. \(f_\theta (x) = \theta ^n\left (\prod x_i\right )^{\theta - 1}\), so for two sample points \(x\) and \(y\), \[\frac {f_\theta (x)}{f_\theta (y)} = \left (\frac {\prod x_i}{\prod y_i}\right )^{\theta - 1} .\] This is constant in \(\theta \) if and only if \(\prod x_i = \prod y_i\). By theorem 1.4.2, \(T(X) = \prod X_i\) is minimal sufficient, and so is \(\sum \ln X_i\).

Example 1.4.4. Let \(X_1, \dots , X_n\) be a random sample from \(N(\theta , \theta ^2)\), \(\theta \ne 0\). Find a minimal sufficient statistic.

Solution. \[f_\theta (x) = (2\pi \theta ^2)^{-n/2}\exp \left (-\frac {1}{2\theta ^2}\left [\sum x_i^2 - 2\theta \sum x_i + n\theta ^2\right ]\right ),\] so \[\frac {f_\theta (x)}{f_\theta (y)} = \exp \left (-\frac {1}{2\theta ^2}\left [\sum x_i^2 - \sum y_i^2\right ] + \frac 1\theta \left [\sum x_i - \sum y_i\right ]\right ).\] The functions \(\frac {1}{\theta ^2}\) and \(\frac 1\theta \) are linearly independent, so the exponent is constant in \(\theta \) only if both brackets vanish. The ratio is constant if and only if \(\sum x_i^2 = \sum y_i^2\) and \(\sum x_i = \sum y_i\), and \(T(X) = \left (\sum X_i, \sum X_i^2\right )\) is minimal sufficient. Although there is only one parameter, the minimal sufficient statistic is two-dimensional.

Example 1.4.5. Let \(X_1, \dots , X_n\) be a random sample from \(\text {UNIF}(0, \theta )\). Show that \(X_{(n)}\) is minimal sufficient.

Solution. Here the density can be zero, so we apply the idea of theorem 1.4.2 directly. For sample points \(x\) and \(y\) with positive entries, \[\frac {f_\theta (x)}{f_\theta (y)} = \frac {I\left (x_{(n)}<\theta \right )}{I\left (y_{(n)}<\theta \right )} .\] If \(x_{(n)} = y_{(n)}\), numerator and denominator are equal for every \(\theta \), and the ratio is \(1\) wherever it is defined. If \(x_{(n)}>y_{(n)}\), the ratio is \(1\) for \(\theta >x_{(n)}\) but \(0\) for \(y_{(n)}<\theta \le x_{(n)}\), so it depends on \(\theta \); the case \(x_{(n)}<y_{(n)}\) is symmetric. Hence the ratio is free of \(\theta \) exactly when \(x_{(n)} = y_{(n)}\), and \(X_{(n)}\) is minimal sufficient. Problem 1.5.4 gives a direct proof from the definition.

In examples 1.3.2, 1.3.5 and 1.3.7 the same argument shows that the sufficient statistics found (\(\sum X_i\), \(\left (\sum X_i, \sum X_i^2\right )\) and \(X_{(n)}\)) are minimal.

Example 1.4.6. Let \(X_1, \dots , X_n\) be a random sample from the logistic distribution with p.d.f. \(f_\theta (x) = \frac {e^{-(x - \theta )}}{\left (1 + e^{-(x - \theta )}\right )^2}\), \(-\infty <x<\infty \). Show that the order statistics are minimal sufficient.

Solution. \[\frac {f_\theta (x)}{f_\theta (y)} = \exp \left (\sum y_i - \sum x_i\right ) \prod _{i=1}^n\left (\frac {1 + e^{-(y_i - \theta )}}{1 + e^{-(x_i - \theta )}}\right )^2 .\] If the \(x_i\) are a rearrangement of the \(y_i\) the ratio is \(1\). Conversely, put \(u = e^\theta \); the ratio is constant in \(\theta \) only if \(\prod (1 + u e^{-y_i})^2\) and \(\prod (1 + u e^{-x_i})^2\) are proportional as polynomials in \(u\). Two polynomials that are proportional have the same roots, and the roots here are \(-e^{y_i}\) and \(-e^{x_i}\), so the sets \(\{x_i\}\) and \(\{y_i\}\) agree. Hence the ratio is constant if and only if \(x\) and \(y\) have the same order statistics, and \((X_{(1)}, \dots , X_{(n)})\) is minimal sufficient. Even for a one-parameter location family, no reduction beyond the order statistics may be possible.

Problem 1.4.1. Let \(\, X_1\, , \, X_2\, , \, \cdots \, , \, X_n\,\) be a random sample from the \(UNIF(\theta , \theta + 1)\,\) distribution. Find a minimal sufficient statistic for \(\, \{f_{\theta }(x)\, :\, \theta \in \Omega \}\).

Show solution

Solution. The joint density is one exactly when every observation lies in \((\theta ,\theta +1)\), that is \[f_{\theta }(x) = \prod _{i=1}^{n} I\left (\theta <x_i<\theta +1\right ) = I\left (x_{(n)}-1 < \theta < x_{(1)}\right ),\] and zero otherwise. Sufficiency of \(T=\left (X_{(1)},X_{(n)}\right )\) is immediate from this display.

For minimality use the ratio criterion. For two samples \(x\) and \(y\) in the support, \[\frac {f_{\theta }(x)}{f_{\theta }(y)} = \frac {I\left (x_{(n)}-1<\theta <x_{(1)}\right )}{I\left (y_{(n)}-1<\theta <y_{(1)}\right )} .\] This ratio is a constant function of \(\theta \) precisely when the two intervals \(\left (x_{(n)}-1,\ x_{(1)}\right )\) and \(\left (y_{(n)}-1,\ y_{(1)}\right )\) coincide, and two intervals coincide exactly when their endpoints agree, that is when \(x_{(1)}=y_{(1)}\) and \(x_{(n)}=y_{(n)}\). Hence \[T(X) = \left (X_{(1)},\, X_{(n)}\right )\] is minimal sufficient.

Remark. The parameter is one-dimensional and the minimal sufficient statistic is two-dimensional. There is no contradiction — minimal means no further reduction is possible, not that the dimension matches. It also shows why this model is a standard source of counterexamples: the same \(T\) is minimal sufficient but, as the next problem in the completeness section shows, it is not complete.

Problem 1.4.2. Let \(\, X_1\, , \, X_2\, , \, \cdots \, , \, X_n\,\) be a random sample from the \(EXP(1, \theta )\) distribution. Show that \(X_{(1)}\) is sufficient statistic for the model and find the conditional distribution for \(\, X_1\, , \, X_2\, , \, \cdots \, , \, X_n\,\) given \(X_{(1)} = t\). Prove that \(X_{(1)}\) is a minimal sufficient statistic.

Show solution

Solution.

Sufficiency

As in the previous section, the joint density factorises as \[f_{\theta }(x) = e^{n\theta }\,I\left (x_{(1)}>\theta \right )\cdot e^{-\sum _i x_i},\] so \(X_{(1)}\) is sufficient.

The conditional distribution

The density of \(X_{(1)}\) is that of the minimum of \(n\) independent shifted exponentials, \[f_{X_{(1)}}(t) = n\,e^{-n(t-\theta )},\qquad t>\theta ,\] so on the set where \(\min _i x_i = t\), \[f\left (x \mid X_{(1)}=t\right ) = \frac {e^{n\theta }e^{-\sum _i x_i}}{n\,e^{-n(t-\theta )}} = \frac {e^{nt-\sum _i x_i}}{n} .\] The result does not involve \(\theta \), which confirms sufficiency directly rather than through the factorisation criterion. Read another way: given \(X_{(1)}=t\), the label of the minimising index is uniform on \(\{1,\dots ,n\}\) and the remaining \(n-1\) observations are distributed as \(t\) plus independent EXP\((1,0)\) variables — the memoryless property, with the threshold reset to \(t\).

Minimality

For two samples, \[\frac {f_{\theta }(x)}{f_{\theta }(y)} = e^{\sum _i y_i - \sum _i x_i}\cdot \frac {I\left (x_{(1)}>\theta \right )}{I\left (y_{(1)}>\theta \right )} .\] The first factor is free of \(\theta \) already. The second is a constant function of \(\theta \) only if the two indicators switch at the same place, that is only if \(x_{(1)} = y_{(1)}\). Hence \(X_{(1)}\) is minimal sufficient.

Problem 1.4.3. Let \(\, X_1\, , \, X_2\, , \, \cdots \, , \, X_n\,\) be a random sample from the \(CAU(1,\theta )\) distribution. Find a minimal sufficient for \(\, \{f_{\theta }(x)\, :\, \theta \in \Omega \}\).

Show solution

Solution. The Cauchy density with location \(\theta \) and scale \(1\) is \(f_{\theta }(x) = \left [\pi \left (1+(x-\theta )^{2}\right )\right ]^{-1}\), so \[f_{\theta }(x_1,\dots ,x_n) = \frac {1}{\pi ^{n}}\prod _{i=1}^{n}\frac {1}{1+(x_i-\theta )^{2}} .\] For two samples \(x\) and \(y\) the ratio is \[\frac {f_{\theta }(x)}{f_{\theta }(y)} = \frac {\prod _{i=1}^{n}\left [1+(y_i-\theta )^{2}\right ]} {\prod _{i=1}^{n}\left [1+(x_i-\theta )^{2}\right ]} .\] Regard numerator and denominator as polynomials in \(\theta \). Each is monic of degree \(2n\). The ratio is a constant function of \(\theta \) exactly when the two polynomials are proportional, and two monic polynomials of the same degree are proportional only if they are equal. Equal polynomials have the same roots with the same multiplicities; the roots of \(\prod _i\left [1+(x_i-\theta )^{2}\right ]\) are \(\theta = x_i \pm i\), so the multiset \(\{x_1,\dots ,x_n\}\) is determined. Hence the ratio is free of \(\theta \) if and only if \(y\) is a permutation of \(x\), and the minimal sufficient statistic is the full set of order statistics \[T(X) = \left (X_{(1)},\, X_{(2)},\, \dots ,\, X_{(n)}\right ).\]

Remark. No reduction of the data is possible beyond discarding the order in which the observations arrived. This is the standard warning against expecting a low-dimensional summary: the Cauchy location model has one parameter and a minimal sufficient statistic of dimension \(n\). It is also why the sample mean is useless here — \(\overline {X}\) has the same Cauchy distribution as a single observation, so averaging buys nothing at all.
